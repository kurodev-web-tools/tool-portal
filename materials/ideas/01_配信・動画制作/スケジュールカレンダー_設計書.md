# アプリケーション設計書：スケジュールカレンダー

## 1. 概要

VTuber向けのスケジュール管理・画像生成アプリケーション。Next.jsを用いた最新のフロントエンド技術を全面的に採用し、サーバーレスで動作する静的サイトとして構築されている。

## 2. 技術スタック

| 分類          | 技術                                      | 目的                             |
| :---------- | :-------------------------------------- | :----------------------------- |
| **フレームワーク** | Next.js (App Router)                    | ReactベースのモダンなWebアプリケーション開発     |
| **言語**      | TypeScript                              | 型安全性の確保と開発効率の向上                |
| **UIライブラリ** | shadcn/ui                               | アクセシビリティとカスタマイズ性に優れたUIコンポーネント群 |
| **スタイリング**  | Tailwind CSS                            | ユーティリティファーストなCSS設計             |
| **状態管理**    | React Hooks (useState, useEffect)       | コンポーネント単位での状態管理                |
| **データ永続化**  | **PostgreSQL**または**MongoDB** (バックエンド経由) | 堅牢なデータ保存と複数デバイスでの同期            |
| **バックエンド**  | **Python (FastAPI)**                    | スケジュールデータの管理、ユーザー認証、API提供      |
| **日付操作**    | date-fns                                | 高機能かつ軽量な日付・時刻操作                |
| **フォーム管理**  | React Hook Form, Zod                    | 高パフォーマンスなフォーム実装と厳格なバリデーション     |

## 3. アーキテクチャ

*   **フロントエンド完結型**: サーバーサイドのロジックを持たない静的サイトとして設計。全ての処理はブラウザ上で完結する。
*   **データ保存**: スケジュールデータは、ブラウザの`localStorage`にJSON形式で保存される。これにより、サーバーコストをゼロに抑えつつ、ユーザーのデータを永続化している。
*   **コンポーネント指向**: shadcn/uiをベースに、機能ごとにコンポーネントが適切に分割・管理されており、高い再利用性と保守性を実現している。

## 4. データモデル

スケジュール項目は、以下の`ScheduleItem`インターフェースで定義される。

```typescript
export interface ScheduleItem {
  id: string; // UUID
  title: string; // 予定のタイトル
  date: string; // ISO 8601形式 (YYYY-MM-DD)
  time?: string; // HH:mm形式 または「未定」
  category: string; // 「雑談」「ゲーム」など
  platform: string; // 「YouTube」「Twitch」など
  notes?: string; // 備考
  isCompleted: boolean; // 完了フラグ
}
```

## 5. 主要コンポーネント構成

| コンポーネント名                            | 役割                                                |
| :---------------------------------- | :------------------------------------------------ |
| **`page.tsx`**                      | アプリケーションのメインコンポーネント。全体のレイアウト、状態管理、主要なロジックを統括する。   |
| **`calendar.tsx`**                  | 月・週・日表示を切り替え可能なカレンダーUI。日付の選択と、予定の簡易表示を担当。         |
| **`schedule-form.tsx`**             | `react-hook-form`を利用した、スケジュールの新規作成・編集フォーム。        |
| **`ScheduleManagementContent.tsx`** | PC表示時のサイドパネル、およびモバイル表示時のモーダルの中身。予定の追加ボタンや一覧表示を担う。 |
| **`SnsTemplatesContent.tsx`**       | SNS投稿テンプレートの編集と、お気に入りハッシュタグの管理機能を担う。              |
| **`@/components/ui/`**              | shadcn/uiによって提供される、ボタンやダイアログなどの基本的なUIパーツ群。        |

## 6. 主要ロジック

*   **スケジュール永続化 (`schedule-storage.ts`)**: `localStorage`へのスケジュールの保存（`saveSchedule`）と読み込み（`loadSchedule`）を行う。
*   **SNS投稿文生成 (`handleCopySNS` in `page.tsx`)**: テンプレート構文（`${title}`など）を、選択されたスケジュール項目のデータで置換し、投稿用のテキストを生成する。
