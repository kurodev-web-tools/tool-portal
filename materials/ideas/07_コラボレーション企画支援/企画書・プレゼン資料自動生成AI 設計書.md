# 企画書・プレゼン資料自動生成AI 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが企画の情報を入力し、AIが生成した企画書やプレゼン資料を閲覧・編集するインターフェース。
- **バックエンド（APIサーバー）**: データ管理、AIモデルとの連携、外部APIとの通信を処理する。
- **AIモデル**: 入力された情報や外部データに基づいて、企画書やプレゼン資料のテキストと構成を生成する。
- **外部API**: YouTube Data APIなどからコラボ相手のデータを取得する。

### PC（ブラウザ）表示
企画の概要、ターゲット、期待効果などを入力するフォームを上部に配置し、AIが生成した資料をリアルタイムでプレビューできるレイアウトを基本とする。

### スマホ表示
主要な入力項目に絞って表示し、生成された資料は縦にスクロールして見られるようにする。

## 2. 主要機能詳細

### 2-1. 自動資料生成機能
- **ユーザーアクション**:
    - **情報入力**: 企画のテーマ、コラボ相手の情報、目的などを入力する。
- **システム動作**:
    1. バックエンドが入力データを受け取る。
    2. AIモデルが、入力内容と外部から取得したデータを基に、企画書やプレゼン資料の骨子（目次、各項目のテキスト）を自動で生成する。

### 2-2. データ連携・情報自動挿入機能
- **ユーザーアクション**:
    - **アカウント連携**: コラボ相手のYouTubeチャンネルなどと連携する。
- **システム動作**:
    1. バックエンドが外部APIを通じて、コラボ相手のチャンネル登録者数、人気動画、視聴者層などのデータを自動で取得する。
    2. 取得したデータは、資料内の適切な場所に自動で挿入される。

### 2-3. デザインテンプレート・エクスポート機能
- **ユーザーアクション**:
    - **テンプレート選択**: 用意されたデザインテンプレートから好みのものを選ぶ。
    - **エクスポート**: 生成された資料をPDFやGoogleスライド、PowerPointなどの形式でダウンロードする。
- **システム動作**:
    1. 生成されたテキストとデータが選択されたテンプレートに適用される。
    2. エクスポートリクエストに応じて、指定された形式でファイルを生成する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**生成AIモデル**（GPTなど）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**Google Slides API**など。

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Proposals**: AIが生成した企画書・プレゼン資料の履歴管理.
