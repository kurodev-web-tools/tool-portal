# AI自動編集アシスタント（長尺動画向け） 設計書

## ツール名
AI自動編集アシスタント（長尺動画向け）

## カテゴリ
01_配信・動画制作

## 目的
長時間の配信アーカイブや収録動画から、AIが不要部分（無音、繰り返し、ロード時間など）やハイライトシーンを自動で検出し、効率的な動画編集を支援する。これにより、VTuberの動画編集にかかる時間と労力を大幅に削減し、コンテンツ制作の生産性を向上させる。

## 機能要件
### 1. 動画ファイル入力
*   動画ファイルのアップロード（MP4, MOVなど主要フォーマット対応）
*   クラウドストレージ（Google Drive, Dropboxなど）からの連携インポート（オプション）
*   YouTubeアーカイブURLからの直接インポート（オプション）

### 2. 不要部分自動検出
*   **無音検出:** 音声レベルが一定以下で継続する区間を自動検出（閾値設定可能）
*   **繰り返しシーン検出:** 映像の類似性（ハッシュ値、特徴量）や音声の繰り返しパターンから、同じシーンや動作の繰り返しを検出
*   **ゲーム特化検出:**
    *   ロード画面、メニュー画面、死亡・リトライ画面などのパターンを画像認識で検出
    *   特定のゲームタイトルに特化した検出モデル（オプション）

### 3. ハイライトシーン自動抽出
*   **音声イベント検出:** 音声の盛り上がり（笑い声、叫び声）、声のトーン変化、BGMの変化などを分析し、盛り上がりポイントを検出
*   **コメント・チャット連携:** 配信プラットフォームのコメントログと連携し、コメントの急増、特定のキーワード（「草」「神回」など）出現箇所をハイライト候補として検出
*   **ゲームイベント検出:** ゲーム内の特定のイベント（ボス撃破、レベルアップ、レアアイテム取得、勝利/敗北画面など）を映像解析で認識し、ハイライト候補として検出
*   **VTuberのリアクション検出:** VTuberの表情や動き（驚き、喜びなど）を映像解析で検出し、ハイライト候補として提案

### 4. 編集候補タイムライン表示
*   検出された不要部分とハイライトシーンを、動画のタイムライン上に視覚的に表示
*   各検出区間の種類（無音、ロード、ハイライトなど）を色分け表示
*   タイムラインの拡大・縮小、スクロール機能

### 5. プレビュー・微調整
*   提案された編集内容（カット、ハイライト）をプレビュー再生
*   VTuberがタイムライン上でカット点の調整、区間の追加、削除、結合などを手動で行えるインターフェース
*   ハイライトシーンの長さ調整機能

### 6. 自動テロップ・字幕生成（オプション）
*   検出されたハイライトシーンの会話から、音声認識により自動でテロップや字幕を生成
*   生成された字幕の編集・タイミング調整機能

### 7. 編集済み動画エクスポート
*   最終確認後、編集済み動画ファイルを指定の形式（MP4, MOVなど）でエクスポート
*   解像度、フレームレート、ビットレートなどのエクスポート設定
*   クラウドストレージへの直接アップロード（オプション）

## 非機能要件
*   **性能:** 長尺動画（例：2時間）の解析・編集候補生成は30分以内（目標）。エクスポート処理の高速性。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** アップロードされた動画ファイルのプライバシー保護。データ暗号化。
*   **拡張性:** 新しい検出アルゴリズム、ゲームタイトルへの対応、エクスポートフォーマットの追加。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。動画編集の知識が少ないVTuberでも容易に操作できる設計。

## システム構成
*   **フロントエンド:** React / Next.js (Webアプリケーション)
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **動画解析エンジン:** FFmpeg, OpenCV, Librosa (音声解析)
*   **AI/MLモデル:** TensorFlow / PyTorch (画像認識、音声認識、NLP)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (動画ファイル、中間処理データ)
*   **キューイングサービス:** RabbitMQ / Kafka (非同期処理、タスク管理)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`
*   **VideoProject:** `id`, `user_id`, `original_file_path`, `status` (processing, ready, exported), `created_at`
*   **Segment:** `id`, `project_id`, `start_time`, `end_time`, `type` (mute, repeat, highlight, load_screen), `confidence_score`
*   **Highlight:** `id`, `project_id`, `segment_id`, `reason` (audio_spike, comment_surge, game_event), `thumbnail_path`
*   **ExportJob:** `id`, `project_id`, `export_format`, `resolution`, `status`, `exported_file_path`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** TensorFlow, PyTorch, Transformers, OpenCV, Librosa
*   **動画処理:** FFmpeg
*   **データベース:** PostgreSQL
*   **ストレージ:** AWS S3
*   **キュー:** RabbitMQ

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 動画ファイルアップロード、無音検出、基本的なカット編集候補生成、タイムライン表示、エクスポート機能。
*   **フェーズ2:** 繰り返しシーン検出、ゲーム特化検出（ロード画面）、基本的なハイライトシーン抽出（音声イベント）。
*   **フェーズ3:** コメント・チャット連携によるハイライト検出、ゲームイベント検出、VTuberリアクション検出、自動テロップ・字幕生成。
