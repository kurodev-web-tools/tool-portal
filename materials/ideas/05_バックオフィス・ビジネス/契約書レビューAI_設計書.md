# 契約書レビューAI 設計書

## ツール名
契約書レビューAI

## カテゴリ
05_バックオフィス・ビジネス

## 目的
VTuberが企業案件やコラボレーション、グッズ販売などに関する契約書の内容をAIがレビューし、VTuberにとって不利な条項、リスク、見落としがちなポイントを検出する。これにより、法的な専門知識がなくても契約内容を正確に理解し、安心して契約を締結できるよう支援し、法的リスクを低減する。

## 機能要件
### 1. ユーザー認証・契約書管理
*   VTuberアカウントでのログイン機能
*   レビュー済み契約書の履歴管理、検索、フィルタリング

### 2. 契約書ファイル入力
*   契約書ファイル（PDF, Word, テキストなど）のアップロード
*   OCR（光学文字認識）によるPDF/画像からのテキスト抽出
*   テキストの自動整形、段落・条項の自動認識

### 3. AIによる条項解析
*   **自然言語処理（NLP）:** 契約書テキストを解析し、各条項の法的意味合い、目的、当事者間の関係性を理解
*   **法的知識データベース連携:** 関連する法律、判例、業界慣習などのデータベースと照合
*   **VTuber特化型解析:** 著作権の帰属、肖像権、配信プラットフォームの規約、VTuber活動における特有のリスク（例：アンチコメントへの対応義務）などを考慮した解析

### 4. リスク検出・警告
*   **不利な条項検出:**
    *   過度な責任範囲（例：VTuberに一方的に不利な損害賠償条項）
    *   不公平な解除条項（例：VTuber側からの解除が極めて困難）
    *   競業避止義務の範囲（例：活動ジャンルを過度に制限）
    *   著作権の不適切な帰属（例：VTuberが作成したコンテンツの著作権が全て相手方に移転）
*   **リスクポイント指摘:**
    *   報酬の支払い条件（時期、方法、遅延時の対応）
    *   秘密保持義務の範囲と期間
    *   契約期間と更新条件
    *   準拠法、紛争解決条項
*   **不足条項提案:** 一般的な契約書に記載されるべきだが、不足している条項（例：不可抗力条項、反社会的勢力排除条項）を提案
*   **警告レベル表示:** 検出されたリスクの重要度をレベル分けして表示

### 5. 修正案提案
*   検出されたリスクや不利な条項に対して、AIが一般的な修正案や交渉のポイントを提案
*   修正案の具体例（例：「甲は乙に対し、本件コンテンツの著作権を無償で譲渡する」→「甲は乙に対し、本件コンテンツの利用許諾を与える」）

### 6. 用語解説
*   契約書によく出てくる専門用語や法律用語を、VTuberにも分かりやすい言葉で解説
*   関連する判例や具体例の提示

### 7. 弁護士連携
*   AIレビュー結果を弁護士に共有するためのレポート生成（PDF, CSV形式）
*   提携弁護士への相談窓口案内、オンライン相談予約機能（オプション）

## 非機能要件
*   **性能:** 契約書アップロード後、レビュー結果を数分以内に表示（目標）。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** アップロードされた契約書データ、ユーザー情報の機密性の厳重な保護。データ暗号化、アクセス制御。
*   **拡張性:** 新しい法律、判例、契約書テンプレート、VTuber業界の慣習への対応。AIモデルの更新。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。法律知識が少ないVTuberでも容易に利用できる設計。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **OCRエンジン:** Google Cloud Vision AI, AWS TextractなどのAPI利用
*   **AI/MLモデル:** 自然言語処理（NLP）モデル（Transformers, spaCyなど）、法律知識グラフ、ルールベースエンジン
*   **データベース:** PostgreSQL / MongoDB (契約書データ、レビュー結果、用語解説)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (契約書ファイル)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`
*   **Contract:** `id`, `user_id`, `file_name`, `file_path`, `upload_date`, `status` (pending, reviewed), `review_result_id`
*   **ReviewResult:** `id`, `contract_id`, `review_date`, `summary`, `risk_score`, `issues` (Array of JSONB), `recommendations` (Array of JSONB)
*   **Issue:** `type` (unfavorable_clause, missing_clause, risk_point), `clause_text`, `explanation`, `suggested_amendment`
*   **TermGlossary:** `id`, `term`, `explanation`, `example`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** Transformers, spaCy, NLTK
*   **データベース:** PostgreSQL
*   **ストレージ:** AWS S3

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 契約書ファイルアップロード（テキスト/PDF）、基本的な条項解析、不利な条項検出（著作権帰属、報酬支払い）、用語解説。
*   **フェーズ2:** より詳細なリスク検出（秘密保持、競業避止）、修正案提案、弁護士連携レポート生成。
*   **フェーズ3:** 比較レビュー機能、VTuber特有のリスク分析の強化、AIモデルの継続的な学習。
