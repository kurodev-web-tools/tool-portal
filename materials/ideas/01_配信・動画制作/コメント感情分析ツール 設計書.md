# コメント感情分析ツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが操作するウェブインターフェース。
- **バックエンド（APIサーバー）**: フロントエンドからのリクエストを処理し、AIモデルや外部APIと連携する。
- **AIモデル**: コメントの感情分析を行うコアエンジン。
- **外部API**: YouTube Live Chat APIからコメントデータを取得する。

### PC（ブラウザ）表示
広さのある画面を活かし、グラフや感情ごとのコメント一覧をダッシュボード形式で表示する。リアルタイムでの変動を把握しやすいように、複数の情報を同時に見られるレイアウトを基本とする。

### スマホ表示
画面サイズに合わせて、主要な感情グラフを上部に配置し、その下に感情ごとのコメント一覧がスクロールできるシングルカラムレイアウトを採用する。

## 2. 主要機能詳細

### 2-1. リアルタイム感情分析機能
- **ユーザーアクション**:
    - **配信URL入力**: 分析したいYouTubeライブ配信のURLを入力する。
    - **分析開始**: ボタンをクリックして、リアルタイム分析を開始する。
- **システム動作**:
    1.  バックエンドがYouTube Data APIを通じて、指定された配信のコメントストリームをリアルタイムで取得する。
    2.  取得した各コメントをAIモデルに渡し、感情（例: 喜び、怒り、悲しみ、驚き）を分析・判定する。
    3.  分析結果（感情のスコアやコメント内容）をリアルタイムでフロントエンドに送り、UIのグラフやコメント一覧に反映させる。

### 2-2. 感情トレンド可視化機能
- **ユーザーアクション**:
    - **ダッシュボード閲覧**: 配信中にダッシュボードを開いて、感情の推移を確認する。
- **システム動作**:
    1.  リアルタイムで蓄積された感情分析データを時系列でグラフ化する。
    2.  特定の時間帯で感情が急変した箇所に、その時のコメント内容を紐づけて表示する。これにより、感情の変化の原因を把握できるようにする。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**（自然言語処理モデル）
- **データベース**: **MongoDB**または**PostgreSQL**（リアルタイムデータの保存）
- **外部連携**: **YouTube Data API v3**

## 4. データベース設計
- **Comments**: 取得したコメントの生データと分析結果（感情スコアなど）を保存。
- **AnalysisSessions**: 過去の分析セッション情報（配信ID、開始・終了時間など）を管理。
- **EmotionalTrend**: 感情スコアの時系列データを保存し、グラフ化に利用。
