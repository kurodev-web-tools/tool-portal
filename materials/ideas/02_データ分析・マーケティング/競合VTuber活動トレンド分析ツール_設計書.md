# 競合VTuber活動トレンド分析ツール 設計書

## ツール名
競合VTuber活動トレンド分析ツール

## カテゴリ
02_データ分析・マーケティング

## 目的
VTuberが自身の活動戦略を策定・改善するために、競合VTuberの活動データ、コンテンツ、視聴者層、プロモーション戦略、成長トレンドなどをAIが多角的に分析し、深いインサイトを提供する。これにより、市場の動向を正確に把握し、効果的な差別化戦略と成長戦略の策定を支援する。

## 機能要件
### 1. ユーザー認証・競合VTuber登録
*   VTuberアカウントでのログイン機能
*   分析したい競合VTuberのチャンネルURL（YouTube, Twitchなど）、SNSアカウント（X, TikTokなど）を登録・管理
*   競合VTuberのグループ化機能（例：同ジャンル、同規模）

### 2. 活動データ収集・分析
*   **配信データ:**
    *   配信頻度、配信時間帯、配信ジャンル、使用ゲーム、同時接続者数、視聴回数、コメント数、スパチャ額などの自動収集・分析
    *   ライブ配信のアーカイブデータからの自動要約・キーワード抽出
*   **コンテンツデータ:**
    *   人気動画の傾向、動画タイトル・サムネイルの傾向、動画の長さ、エンゲージメント率（高評価率、コメント率）などの分析
    *   動画内容のAIによる自動分類（ゲーム実況、歌枠、雑談など）
*   **SNSデータ:**
    *   フォロワー数推移、投稿頻度、エンゲージメント率、話題のキーワード、メンション数などの自動収集・分析
    *   SNS投稿内容の感情分析、トーン分析

### 3. 視聴者層分析
*   競合VTuberの視聴者層（年齢、性別、地域、興味関心）を推定・分析（公開されているデータに基づく）
*   自身の視聴者層との比較分析

### 4. 成長トレンド分析
*   チャンネル登録者数、視聴回数、フォロワー数などの推移を時系列で分析し、成長トレンドを可視化
*   成長率、加速/減速の傾向を分析
*   特定のイベント（コラボ、大型企画など）が成長に与えた影響を分析

### 5. プロモーション戦略分析
*   競合VTuberがどのようなプロモーション（コラボ、イベント、SNSキャンペーン、メディア露出など）を行っているかを分析
*   プロモーションと活動指標（登録者数、視聴回数など）の相関分析

### 6. トレンドキーワード分析
*   競合VTuberが使用しているキーワード、動画タイトル、概要欄、SNS投稿内容から、そのジャンルやVTuber界隈で話題になっているキーワードをAIが抽出・分析
*   キーワードの検索ボリューム、競合度、トレンド推移を提示

### 7. 比較分析レポート
*   登録した競合VTuberと自身の活動データを多角的に比較し、強みや弱み、改善点を明確にするレポートを自動生成
*   グラフ、チャート、ヒートマップなどを用いた視覚的なレポート
*   レポートのエクスポート機能（PDF, CSV）

### 8. 戦略提案AI
*   分析結果に基づき、自身の活動戦略（コンテンツジャンル、プロモーション方法、ターゲット層、配信時間帯など）に関する具体的な提案をAIが行う
*   差別化戦略、ニッチ市場開拓、成長加速のためのアクションプランなどを提案

## 非機能要件
*   **性能:** データ収集は定期的に自動実行。分析レポート生成は数分以内。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** 収集データのプライバシー保護。APIキーの安全な管理。
*   **拡張性:** 新しい配信プラットフォーム、SNS、分析指標への対応。AIモデルの更新。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。データ分析の知識が少ないVTuberでも容易に利用できる設計。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **データ収集:** Webスクレイピング、各プラットフォームAPI（YouTube Data API, Twitch API, X APIなど）
*   **データウェアハウス:** BigQuery / Snowflake / PostgreSQL (分析データ蓄積)
*   **データ分析・可視化:** Pandas, NumPy, Matplotlib, Seaborn, Power BI / Tableau (BIツール連携)
*   **AI/MLモデル:** TensorFlow / PyTorch (クラスタリング、トレンド予測、NLP)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`
*   **Competitor:** `id`, `user_id`, `name`, `channel_url`, `sns_accounts` (JSONB)
*   **ActivityData:** `id`, `competitor_id`, `date`, `platform`, `metrics` (JSONB - views, subs, comments, etc.), `content_type`, `game_title`
*   **SnsData:** `id`, `competitor_id`, `date`, `platform`, `metrics` (JSONB - followers, engagement, etc.), `post_content`, `hashtags`
*   **AnalysisReport:** `id`, `user_id`, `report_date`, `report_data` (JSONB), `recommendations` (JSONB)

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **データ収集:** Scrapy, Selenium
*   **データ分析:** Pandas, NumPy
*   **AI/MLライブラリ:** TensorFlow, PyTorch, scikit-learn, Transformers
*   **データベース:** PostgreSQL (DWH)

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 競合VTuber登録、YouTubeチャンネルの基本データ（登録者数、視聴回数）収集・可視化、成長トレンド分析。
*   **フェーズ2:** 配信データ（配信頻度、ジャンル）、コンテンツデータ（人気動画）、SNSデータ（フォロワー数）の収集・分析。比較分析レポートの自動生成。
*   **フェーズ3:** 視聴者層分析、プロモーション戦略分析、トレンドキーワード分析。AIによる戦略提案機能の強化。
