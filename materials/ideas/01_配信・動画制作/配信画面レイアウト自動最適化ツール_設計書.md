# 配信画面レイアウト自動最適化ツール 設計書

## ツール名
配信画面レイアウト自動最適化ツール

## カテゴリ
01_配信・動画制作

## 目的
VTuberのライブ配信において、複数の画面要素（ゲーム画面、VTuberモデル、コメント欄など）をAIが自動で最適に配置し、視認性とデザイン性を向上させる。これにより、VTuberのレイアウト設定負担を軽減し、視聴者にとって見やすく魅力的な配信画面を提供する。

## 機能要件
### 1. ユーザー認証・プロファイル管理
*   VTuberアカウントでのログイン機能
*   配信プロファイル登録（配信ジャンル、VTuberモデル情報、使用ゲームなど）

### 2. 画面要素認識・登録
*   **要素の自動検出:** OBS Studioなどの配信ソフトウェアから、ゲーム画面、VTuberモデル、コメント欄、チャットボックス、ウェブカメラ、テロップなどのソースを自動検出
*   **要素の手動登録:** 自動検出できない要素の手動登録（名称、種類、優先度など）
*   **要素の特性設定:** 各要素の重要度、可変性（サイズ変更可否）、固定位置の有無などを設定

### 3. 自動レイアウト生成
*   **テンプレートベース生成:** 事前に用意されたレイアウトテンプレート（例：ゲーム画面重視、VTuberモデル重視、雑談向け）を選択し、登録された要素を自動配置
*   **AI最適化生成:**
    *   **入力データ:** 配信内容（ゲームのジャンル、現在のゲーム画面、コメント量、VTuberモデルの動き、音声情報など）をリアルタイムで分析
    *   **最適化アルゴリズム:** 視認性（文字の読みやすさ、UIの隠蔽回避）、情報量（必要な情報の表示）、デザインバランス（要素間の余白、配置の美しさ）を評価指標として、最適なレイアウトを自動生成
    *   **制約条件:** ユーザーが設定した要素の固定位置、最小サイズ、最大サイズなどの制約を考慮

### 4. リアルタイム調整
*   **ゲームUI認識:** ゲーム画面内の重要なUI要素（体力バー、マップ、スキルクールダウン、ミニマップなど）をAIがリアルタイムで認識。これらのUIが隠れないように、他の要素（VTuberモデル、コメント欄など）の配置やサイズを自動で微調整
*   **コメント量連動:** 配信中のコメントの量や流速を検知し、コメント欄のサイズや透明度を自動で調整（コメントが多い時に拡大、少ない時に縮小/透明化など）
*   **VTuberの動き連動:** VTuberモデルの動きやポーズ（例：大きく動いた際に他の要素を一時的に縮小）に合わせて、他の要素の配置を微調整
*   **音声連動:** VTuberが話している際に、マイクアイコンを大きく表示するなど、音声情報に連動したレイアウト変化

### 5. 手動調整・プリセット管理
*   自動生成されたレイアウトをVTuberが手動で微調整（ドラッグ＆ドロップ、リサイズなど）
*   調整後のレイアウトをプリセットとして保存・読み込み
*   複数のプリセットを管理し、配信中に切り替え可能

### 6. 配信ソフトウェア連携
*   OBS Studioなどの主要な配信ソフトウェアのAPIと連携し、レイアウト設定を自動で適用
*   OBSのシーン切り替えと連動し、シーンごとに異なるレイアウトを自動適用

### 7. プレビュー機能
*   配信前に生成されたレイアウトをリアルタイムでプレビュー表示
*   異なる解像度やアスペクト比での表示シミュレーション

## 非機能要件
*   **性能:** レイアウト生成およびリアルタイム調整は1秒以内（目標）。低遅延での画面要素認識。
*   **可用性:** 安定した動作、配信中のクラッシュ耐性。
*   **セキュリティ:** 配信画面の内容やVTuberの操作データのプライバシー保護。
*   **拡張性:** 新しい配信ソフトウェア、ゲームタイトル、画面要素への対応。AIモデルの更新。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。配信中でも容易に設定変更できるインターフェース。

## システム構成
*   **クライアントアプリケーション:** デスクトップアプリケーション (Electron, C++ with Qtなど) またはOBSプラグイン
*   **画像認識・解析エンジン:** Python (OpenCV, TensorFlow / PyTorch)
*   **AI/MLモデル:** TensorFlow / PyTorch (オブジェクト検出、セグメンテーション、最適化アルゴリズム)
*   **配信ソフトウェア連携:** OBS Studio WebSocket APIなど
*   **データベース:** SQLite (ローカル設定), PostgreSQL (ユーザープロファイル、プリセット)
*   **クラウドプラットフォーム:** AWS / GCP / Azure (AIモデルの学習、APIホスティング)

## データモデル
*   **User:** `id`, `username`, `email`
*   **StreamProfile:** `id`, `user_id`, `profile_name`, `stream_genre`, `game_title`
*   **ScreenElement:** `id`, `profile_id`, `name`, `type` (game, vtuber_model, chat, comment), `priority`, `current_position`, `current_size`, `is_fixed`
*   **LayoutPreset:** `id`, `profile_id`, `preset_name`, `element_positions` (JSONB), `element_sizes` (JSONB)

## 技術スタック
*   **言語:** Python, C++ (リアルタイム処理部分), JavaScript (Electron)
*   **フレームワーク:** Electron (デスクトップアプリ)
*   **AI/MLライブラリ:** TensorFlow, PyTorch, OpenCV
*   **配信連携:** OBS WebSocket API
*   **データベース:** SQLite

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 画面要素の手動登録、テンプレートベースの自動レイアウト生成、手動調整・保存、OBS連携（シーン切り替え連動）。
*   **フェーズ2:** AI最適化生成（基本的な視認性・デザインバランス考慮）、コメント量連動のリアルタイム調整。
*   **フェーズ3:** ゲームUI認識によるリアルタイム調整、VTuberの動き連動調整、より高度なAI最適化アルゴリズムの導入。
