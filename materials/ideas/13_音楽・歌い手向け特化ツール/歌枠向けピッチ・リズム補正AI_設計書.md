# 歌枠向けピッチ・リズム補正AI 設計書

## ツール名
歌枠向けピッチ・リズム補正AI

## カテゴリ
13_音楽・歌い手向け特化ツール

## 目的
VTuberの歌枠配信において、歌声のピッチとリズムのずれをリアルタイムかつ自然に補正し、歌唱のクオリティを向上させる。これにより、VTuberが自信を持って歌枠配信を行えるように支援し、視聴者にとってより快適で魅力的な音楽体験を提供する。

## 機能要件
### 1. 音声入力・出力設定
*   マイク入力デバイスの選択
*   伴奏音源の入力（ファイルインポート、仮想オーディオデバイスからの入力）
*   補正後の歌声を仮想オーディオデバイスを通じてOBSなどの配信ソフトウェアに出力
*   補正前と補正後の歌声のリアルタイムモニタリング機能（ヘッドホン出力）

### 2. ピッチ検出・補正
*   **リアルタイムピッチ検出:** 入力された歌声の基本周波数（F0）をリアルタイムで高精度に検出
*   **自動ピッチ補正:**
    *   設定された楽曲のキー、スケール（長調、短調など）に基づいて、検出されたピッチのずれを自動で補正
    *   補正の強度（どれだけ目標ピッチに近づけるか）、補正速度（どれくらいの速さで補正するか）を調整可能
    *   ビブラートやしゃくりなどの表現を維持しつつ、不自然な機械音（ケロケロ声）を抑制するAIアルゴリズム
*   **手動ピッチ設定:** 楽曲のキー、スケールをVTuberが手動で設定
*   **キー・スケール自動検出:** 伴奏音源をAIが解析し、楽曲のキーやスケールを自動で推定（オプション）

### 3. リズム検出・補正
*   **リアルタイムリズム検出:** 入力された歌声の音の開始タイミングをリアルタイムで検出
*   **自動リズム補正:**
    *   伴奏音源のテンポや拍子と照合し、歌声のリズムのずれを自動で補正
    *   クオンタイズの細かさ（例：8分音符、16分音符）や補正の強度を調整可能
    *   自然なグルーヴ感を損なわないAIアルゴリズム
*   **手動テンポ・拍子設定:** 楽曲のテンポ（BPM）、拍子をVTuberが手動で設定

### 4. 音声前処理・後処理
*   ノイズリダクション、エコー除去などの入力音声前処理
*   コンプレッサー、リミッター、イコライザーなどの出力音声後処理（オプション）

### 5. 視覚的フィードバック
*   リアルタイムで検出されたピッチと補正後のピッチをグラフなどで視覚的に表示
*   リズムのずれを視覚的に表示

## 非機能要件
*   **性能:** 音声入力から補正後の出力までの遅延は50ms以内（目標）。リアルタイム処理における安定性。
*   **可用性:** 安定した動作、配信中のクラッシュ耐性。
*   **セキュリティ:** 音声データのプライバシー保護。
*   **拡張性:** 新しいピッチ・リズム補正アルゴリズム、AIモデルの追加。対応オーディオインターフェースの拡充。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。歌唱中にVTuberが容易に設定変更できるインターフェース。
*   **互換性:** 主要な配信ソフトウェア（OBS Studio, Streamlabs OBSなど）やオーディオインターフェースとの互換性。

## システム構成
*   **クライアントアプリケーション:** デスクトップアプリケーション (C++ with Qt/WPF, Electronなど)
*   **音声処理エンジン:** C++ / Python (リアルタイム音声処理ライブラリ)
*   **AI/MLモデル:** PyTorch / TensorFlow (ピッチ・リズム補正、自然な歌声生成)
*   **クラウドサービス:** AWS / GCP / Azure (AIモデルの学習、APIホスティング)
*   **データベース:** SQLite (ローカル設定), PostgreSQL (ユーザー設定、カスタムプリセット)

## データモデル
*   **User:** `id`, `username`, `email`
*   **SongSetting:** `id`, `user_id`, `song_name`, `key`, `scale`, `tempo`, `pitch_correction_strength`, `rhythm_correction_strength`
*   **Preset:** `id`, `user_id`, `preset_name`, `settings` (JSONB)

## 技術スタック
*   **言語:** C++ (リアルタイム音声処理), Python (AIモデル開発、バックエンド)
*   **フレームワーク:** PyTorch / TensorFlow (AIモデル)
*   **音声処理ライブラリ:** PortAudio, librosa, Aubio
*   **データベース:** SQLite

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 基本的なリアルタイムピッチ補正（キー・スケール手動設定）、補正強度調整、仮想オーディオデバイス出力。
*   **フェーズ2:** リアルタイムリズム補正、キー・スケール自動検出、ノイズリダクション、視覚的フィードバック。
*   **フェーズ3:** AIによるより自然な歌声生成アルゴリズムの導入、カスタムプリセット管理、詳細な音声後処理機能。
