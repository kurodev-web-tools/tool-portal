# 多言語対応ライブ翻訳オーバーレイ 設計書

## ツール名
多言語対応ライブ翻訳オーバーレイ

## カテゴリ
15_最新技術活用ツール / 01_配信・動画制作

## 目的
VTuberのライブ配信において、言語の壁を取り払い、グローバルな視聴者層へのリーチを最大化する。VTuberの音声をリアルタイムで複数の言語に翻訳し、視聴者が選択可能な字幕としてオーバーレイ表示することで、配信のアクセシビリティと国際的なファンエンゲージメントを向上させる。

## 機能要件
### 1. ユーザー認証・配信連携
*   VTuberアカウントでのログイン機能
*   マイク入力デバイスの選択
*   OBS Studioなどの配信ソフトウェアとの連携（仮想カメラ、ブラウザソースなど）

### 2. リアルタイム音声認識（ASR）
*   VTuberの音声を高精度でリアルタイムにテキスト化
*   話者分離（オプション）
*   ノイズリダクション、エコー除去

### 3. 多言語リアルタイム翻訳
*   音声認識されたテキストを、VTuberが設定した複数のターゲット言語（例：英語、中国語、韓国語、スペイン語、フランス語など）にリアルタイムで翻訳
*   ニューラル機械翻訳（NMT）モデルの利用
*   専門用語、VTuber特有の固有名詞、キャラクターの口調などを学習し、翻訳精度を向上させるカスタム辞書・モデルファインチューニング機能

### 4. 字幕オーバーレイ表示
*   翻訳された字幕を、配信画面上にオーバーレイとして表示
*   **表示形式:**
    *   VTuberが設定した単一言語の字幕を常に表示
    *   複数の言語の字幕を同時に表示（例：日本語と英語）
    *   視聴者がWebベースの視聴ページで言語を選択し、その言語の字幕のみを表示（推奨）
*   **カスタマイズ:** 字幕のフォント、サイズ、色、背景色、透明度、表示位置、表示時間などをVTuberが細かく設定
*   **自動改行・表示調整:** 画面サイズに合わせて字幕が適切に改行され、読みやすいように表示を自動調整

### 5. 翻訳履歴・修正
*   翻訳されたテキストの履歴を保存
*   配信後に翻訳結果を確認し、誤訳があった場合に手動で修正できる機能
*   修正されたデータは翻訳モデルの学習にフィードバック

### 6. 視聴者向けインターフェース（Webベース）
*   VTuberの配信を埋め込み、字幕言語を選択できる専用のWebページを提供
*   選択された言語の字幕がリアルタイムで表示される

## 非機能要件
*   **性能:** 音声入力から字幕表示までの遅延は2秒以内（目標）。翻訳処理の高速性。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** 音声データ、翻訳データのプライバシー保護。APIキーの安全な管理。
*   **拡張性:** 新しい言語、翻訳モデル、配信プラットフォームへの対応。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** VTuberが容易に設定・操作できるインターフェース。視聴者にとっても直感的な字幕選択。

## システム構成
*   **クライアントアプリケーション/サービス:** デスクトップアプリケーション (OBS連携用) またはクラウドサービス
*   **音声認識エンジン:** Google Cloud Speech-to-Text, AWS Transcribe, Azure Speech ServiceなどのAPI利用
*   **翻訳エンジン:** Google Cloud Translation API, DeepL API, AWS Translate, Azure TranslatorなどのAPI利用
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS) (音声・翻訳処理のオーケストレーション、カスタム辞書管理)
*   **データベース:** PostgreSQL / MongoDB (ユーザー設定、カスタム辞書、翻訳履歴)
*   **クラウドプラットフォーム:** AWS / GCP / Azure
*   **字幕配信:** WebSocket (リアルタイム字幕配信)

## データモデル
*   **User:** `id`, `username`, `email`, `hashed_password`, `streaming_platform_credentials`
*   **TranslationSetting:** `id`, `user_id`, `source_language`, `target_languages` (Array), `custom_dictionary` (JSONB), `subtitle_style` (JSONB)
*   **TranslationHistory:** `id`, `user_id`, `timestamp`, `original_text`, `translated_texts` (JSONB), `is_corrected`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **リアルタイム通信:** WebSocket
*   **AI/MLサービス:** 各クラウドプロバイダーのASR/NMT API
*   **データベース:** PostgreSQL

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** VTuberの音声をリアルタイムでテキスト化し、設定された単一のターゲット言語に翻訳、OBSへの字幕オーバーレイ表示。
*   **フェーズ2:** 複数のターゲット言語への同時翻訳、カスタム辞書機能、字幕表示カスタマイズの強化。
*   **フェーズ3:** 視聴者向けWebインターフェースでの言語選択機能、翻訳精度向上学習（フィードバックループ）、他配信プラットフォーム連携。
