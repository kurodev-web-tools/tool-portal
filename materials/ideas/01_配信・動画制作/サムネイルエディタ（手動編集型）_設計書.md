# アプリケーション設計書：サムネイルエディタ（手動編集型）

## 1. 概要

素材持ち込み前提で、16:9サムネイルをブラウザ上で編集・保存・書き出しするフロントエンド完結型ツール。  
MVPでは「文字品質」「レイヤー編集」「実戦プリセット」を中核に設計する。

## 2. 技術スタック

| 分類 | 技術 | 目的 |
| :--- | :--- | :--- |
| フレームワーク | Next.js (App Router) | 既存ポータルとの統合 |
| 言語 | TypeScript | 型安全な描画・状態管理 |
| UI | React | 編集UIの状態同期 |
| スタイリング | Tailwind CSS | 既存デザインシステム準拠 |
| 描画 | HTML Canvas 2D API | エディタプレビューと書き出し |
| データ保存 | localStorage | 下書き保存/復元 |
| フォント | Google Fonts | MVPのフォント供給 |

## 3. アーキテクチャ

- **フロント完結型**: サーバー依存なしで編集〜出力を完結。
- **責務分離**:
  - UI層: ツールパネル、レイヤー一覧、ダイアログ
  - ドメイン層: レイヤー操作、プリセット適用、バリデーション
  - 描画層: Canvas描画順管理
  - 永続化層: localStorage入出力

## 4. データモデル

```ts
type CanvasPresetId = "stream_announce" | "karaoke" | "chatting" | "clip";

type LayerType = "image" | "text" | "shape";
type ShapeType = "rect" | "circle";

interface BaseLayer {
  id: string;
  type: LayerType;
  x: number;
  y: number;
  width: number;
  height: number;
  rotation: number;
  opacity: number; // 0..1
  blur: number; // px
}

interface ImageLayer extends BaseLayer {
  type: "image";
  src: string; // data URL
}

interface TextLayer extends BaseLayer {
  type: "text";
  text: string;
  fontFamily: string;
  fontSize: number;
  lineHeight: number;
  color: string;
  strokeColor: string;
  strokeWidth: number;
  shadowColor: string;
  shadowBlur: number;
  shadowOffsetX: number;
  shadowOffsetY: number;
}

interface ShapeLayer extends BaseLayer {
  type: "shape";
  shapeType: ShapeType;
  fillColor: string;
  strokeColor: string;
  strokeWidth: number;
  borderRadius?: number;
}

type EditorLayer = ImageLayer | TextLayer | ShapeLayer;

interface ThumbnailEditorDraft {
  version: 1;
  canvas: { width: number; height: number };
  presetId: CanvasPresetId;
  layers: EditorLayer[];
  updatedAt: string;
}
```

## 5. コンポーネント構成

| コンポーネント名 | 役割 |
| :--- | :--- |
| `ThumbnailEditorPage` | 画面全体レイアウトと状態統括 |
| `PresetSelector` | プリセット選択/再適用 |
| `EditorCanvas` | Canvas描画と選択操作 |
| `LayerPanel` | レイヤー一覧、順序変更、複製、削除 |
| `PropertyPanel` | 選択レイヤーのスタイル編集 |
| `ExportDialog` | PNG/JPEG書き出し設定 |

## 6. 主要ロジック

### 6.1 描画順

- `layers` 配列の先頭を背面、末尾を前面として描画する。
- 1フレーム内で以下順序を守る:
  1. 背景
  2. 画像レイヤー
  3. 図形レイヤー
  4. テキストレイヤー

### 6.2 プリセット適用

- プリセットは「初期レイヤーセット + スタイル定義」で管理。
- 適用時は既存編集を上書きするため、適用前確認を行う。

### 6.3 保存・復元

- 保存キー: `v-streamer-tools:thumbnail-editor:draft:v1`
- 保存トリガー:
  - 明示保存ボタン
  - 主要変更後の遅延保存（デバウンス）
- 復元時に`version`不一致またはJSON破損なら初期化する。

### 6.4 書き出し

- プレビューと同一描画パイプラインを使い、出力時の見た目差異を防ぐ。
- JPEG時は背景透過不可のため背景色を強制適用する。

## 7. エラーハンドリング

- 画像読み込み失敗: 該当レイヤー追加を中止し通知。
- localStorage容量超過: 保存失敗通知、編集継続。
- 書き出し失敗: 再試行案内を表示。
