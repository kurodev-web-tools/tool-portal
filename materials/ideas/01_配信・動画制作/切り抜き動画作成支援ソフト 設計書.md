# 切り抜き動画作成支援ソフト 設計書

## 1. システム構成図
このツールは、以下の5つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが操作するウェブインターフェース。
- **バックエンド（APIサーバー）**: フロントエンドからのリクエストを処理し、AIモデルや外部APIと連携する。
- **AIモデル**: 動画の盛り上がりシーンを検出し、字幕を自動で生成するコアエンジン。
- **外部API**: YouTube Data APIから動画データやコメントを取得する。
- **動画処理サーバー**: アップロードされた動画や音声を処理し、エンコードや編集を行う。

### PC（ブラウザ）表示
長尺の配信アーカイブのタイムラインを上部に配置し、AIが検出したハイライトシーンのリストとプレビューを下に表示するレイアウトを基本とする。字幕の編集画面は、タイムラインと同期した専用のパネルで表示する。

### スマホ表示
画面サイズに合わせて、動画のプレビューを上部に、ハイライトシーンのリストをスクロール可能な形式で下部に配置する。編集機能は、タップやスワイプで直感的に操作できるように設計する。

## 2. 主要機能詳細

### 2-1. 盛り上がりシーン自動検出機能
- **ユーザーアクション**:
    - **動画URL入力**: 切り抜きを生成したいYouTubeアーカイブのURLを入力する。
- **システム動作**:
    1.  バックエンドがYouTube Data APIを通じて、指定された動画のデータ（動画本体、コメント、音声など）を取得する。
    2.  AIモデルが以下のデータを解析し、動画内の盛り上がりシーンを検出する。
        - **コメントの急増**: 短時間でコメント数が急増した箇所を検出。
        - **スパチャ・メンバーシップ**: スパチャやメンバーシップ加入があった時間帯を検出。
        - **音声分析**: 笑い声や声のトーンの変化を分析。
    3.  検出されたシーンの開始・終了時間を特定し、フロントエンドにリストとして返す。

### 2-2. クリップ自動生成＆編集機能
- **ユーザーアクション**:
    - **ハイライトシーン選択**: 検出されたリストから、切り抜きたいシーンを選ぶ。
    - **編集**: 自動生成された字幕を修正したり、不要な部分をカットしたりする。
    - **出力**: 任意の尺（例: 15秒、60秒）で出力形式を選択し、ダウンロードをリクエストする。
- **システム動作**:
    1.  ユーザーが選択したシーンと編集内容をバックエンドが受け取る。
    2.  動画処理サーバーが、元の動画から指定された部分を切り抜き、字幕を自動で焼き付ける。
    3.  指定されたフォーマット（例: MP4）で動画をエンコードし、ダウンロードリンクを生成する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**（自然言語処理、音声認識モデル）
- **データベース**: **MongoDB**または**PostgreSQL**
- **外部連携**: **YouTube Data API v3**、**FFmpeg**（動画・音声処理）

## 4. データベース設計
- **Videos**: 処理対象となる動画の情報管理
- **Highlights**: AIが検出したハイライトシーンの情報（タイムスタンプ、検出理由など）
- **Users**: ユーザー情報管理
- **GeneratedClips**: 生成された切り抜き動画の情報（元の動画ID、尺、生成日時など）
