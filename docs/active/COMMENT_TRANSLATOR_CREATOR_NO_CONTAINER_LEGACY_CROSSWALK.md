## Rejected Implementation Boundary

次はlegacy requirementではなく、明示的に廃棄するrejected implementationである。

- Cloudflare Container、Dockerfile/image、managed Container Registry、Container binding、Container Durable Object、paid Container permission;
- Worker→Container RPC/stream、single-use child process、parent/child Buffer zero-fill、image execution proof、image retention rollback;
- Container availability/cost/permission/deploymentを前提にしたC1/CP1 approval units、contract、authority、migration/configuration;
- 旧コードが存在・merge・local proofされたこと自体を新設計のfeasibility proofにすること。

新設計が保持するのは、server-only credentials、signed billing evidence、durable entitlement、atomic usage、browser-safe output、fail-closed、no raw private payload persistenceというユーザー/security要件だけである。
