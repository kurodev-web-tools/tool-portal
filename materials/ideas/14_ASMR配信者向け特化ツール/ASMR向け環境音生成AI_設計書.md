# ASMR向け環境音生成AI 設計書

## ツール名
ASMR向け環境音生成AI

## カテゴリ
14_ASMR配信者向け特化ツール

## 目的
ASMR配信において、VTuberが特定のシチュエーションに合わせた高品質な環境音をAIにより効率的に生成・調整できるようにする。これにより、配信の没入感を高め、多様なASMRコンテンツの制作を支援し、VTuberの表現の幅を拡大する。

## 機能要件
### 1. ユーザー認証・プロファイル管理
*   VTuberアカウントでのログイン機能
*   ASMR配信プロファイル登録（得意なASMRジャンル、使用機材など）

### 2. 環境音生成インターフェース
*   **テキストプロンプト入力:** ユーザーが生成したい環境音のテキスト記述を入力（例：「雨の降る森の夜」「静かなカフェの片隅」「焚き火の燃える音」）
*   **カテゴリ・タグ選択:** 事前定義されたカテゴリ（例：自然、都市、室内、ファンタジー）やタグ（例：リラックス、集中、睡眠、ASMRトリガー）からの選択
*   **音源パラメータ調整:**
    *   音量、残響（リバーブ）、エコー、ディレイなどの空間エフェクト調整
    *   特定の音要素の強調・抑制（例：雨の強さ、風の音の有無、人の声の有無）
    *   音源の複雑さ、密度調整
*   **バイノーラル設定:** 生成される音源がバイノーラル録音のように空間的な広がりを持つように調整（左右の音量差、位相差など）

### 3. 音源生成エンジン
*   入力されたプロンプト、カテゴリ、パラメータなどに基づき、AIモデルが環境音を生成
*   **Text-to-Audioモデル:** 既存の音声生成AIモデル（例：GAN, VAE, Diffusion Modelベース）をASMR向けにファインチューニングまたはAPI利用
*   **リアルタイム生成/プリレンダリング:** 短いループ音源はリアルタイム生成、長尺の複雑な音源はプリレンダリング

### 4. リアルタイム再生・ループ
*   生成された環境音をリアルタイムで再生
*   シームレスなループ再生機能
*   複数の環境音をレイヤーとして重ねて再生し、それぞれの音量やエフェクトを個別に調整

### 5. プリセット管理
*   生成・調整した環境音のプリセットを保存・読み込み
*   コミュニティでのプリセット共有機能（オプション）

### 6. 配信ソフトウェア連携
*   生成された環境音を仮想オーディオデバイスを通じてOBSなどの配信ソフトウェアに出力
*   音量ミキサー機能（環境音とVTuberの音声のバランス調整）

## 非機能要件
*   **性能:** 環境音生成は数秒以内（目標）。リアルタイム再生時の低遅延（目標50ms以内）。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** ユーザーの入力データ、生成音源のプライバシー保護。
*   **拡張性:** 新しい音声生成モデル、音源パラメータ、カテゴリの追加に対応できるアーキテクチャ。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。配信中でも容易に設定変更できるインターフェース。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **音声生成AI:** クラウドベースのAIサービスAPI利用または、自社サーバーでのGPUインスタンスによるモデルホスティング
*   **音声処理ライブラリ:** Librosa, PyAudio, PortAudio
*   **データベース:** PostgreSQL / MongoDB (ユーザーデータ、生成履歴、プリセット)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`
*   **EnvironmentSound:** `id`, `user_id`, `prompt_text`, `category`, `parameters` (JSONB), `audio_file_url`, `generated_at`, `is_favorite`
*   **Preset:** `id`, `user_id`, `preset_name`, `sound_settings` (JSONB)

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AIライブラリ:** PyTorch / TensorFlow (自社ホスティングの場合)
*   **音声処理:** Librosa, PortAudio
*   **データベース:** PostgreSQL

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** テキストプロンプトからの基本的な環境音生成、リアルタイム再生・ループ、音量調整、仮想オーディオデバイス出力。
*   **フェーズ2:** カテゴリ・タグ選択、複数の音源レイヤー、基本的な音源パラメータ調整、プリセット管理。
*   **フェーズ3:** バイノーラル設定の強化、より高度な音源パラメータ調整、コミュニティ共有機能。
