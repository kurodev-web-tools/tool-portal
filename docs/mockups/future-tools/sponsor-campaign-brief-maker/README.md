## Direction Memo

- 想定ユーザー: 案件配信やタイアップ用の要件、訴求、素材、表記を整理したい VTuber / 配信者。
- 主要 workflow: campaign goal、deliverables、talking points、disclosure note、素材 checklist、review state をまとめ、brief として copy / export する。
- 強み: creator business tool として差別化しやすく、legal foundation や media kit 候補との接続も説明しやすい。
- 実装リスク: 契約、支払い、広告表記、成果計測、第三者確認まで扱うと legal / billing / analytics の境界が大きくなる。
- 既存ツールとの接続点: Vtuber Profile / Media Kit Generator、legal foundation、Thumbnail Editor export、account / monetization later scope。
