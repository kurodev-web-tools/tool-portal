# 同期歌詞・コード譜プロンプター

## 1. ツールの目的・概要
- **目的**: 歌枠や弾き語り配信を行うVTuber向けに、演奏する音源と同期して歌詞やコード譜を自動でスクロール表示するプロンプターツール。
- **ターゲット**: 歌枠、弾き語り、楽器演奏などを配信する音楽系VTuber。
- **価値**: 歌詞やコードの間違いを防ぎ、パフォーマーがより安心して演奏に集中できる環境を提供する。また、視聴者側にもデザインされた歌詞を表示することで、カラオケのような一体感や、より深い音楽体験を創出する。

## 2. 主要な機能
- **音源・歌詞・コード譜の同期**: 楽曲の音源（MP3, WAV）をアップロードすると、その波形やBPMを解析。テキストで入力した歌詞やコード譜とタイミングを合わせ、自動でタイムタグを付与する。
- **自動スクロールプロンプター**: 配信時、音源の再生に合わせて、設定したタイムタグ通りに歌詞やコードがリアルタイムでハイライト・スクロールする。
- **多彩なオーバーレイ表示**: 配信画面にオーバーレイ表示するための、カスタマイズ可能なデザインテンプレートを多数用意。フォント、色、背景などを自由に調整できる。
- **MIDI連携**: MIDIキーボードなどの演奏とリアルタイムで同期し、弾いたコードをハイライトする機能。
- **セットリスト管理**: 配信で演奏する楽曲のリストを作成し、曲順の入れ替えや、曲ごとの設定を保存できる。

## 3. 技術的な側面
- **音声解析**: Web Audio APIなどを用いて、音源の波形、BPM、ビートを解析し、同期のタイミングを自動で提案する。
- **リアルタイム処理**: 低遅延での同期を実現するため、WebSocketや正確なタイマー処理が必要。
- **レンダリング**: 配信ソフト（OBSなど）にブラウザソースとして取り込めるよう、HTML/CSS/JavaScriptでオーバーレイ画面を描画する。
- **MIDI対応**: Web MIDI APIを利用して、MIDIデバイスからの入力を受け取る。

## 4. 収益モデル
- **月額課金モデル**: 無料プランでは登録できる楽曲数や、利用できるデザインテンプレートに制限を設ける。有料プランでは、無制限の楽曲登録、全テンプレートの利用、MIDI連携機能などを提供する。

## 5. 開発ロードマップ
- **MVP（第一段階）**: 音源と歌詞の同期、基本的な自動スクロール機能、数種類のオーバーレイテンプレートに絞って開発。
- **第二段階**: コード譜への対応と、セットリスト管理機能を追加。
- **第三段階**: MIDI連携機能、より高度なデザインカスタマイズ機能、主要なカラオケ音源サービスとの連携などを実装。
