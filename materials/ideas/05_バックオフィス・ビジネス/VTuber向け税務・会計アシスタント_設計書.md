# VTuber向け税務・会計アシスタント 設計書

## ツール名
VTuber向け税務・会計アシスタント

## カテゴリ
05_バックオフィス・ビジネス

## 目的
VTuberの複雑な収入・支出管理と確定申告業務を効率化し、税務リスクを低減する。AIによる自動分類、レポート生成、税務Q&A機能を提供することで、VTuberが本業に集中できる環境を整備し、安心して活動を継続できるように支援する。

## 機能要件
### 1. ユーザー認証・アカウント管理
*   VTuberアカウントでのログイン機能
*   銀行口座、クレジットカード、各プラットフォーム（YouTube, BOOTHなど）との連携設定

### 2. 収入・支出データ連携・入力
*   **自動連携:**
    *   銀行API（Open Banking APIなど）を通じた入出金明細の自動取得
    *   クレジットカード明細の自動取得
    *   YouTube API（広告収入、スーパーチャット、メンバーシップ収益）からの自動取得
    *   主要グッズ販売プラットフォーム（BOOTH, PixivFANBOXなど）からの売上データ自動取得
*   **手動入力:** 自動連携できない収入・支出（例：現金取引、イベント出演料）の手動入力フォーム
*   **レシート・領収書OCR:** スマートフォンカメラなどで撮影したレシートや領収書の画像から、日付、金額、品目などをOCRで自動読み取りし、データ化

### 3. 勘定科目自動分類
*   入力された収入・支出データを、AIが税務上の適切な勘定科目（例：売上、消耗品費、通信費、交通費、会議費、接待交際費など）に自動で分類
*   VTuber特有の勘定科目（例：モデル制作費、配信機材費、衣装費、配信ツール利用料）に対応
*   ユーザーによる手動修正・学習機能（AIの分類精度向上）

### 4. 収支レポート・可視化
*   月次・年次の損益計算書、貸借対照表（簡易版）を自動生成
*   収益源別、費用項目別の内訳をグラフ（棒グラフ、円グラフ）や表で可視化
*   期間指定、フィルタリング機能

### 5. 確定申告書類作成支援
*   青色申告決算書、所得税確定申告書（第一表、第二表）の作成に必要なデータを自動集計し、出力
*   e-Tax連携（電子申告）のためのデータ出力形式対応
*   必要書類のチェックリスト、提出期限リマインダー

### 6. 税務Q&Aチャットボット
*   税務に関する一般的な質問や、VTuber特有の税務に関する質問（例：機材費の減価償却、交際費の範囲）にAIチャットボットが回答
*   税法改正情報などの自動更新

### 7. 税理士連携
*   提携税理士への相談窓口提供
*   会計データ（CSV, 弥生会計形式など）のエクスポート機能

### 8. 領収書・請求書管理
*   領収書や請求書の画像データをアップロードし、デジタルで一元管理
*   データと紐付け、検索・閲覧機能

## 非機能要件
*   **性能:** データ連携は日次で自動実行。レポート生成は数秒以内。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** 機密性の高い財務データ、個人情報、金融機関連携情報は厳重に暗号化され、保護されること。二段階認証。
*   **拡張性:** 新しい金融機関、プラットフォーム、税法改正への対応。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。税務知識がなくても操作しやすい設計。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **データ連携:** 各金融機関API, 各プラットフォームAPI, Webスクレイピング
*   **OCRエンジン:** Google Cloud Vision AI, AWS TextractなどのAPI利用
*   **AI/MLモデル:** Hugging Face Transformers (NLP), scikit-learn (分類)
*   **データベース:** PostgreSQL (取引データ、勘定科目、ユーザー設定)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (領収書画像など)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`, `hashed_password`, `tax_info`
*   **AccountLink:** `id`, `user_id`, `platform_type`, `credentials` (encrypted)
*   **Transaction:** `id`, `user_id`, `date`, `amount`, `type` (income/expense), `description`, `source_account`, `category_id`, `receipt_url`
*   **Category:** `id`, `name`, `tax_code`
*   **Report:** `id`, `user_id`, `period`, `type` (P/L, B/S), `data` (JSONB)

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** Transformers, NLTK, spaCy
*   **データベース:** PostgreSQL
*   **ストレージ:** AWS S3

## 開発ロードマップ（簡易版）

*   **フェーズ3:** クレジットカード連携、税理士連携機能、領収書・請求書管理の強化、e-Tax連携。
