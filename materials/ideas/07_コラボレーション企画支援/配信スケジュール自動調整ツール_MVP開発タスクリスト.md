# 配信スケジュール自動調整ツール MVP開発タスクリスト

## 概要
このタスクリストは、「配信スケジュール自動調整ツール」のMVP（Minimum Viable Product）を開発するためのものです。
このツールは、複数人でのコラボ配信などの日程調整を自動化することを目的とします。

---

## MVP開発タスクリスト

- **T-01: 基本的なページ構造のセットアップ**
    - [x] `vtuber-tools-portal` プロジェクト内に、ツール用の新しいルートを作成する (`/tools/schedule-adjuster`)。
    - [x] `page.tsx` ファイルを作成し、基本的なコンポーネントを配置する。
    - [x] このツールは単一のダッシュボード形式で機能するため、7:3の固定レイアウトは採用せず、より柔軟なレイアウトを検討する。

- **T-02: プロジェクト管理機能（フロントエンド）**
    - [x] **プロジェクト作成UI:**
        - [x] 「新規プロジェクト作成」ボタンを配置する。
        - [x] ボタンクリックで表示されるモーダルダイアログ内に、「プロジェクト名」「概要」「所要時間」の入力フォームを作成する。
    - [x] **プロジェクト一覧UI:**
        - [x] ユーザーが関わるプロジェクトをカード形式で一覧表示するエリアを作成する。
        - [x] 各カードにはプロジェクト名、参加者アイコン、ステータス（調整中/確定済み）を表示する。

- **T-03: プロジェクト詳細画面（フロントエンド雛形）**
    - [x] プロジェクトカードクリックで遷移する詳細ページの雛形を作成する。
    - [x] **参加者エリア:**
        - [x] 参加者のアイコンと名前を一覧表示する。
        - [x] 各参加者のカレンダー連携状態（未連携/連携済み）を示すインジケーターを配置する。
        - [x] 「招待リンクをコピー」ボタンを配置する。
    - [x] **カレンダー連携/入力エリア:**
        - [x] 「Googleカレンダーを連携」ボタンを配置する。
        - [x] 「空き時間を手入力する」ボタンを配置する。
    - [x] **空き時間表示エリア:**
        - [x] 「空き時間を探す」ボタンを配置する。
        - [x] ボタンクリック後に、タイムグリッド形式のカレンダーが表示されるプレースホルダーを配置する。色分け（全員OK/一部OK/NG）が分かるように静的なスタイルを適用しておく。

- **T-04: バックエンドとの連携（BaaSを利用した低コスト実装）**
    - [ ] **データベース設計:**
        - [ ] Supabase/Firebase等に `projects` と `participants` テーブル（またはコレクション）を設計する。
        - [ ] `projects`: `id`, `name`, `description`, `duration`
        - [ ] `participants`: `id`, `project_id`, `user_id`, `status`
    - [ ] **API実装:**
        - [ ] プロジェクトの作成、一覧取得、詳細取得を行うためのAPI（またはBaaSの関数）を実装する。
        - [ ] 招待リンクに対応するロジック（実際にはプロジェクトIDを共有するだけでも可）を実装する。
    - [ ] **フロントエンド接続:**
        - [ ] プロジェクトの作成・一覧表示機能をバックエンドと接続する。

- **T-05: Googleカレンダー連携と空き時間算出（※要API利用）**
    - [ ] **バックエンド:**
        - [ ] Google Calendar APIのOAuth認証フローを実装する。
        - [ ] ユーザーから取得したアクセストークンを安全にDBに保存する。
        - [ ] 複数の参加者のカレンダーから予定（busyな時間帯）を読み取る処理を実装する。
        - [ ] 全員の予定を突き合わせ、共通の空き時間（freeな時間帯）を算出するコアロジックを実装する。
    - [ ] **フロントエンド:**
        - [ ] 「Googleカレンダーを連携」ボタンにOAuthフローを開始する処理を接続する。
        - [ ] 「空き時間を探す」ボタンでバックエンドの空き時間算出APIを呼び出し、結果をタイムグリッドカレンダーに動的に描画する。

- **T-06: 日程確定機能（※要API利用）**
    - [ ] **バックエンド:**
        - [ ] 確定した日時を、参加者（Googleカレンダー連携済み）のカレンダーに新しい予定として書き込むAPIを実装する。
    - [ ] **フロントエンド:**
        - [ ] ユーザーが空き時間（緑色のセル）をクリックした際に、確認モーダルを表示する。
        - [ ] 「確定」ボタンでバックエンドの予定書き込みAPIを呼び出し、成功/失敗のメッセージを表示する。
