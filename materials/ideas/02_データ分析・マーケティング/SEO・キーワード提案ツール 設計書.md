# SEO・キーワード提案ツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーがキーワードを検索し、提案結果を閲覧するインターフェース。
- **バックエンド（APIサーバー）**: キーワード検索やデータ分析を管理する。
- **AIモデル**: キーワードの関連性分析や、タイトルの最適化を提案する。
- **外部API**: YouTube Data APIや、Google Search Console APIなどからデータを取得する。

### PC（ブラウザ）表示
キーワード検索窓を中央に配置し、検索結果としてキーワードの検索ボリューム、関連キーワード、競合情報を分かりやすいグラフやテーブルで表示する。複数のキーワードを並べて比較できるレイアウトを基本とする。

### スマホ表示
検索窓を上部に配置し、結果を縦にスクロールして見られるシングルカラムレイアウトを採用する。重要なデータ（検索ボリューム、トレンドなど）は、一目で分かるように大きな文字やグラフで表示する。

## 2. 主要機能詳細

### 2-1. キーワード分析・提案機能
- **ユーザーアクション**:
    - **キーワード入力**: 分析したいキーワード（例：「Vtuber 歌ってみた」）を入力する。
- **システム動作**:
    1.  バックエンドがユーザーの入力したキーワードを受け取る。
    2.  YouTube Data APIやGoogle Search Console APIを通じて、そのキーワードの月間検索ボリューム、トレンド、関連キーワードデータを取得する。
    3.  AIモデルが、取得したデータを基に、より効果的な関連キーワードや、タイトル・タグの提案を生成する。
    4.  生成された提案を、検索ボリュームなどのデータと合わせてUIに表示する。

### 2-2. 競合キーワード分析機能
- **ユーザーアクション**:
    - **競合チャンネル登録**: 競合となるVTuberのチャンネルを登録する。
- **システム動作**:
    1.  バックエンドが登録された競合チャンネルの動画データを定期的に取得する。
    2.  AIモデルが、競合チャンネルの動画タイトルやタグを分析し、どのキーワードで上位表示されているかを特定する。
    3.  その結果をユーザーのUIに表示し、自身のSEO対策に役立てられるようにする。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**Scikit-learn**（クラスタリング、回帰モデル）、**TensorFlow**（自然言語処理）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**Google Search Console API**など

## 4. データベース設計
- **Users**: ユーザー情報管理
- **KeywordData**: キーワードの検索ボリュームやトレンドデータを保存
- **CompetitorChannels**: 登録された競合チャンネルの情報管理
- **CompetitorVideos**: 競合チャンネルの動画データと、そこから抽出されたキーワードを管理、**Google Search Console API**など
