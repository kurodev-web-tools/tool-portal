# VTuber活動バックオフィス自動化システム 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが収益や経費を管理するダッシュボード。
- **バックエンド（APIサーバー）**: 外部APIからのデータ取得、集計、レポート生成を管理する。
- **AIモデル**: 領収書からのテキスト抽出（OCR）や、経費の自動分類を行う。
- **外部API**: YouTube、FANBOX、BOOTHなどのプラットフォームからデータを取得する。

### PC（ブラウザ）表示
複数の収益源と経費を一元的に管理するダッシュボードを主体とする。グラフやテーブルを多用し、収支の状況が一目でわかるレイアウトを基本とする。

### スマホ表示
画面サイズに合わせて、主要な収益と支出のサマリーを上部に表示し、詳細なデータは縦にスクロールして見られるようにする。経費の登録は、カメラ機能を利用して簡単に行えるようにする。

## 2. 主要機能詳細

### 2-1. 収益・経費自動管理機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTubeなどのプラットフォームアカウントを連携させる。
    - **経費登録**: 領収書の写真をアップロードし、経費を登録する。
- **システム動作**:
    1. バックエンドが各プラットフォームのAPIを通じて、収益データを定期的に自動で取得し、データベースに保存する。
    2. ユーザーがアップロードした領収書画像は、AIモデルがOCRでテキストを抽出し、日付、金額、品目を自動でデータ化する。
    3. 経費データはAIモデルが自動でカテゴリ分類し、収支を計算する。

### 2-2. 財務レポート生成機能
- **ユーザーアクション**:
    - **レポート生成**: 期間を指定して、収支レポートや税務申告に必要なレポートを生成する。
- **システム動作**:
    1. バックエンドがデータベースに蓄積された収益・経費データを集計する。
    2. 確定申告に必要な項目（収入、必要経費など）を自動で計算し、指定されたフォーマットでレポートを出力する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**（OCR、分類モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**FANBOX API**など。

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Revenues**: 収益データ管理（プラットフォーム、金額、日付など）。
- **Expenses**: 経費データ管理（金額、カテゴリ、日付、領収書画像URLなど）。
- **Reports**: 生成された財務レポートの履歴管理。
