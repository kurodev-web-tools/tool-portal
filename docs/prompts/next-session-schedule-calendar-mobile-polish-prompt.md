前提:
- 既存の Schedule Calendar は機能実装済み（追加/編集/削除/復元/投稿補助）
- 今回は機能追加よりもモバイルUXの磨き込みを優先
- 技術スタックは `Next.js + React + TypeScript + Tailwind CSS`
- `localStorage` 仕様と保存キー互換は維持する

今回の目的:
- モバイルで `月 / 週 / 日` の各表示を、役割分担が明確なUIにする
- `予定管理 / 投稿補助` パネルと主要アクションの到達性を改善する
- セルタップ導線と新規追加導線を両立する

実装要件:
1) モバイル月表示
- 月グリッドは可読性を優先し、1セルあたりの表示は主予定1件+残件表示（例 `+2件`）まで
- 今日と選択日を明確に区別
- セルタップで対象日を選択し、下段の予定管理領域に反映
- 新規追加は FAB でも起動可能にする（セルタップ導線と併用）

2) モバイル週表示
- 週ストリップ（7日）を常時把握できる形で表示
- メインは選択日の時間軸+予定ブロックを優先
- 予定管理/投稿補助は下段タブで切替し、主要操作（保存/コピー/Xで開く）が届く配置にする

3) モバイル日表示
- 1日の時間軸を主役にし、予定ブロックの読みやすさを優先
- 長文フォームはセクション分割し、入力中も主要アクションへ到達可能にする
- 投稿補助タブのプレビューと操作ボタンを視線移動少なく配置

4) 共通導線（モバイル）
- `日付セル/時間セルタップ` で文脈付き編集を開始できる
- `FAB` は新規予定作成専用導線として常時表示
- 予定ブロックタップは編集モードで開く
- コピー失敗時フォールバック（手動コピー案内）は維持
