# NFTコンテンツ発行・管理ツール 設計書

## ツール名
NFTコンテンツ発行・管理ツール

## カテゴリ
15_最新技術活用ツール

## 目的
VTuberが自身のデジタルコンテンツをNFTとして容易に発行・販売・管理できるようにする。ブロックチェーン技術を活用し、コンテンツの希少性、所有権、真正性を保証することで、VTuberの新たな収益源を創出し、ファンとの新しい関係性を構築する。

## 機能要件
### 1. ユーザー認証・ウォレット連携
*   VTuberアカウントでのログイン機能
*   MetaMaskなどの主要な暗号資産ウォレットとの連携（WalletConnectなど）
*   ウォレットアドレスの表示と管理

### 2. コンテンツアップロード・NFT化
*   画像（JPG, PNG, GIF）、動画（MP4, MOV）、音声（MP3, WAV）、3Dモデル（GLB, VRM）など、様々なデジタルコンテンツのアップロード
*   **NFTメタデータ入力:**
    *   タイトル、説明、カテゴリ、タグ
    *   プロパティ（例：キャラクター名、衣装、背景など）
    *   ロイヤリティ設定（二次流通時のVTuberへの還元率）
    *   供給量（エディション数）
*   **コンテンツのIPFS保存:** アップロードされたコンテンツをIPFS（InterPlanetary File System）などの分散型ストレージに保存し、コンテンツの永続性と耐検閲性を確保

### 3. NFT発行（ミント）
*   **ブロックチェーン選択:** NFTを発行するブロックチェーン（例：Ethereum, Polygon, Flow, Solanaなど）を選択
*   **スマートコントラクト:** ツールが提供する標準的なNFTスマートコントラクト（ERC-721, ERC-1155など）を利用、またはVTuberが自身のカスタムコントラクトをデプロイ（オプション）
*   **ガス代表示:** NFT発行にかかるガス代（手数料）を事前に表示
*   **発行実行:** 簡単な操作でNFTを発行（ミント）し、VTuberのウォレットに紐付け

### 4. マーケットプレイス連携・販売
*   OpenSea, Rarible, Foundationなどの主要NFTマーケットプレイスとのAPI連携
*   **出品機能:**
    *   NFTの出品（固定価格販売、オークション）をツール内から簡単に行える
    *   出品価格、期間、販売形式の設定
*   **販売状況管理:** 出品中のNFTの状況、売上、ロイヤリティ収入などを一元管理
*   **売上・ロイヤリティ自動分配:** NFTが二次流通するたびに、スマートコントラクトにより設定されたロイヤリティがVTuberのウォレットに自動で分配される仕組み

### 5. ファン向けギャラリー・コレクション
*   VTuberが発行したNFTを一覧表示する専用ギャラリーページ（Webサイト）
*   ファンが購入したNFTを管理・閲覧できるコレクション機能（ウォレット連携）
*   NFTの真正性確認機能

### 6. コミュニティ機能（オプション）
*   NFT保有者限定のコミュニティ（Discord連携など）へのアクセス機能
*   NFT保有者限定のコンテンツ（動画、音声、イベント参加権など）へのアクセス機能

## 非機能要件
*   **性能:** NFT発行は数分以内。マーケットプレイスとの同期はリアルタイムまたは数分以内。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** ウォレットの秘密鍵管理、トランザクションの安全性、コンテンツの著作権保護。暗号資産の管理。
*   **拡張性:** 新しいブロックチェーン、NFT規格、マーケットプレイス、コンテンツ形式への対応。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。ブロックチェーンやNFTの知識がないVTuberでも容易に利用できる設計。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Node.js (NestJS) / Python (FastAPI)
*   **ブロックチェーン連携:** Web3.js / Ethers.js (スマートコントラクト操作、トランザクション送信)
*   **IPFSクライアント:** Pinata / Infura IPFS API
*   **NFTマーケットプレイスAPI:** OpenSea API, Rarible APIなど
*   **データベース:** PostgreSQL / MongoDB (ユーザーデータ、コンテンツメタデータ、販売履歴)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (一時的なコンテンツ保存)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`, `wallet_address`
*   **NFTCollection:** `id`, `user_id`, `contract_address`, `chain_id`, `name`, `symbol`
*   **NFTItem:** `id`, `collection_id`, `token_id`, `ipfs_uri`, `metadata` (JSONB), `royalty_percentage`, `current_owner_address`, `status` (minted, listed, sold)
*   **Transaction:** `id`, `nft_item_id`, `type` (mint, list, sale), `from_address`, `to_address`, `amount`, `timestamp`, `tx_hash`

## 技術スタック
*   **言語:** TypeScript / Python
*   **フレームワーク:** Next.js / NestJS
*   **ブロックチェーン:** Web3.js / Ethers.js
*   **IPFS:** Pinata SDK
*   **データベース:** PostgreSQL

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** Ethereum/PolygonチェーンでのNFT発行（ERC-721）、画像/動画コンテンツのIPFS保存、OpenSeaへの出品（固定価格販売）、基本的な販売状況管理。
*   **フェーズ2:** ERC-1155対応、音声/3Dモデルコンテンツ対応、オークション形式での出品、ロイヤリティ自動分配機能。
*   **フェーズ3:** ファン向けギャラリー・コレクション機能、コミュニティ機能（NFT保有者限定アクセス）、他のブロックチェーン/マーケットプレイス連携。
