# バーチャル背景自動生成AI MVP開発タスクリスト

## 概要
このタスクリストは、「バーチャル背景自動生成AI」の雛形（フロントエンドの骨格）およびMVP（Minimum Viable Product）を開発するためのものです。
AIによる画像生成を中核とするため、雛形フェーズではUIの構築に専念し、MVPフェーズでAI連携を行います。

---

## 雛形フェーズ（コストゼロでの実装範囲）
**目標:** AIやバックエンドのロジックなしで、ツールの主要なUIコンポーネントを静的に構築する。

- **T-01: 基本的なページ構造のセットアップ**
    - [x] `vtuber-tools-portal` プロジェクト内に、ツール用の新しいルートを作成する (`/tools/virtual-background-generator`)。
    - [x] `page.tsx` ファイルを作成し、基本的なコンポーネントを配置する。
    - [x] `shadcn/ui` の `Resizable` コンポーネントなどを使用し、左7割（プレビューエリア）と右3割（コントロールパネルエリア）のレイアウトを実装する。
    - [x] レスポンシブ対応（デスクトップ・タブレット・モバイル）の基本構造を実装する。

- **T-02: コントロールパネルのUI作成**
    - [x] 右側のパネルに、背景を生成するためのフォームを配置する。
        - [x] **テキストプロンプト:** `Textarea` コンポーネントを配置（プレースホルダー例：「サイバーパンク都市の夜景」「森の中のカフェ」）。
        - [x] **カテゴリ・タグ選択:** `ToggleGroup` や `Badge` コンポーネントで「ファンタジー」「SF」「日常」「自然」などのカテゴリを選択可能にする。
        - [x] **スタイル選択:** `Select` コンポーネントで「アニメ風」「油絵風」「水彩画風」「リアル」などのスタイルを選択可能にする。
        - [x] **解像度・アスペクト比:** `Select` コンポーネントで「1920x1080 (16:9)」「3840x2160 (4K)」「1080x1920 (9:16)」などのプリセットを選択可能にする。
        - [x] **生成枚数:** `Select` コンポーネントで「1枚」「2枚」「4枚」「8枚」を選択可能にする。
    - [x] フォームの下に「生成する」ボタンを配置（機能は未実装）。
    - [x] 「外部素材から探す」タブまたはボタンを配置する。
    - [x] 「履歴」タブを追加し、過去の生成履歴を表示するUIを準備する。

- **T-03: プレビューエリアのUI作成**
    - [x] 左側のエリアに、生成された画像が表示されることを想定したプレースホルダーを配置する。
    - [x] 画像が複数生成された場合を想定し、グリッドレイアウトで静的なプレースホルダー画像を最大8つまで表示できるようにする。
    - [x] 各画像には、クリックで拡大表示されること、およびダウンロードボタンが付随することを想定したUIを作成する。
    - [x] 画像の拡大表示モーダルを実装する。
    - [x] 画像の基本編集機能（明るさ、コントラスト、色合い調整）のUIを実装する。

- **T-04: 外部素材検索画面のUI作成**
    - [x] 「外部素材から探す」をクリックした際に表示されるモーダルまたは別画面のUIを作成する。
    - [x] `Input`（キーワード入力）と「検索」ボタンを配置。
    - [x] 検索結果がグリッド表示されるエリアをプレースホルダーとして作成する。
    - [x] 検索結果の画像にホバー効果と選択機能を実装する。

- **T-05: フロントエンド内でのUIロジック実装**

## MVPフェーズ（資金調達後の実装範囲）
**目標:** 雛形にバックエンドと画像生成AIの機能を接続し、実際に背景画像を生成できるようにする。

- **T-06: 外部素材検索機能（低コストで実装可能）**
    - [ ] **バックエンド:**
        - [ ] UnsplashやPixabayなどのフリー素材サイトのAPIを呼び出すためのエンドポイントを実装する。
    - [ ] **フロントエンド:**
        - [ ] 外部素材検索画面のUIをバックエンドAPIと接続し、キーワード検索と結果の動的表示を実装する。
        - [ ] 検索結果の画像をクリックしたら、その画像をプレビューエリアに表示し、ダウンロードできるようにする。

- **T-07: 生成履歴の保存・表示機能（低コストで実装可能）**
    - [ ] **バックエンド:**
        - [ ] 生成した画像の情報（プロンプト、画像URLなど）を保存・取得するためのAPIを実装する（BaaSを利用）。
    - [ ] **フロントエンド:**
        - [ ] コントロールパネルに「履歴」タブを追加する。
        - [ ] 過去に生成した画像をリスト表示し、クリックでプレビューエリアに再表示したり、再度ダウンロードしたりできる機能を実装する。

- **T-08: AI連携による画像生成機能（※要資金調達）**
    - [ ] **バックエンド:**
        - [ ] 画像生成AI（Stable Diffusion APIなど）を呼び出すためのサービスを実装する。
        - [ ] フロントエンドから受け取ったプロンプトや設定を元に、AIへのリクエストを構築する。
        - [ ] 生成された画像をクラウドストレージ（S3など）に保存し、そのURLをフロントエンドに返すAPIを実装する。
    - [ ] **フロントエンド:**
        - [ ] 「生成する」ボタンのクリック時に、コントロールパネルの入力内容をバックエンドAPIに送信する。
        - [ ] API通信中は、プログレスバー付きのローディング画面を表示する。
        - [ ] APIから受け取った画像URLをプレビューエリアに動的に描画する。
