# ライブパフォーマンスAIコーチングツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが過去の配信データに基づく分析結果を閲覧するダッシュボード。
- **バックエンド（APIサーバー）**: 外部APIからのデータ取得、AIモデルとの連携を管理する。
- **AIモデル**: 配信中の視聴者行動、音声、コメントを分析し、パフォーマンスを評価する。
- **外部API**: YouTube Data APIなどから配信の公開データを取得する。

### PC（ブラウザ）表示
棒グラフ、折れ線グラフ、ヒートマップなどを多用し、視聴者離脱率、スパチャのタイミング、盛り上がりのピークを可視化するダッシュボードを基本とする。

### スマホ表示
主要な分析結果（視聴者維持率、コメント数など）を上部に集約し、より詳細なデータは縦にスクロールして見られるようにする。

## 2. 主要機能詳細

### 2-1. 配信データ自動取得・分析機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTubeなどのアカウントを連携させる。
- **システム動作**:
    1.  バックエンドがYouTube Data APIを通じて、過去の配信の視聴者数、コメント数、スパチャ数、チャットログなどのデータを自動で取得する。
    2.  AIモデルがこれらのデータを分析し、以下のような指標を算出する。
        - **視聴者離脱率**: どのタイミングで視聴者が離れていったかをグラフで表示。
        - **エンゲージメント評価**: 配信者の「間」や「声のトーン」が視聴者の反応にどう影響したかを評価する。
        - **盛り上がりポイント**: コメントやスパチャが急増したタイミングを特定する。

### 2-2. パフォーマンス改善提案機能
- **ユーザーアクション**:
    - **アドバイス閲覧**: AIが生成したパフォーマンス改善に関するアドバイスを閲覧する。
- **システム動作**:
    1.  AIモデルが分析結果を基に、具体的な改善策を提案する（例: 「配信開始から5分後に視聴者離脱が多いです。オープニングトークを短くしてみましょう。」）。
    2.  過去の良い配信と比較し、成功要因を分析・提示する。

### 2-3. スキル評価・成長追跡機能
- **ユーザーアクション**:
    - **スキルレポート閲覧**: 定期的に生成されるスキルレポートを確認する。
- **システム動作**:
    1.  AIモデルが、配信者の「トークスキル」「企画力」「リアクション」などを複数の指標で評価し、その成長をグラフで追跡可能にする。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**Scikit-learn**、**TensorFlow**（自然言語処理、時系列分析モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Streams**: 配信情報管理（日時、タイトル、視聴者数など）。
- **AnalyticsData**: 各配信の分析結果データ管理。
- **PerformanceReports**: AIが生成したレポートの履歴管理。
