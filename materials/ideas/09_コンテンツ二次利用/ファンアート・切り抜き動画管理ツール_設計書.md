# ファンアート・切り抜き動画管理ツール 設計書

## ツール名
ファンアート・切り抜き動画管理ツール

## カテゴリ
09_コンテンツ二次利用

## 目的
VTuberがファンアートや切り抜き動画といった二次創作コンテンツを効率的に発見、管理、活用できるようにする。これにより、ファンとのエンゲージメントを強化し、二次創作活動を促進するとともに、VTuberのブランドイメージ保護とコンテンツ活用の最大化を図る。

## 機能要件
### 1. ユーザー認証・VTuberアカウント連携
*   VTuberアカウントでのログイン機能
*   X (旧Twitter), Pixiv, YouTubeなどのVTuber公式アカウントとのAPI連携

### 2. コンテンツ自動検出・収集
*   **キーワード・ハッシュタグ監視:** VTuber名、関連ハッシュタグなどを設定し、X, Pixiv, YouTubeなどから関連コンテンツを自動検出・収集
*   **画像認識・動画解析:** VTuberのモデルやロゴをAIが認識し、関連性の高いコンテンツを検出
*   **URL登録:** ファンが直接コンテンツURLを登録できる機能（オプション）

### 3. 一元管理ダッシュボード
*   収集されたファンアート（画像）、切り抜き動画（動画）を一覧表示
*   日付、プラットフォーム、クリエイター名、コンテンツタイプ（画像/動画）、承認ステータスなどでフィルタリング・ソート
*   コンテンツのプレビュー表示

### 4. コンテンツ承認・管理
*   **承認/非承認機能:** VTuberがコンテンツを個別に確認し、公式SNSでの紹介や配信での利用の承認・非承認を設定
*   **公開/非公開設定:** 承認されたコンテンツをツール内で公開するかどうかの設定
*   **タグ付け・カテゴリ分類:** コンテンツにカスタムタグを付けたり、カテゴリに分類したりする機能

### 5. クリエイター情報表示・連携
*   ファンアートや切り抜き動画のクリエイター情報（アカウント名、リンクなど）を自動取得・表示
*   クリエイターへの感謝メッセージ送信機能（オプション）

### 6. 公式共有機能
*   承認されたコンテンツをVTuberの公式SNS（X, YouTubeコミュニティなど）に直接共有する機能
*   共有時の定型文、ハッシュタグの自動挿入

### 7. コメント・リアクション機能
*   コンテンツに対してVTuberがコメントやリアクション（いいねなど）を残せる機能
*   ファンからのコメントを閲覧できる機能

### 8. ガイドライン違反検出・フィルタリング
*   VTuberが設定した二次創作ガイドライン（例：R-18コンテンツの禁止、誹謗中傷の禁止など）をAIが解析し、違反するコンテンツや不適切なコンテンツを自動で検出し、警告・非表示化
*   手動でのコンテンツ報告・削除機能

## 非機能要件
*   **性能:** コンテンツの自動検出は定期的に実行。ダッシュボードの表示は高速。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** ユーザーデータ、連携アカウント情報のプライバシー保護。不適切なコンテンツのフィルタリング。
*   **拡張性:** 新しいSNSプラットフォームや画像・動画サイトへの対応。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **コンテンツ収集:** Webスクレイピング、各プラットフォームAPI（X API, Pixiv API, YouTube Data API）
*   **画像・動画解析:** OpenCV, TensorFlow / PyTorch (画像認識、動画解析)
*   **データベース:** PostgreSQL / MongoDB (コンテンツ情報、クリエイター情報、承認履歴)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (収集したコンテンツの保存)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`, `hashed_password`, `platform_credentials`
*   **Content:** `id`, `vtuber_id`, `platform`, `content_url`, `thumbnail_url`, `creator_name`, `creator_url`, `upload_date`, `content_type` (image/video), `status` (pending/approved/rejected), `tags`, `violation_flag`
*   **ApprovalHistory:** `id`, `content_id`, `approver_id`, `action` (approve/reject), `timestamp`, `notes`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** OpenCV, Transformers, scikit-learn
*   **データベース:** PostgreSQL, MongoDB
*   **ストレージ:** AWS S3

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** X (旧Twitter) からのファンアート自動検出・収集、一元管理ダッシュボード、承認/非承認機能。
*   **フェーズ2:** YouTubeからの切り抜き動画自動検出・収集、Pixiv連携、公式共有機能、基本的なガイドライン違反検出。
*   **フェーズ3:** コメント・リアクション機能、より高度なAIによるコンテンツフィルタリング、クリエイターへの感謝メッセージ送信機能。
