# 配信中の視聴者セグメンテーションツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: リアルタイムで視聴者データを可視化するダッシュボード。
- **バックエンド（APIサーバー）**: リアルタイムでコメントを処理し、セグメンテーションのロジックを管理する。
- **AIモデル**: 視聴者のコメントや行動から、属性を推定・分類する。
- **外部API**: YouTube Live Chat APIなどからコメントデータを取得する。

### PC（ブラウザ）表示
視聴者層の分布を円グラフや棒グラフでリアルタイムに表示するダッシュボードを基本とする。各セグメントに属する視聴者のコメントや行動を一覧で確認できるレイアウトを採用する。

### スマホ表示
主要な視聴者層の割合を上部に大きく表示し、各セグメントの簡単なサマリーを縦にスクロールして見られるようにする。

## 2. 主要機能詳細

### 2-1. 視聴者属性リアルタイム検出機能
- **ユーザーアクション**:
    - **配信URL入力**: 分析したいYouTubeライブ配信のURLを入力する。
- **システム動作**:
    1.  バックエンドがYouTube Live Chat APIを通じて、指定された配信のコメントストリームをリアルタイムで取得する。
    2.  AIモデルが、コメントの内容、コメント頻度、ユーザーの過去の行動データ（あれば）を解析し、視聴者を複数のセグメント（例: 「コアファン」「初見さん」「海外視聴者」など）に分類する。
    3.  セグメンテーションの結果をリアルタイムでフロントエンドに送信し、UIのグラフやリストに反映させる。

### 2-2. 感情・エンゲージメント分析機能
- **ユーザーアクション**:
    - **ダッシュボード閲覧**: 配信中に各セグメントのエンゲージメントを確認する。
- **システム動作**:
    1.  AIモデルが、各セグメントのコメントの感情（ポジティブ、ネガティブ）を分析する。
    2.  セグメントごとのコメント数、スパチャ数、メンバーシップ加入者数などを集計し、エンゲージメントの高さを示す指標として表示する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**（自然言語処理、クラスタリングモデル）
- **データベース**: **MongoDB**（リアルタイムデータの高速な処理に適しているため）
- **外部連携**: **YouTube Live Chat API**

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **LiveComments**: ライブ配信中のコメント履歴管理。
- **AudienceSegments**: AIが分類した視聴者のセグメント情報管理。
