# 挨拶・決め台詞生成AI 設計書

## 1. システム構成図
このツールは、以下の3つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーがキャラクター情報を入力し、生成された挨拶や決め台詞を閲覧するインターフェース。
- **バックエンド（APIサーバー）**: AIモデルとの連携、データ管理を処理する。
- **AIモデル**: キャラクター情報とファン文化を学習し、挨拶や決め台詞を生成する。

### PC（ブラウザ）表示
キャラクター設定の入力フォームを上部に、生成された複数の挨拶・決め台詞の候補を一覧で表示するレイアウトを基本とする。

### スマホ表示
キャラクター設定の入力フォームをシンプルにし、生成結果を縦にスクロールして見られるようにする。

## 2. 主要機能詳細

### 2-1. 挨拶・決め台詞生成機能
- **ユーザーアクション**:
    - **キャラクター情報入力**: キャラクターの性格、口調、活動ジャンルなどをテキストで入力する。
    - **生成**: 入力情報に基づいて、挨拶や決め台詞の生成をリクエストする。
- **システム動作**:
    1. バックエンドがユーザーの入力データを受け取る。
    2. AIモデルが入力内容を基に、複数の挨拶・決め台詞の候補を生成する。

### 2-2. ファン文化学習機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTubeなどのアカウントを連携させる。
- **システム動作**:
    1. バックエンドがYouTube Live Chat APIを通じて、過去のコメントやファンの特徴的な言葉を収集する。
    2. AIモデルが収集したデータを学習し、ファンに響く、よりパーソナライズされた台詞を提案する。

### 2-3. 多言語対応機能
- **ユーザーアクション**:
    - **言語選択**: 挨拶や決め台詞を生成したい言語を選択する。
- **システム動作**:
    1. AIモデルが、選択された言語（例: 英語、中国語）で挨拶や決め台詞を生成する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**生成AIモデル**、**自然言語処理モデル**
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **GeneratedPhrases**: 生成された挨拶や決め台詞の履歴。
- **FanData**: 収集したファンの言葉やコメントのデータ。
