# 競合VTuber分析ツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが競合のデータを閲覧・比較するダッシュボード。
- **バックエンド（APIサーバー）**: 外部APIからデータを取得・集計し、フロントエンドに提供する。
- **AIモデル**: 人気動画の傾向やキーワードを分析するコアエンジン。
- **外部API**: YouTube Data APIなどのプラットフォームからデータを取得する。

### PC（ブラウザ）表示
複数の競合チャンネルのデータを並べて比較できるテーブルやグラフを主体としたレイアウト。各チャンネルのデータ（登録者数、再生回数など）を横並びで比較し、視覚的に違いがわかるように設計する。

### スマホ表示
画面サイズに合わせて、各競合チャンネルのデータを縦にスクロールして見られるようにする。チャンネルごとの詳細ページでは、主要な指標を上部に集約し、その下に動画ごとのパフォーマンス一覧を表示する。

## 2. 主要機能詳細

### 2-1. 競合チャンネル追跡・データ収集機能
- **ユーザーアクション**:
    - **チャンネル登録**: 分析したい競合VTuberのチャンネルURLを登録する。
- **システム動作**:
    1.  バックエンドがYouTube Data APIを通じて、登録されたチャンネルの公開データ（登録者数、動画再生回数、高評価数など）を定期的に自動で取得する。
    2.  取得したデータをデータベースに蓄積し、日次・週次などの推移を記録する。

### 2-2. パフォーマンス比較ダッシュボード
- **ユーザーアクション**:
    - **ダッシュボード閲覧**: ログイン後、登録した競合チャンネルのデータを比較する。
- **システム動作**:
    1.  データベースに蓄積されたデータを基に、ユーザーのチャンネルと競合チャンネルのパフォーマンスをグラフで可視化する。
    2.  各動画のパフォーマンス（再生数、高評価率など）を一覧表示し、ソートやフィルタリングができるようにする。

### 2-3. 人気動画・キーワード分析機能
- **ユーザーアクション**:
    - **分析レポート生成**: 特定の競合チャンネルや期間を指定して、分析レポートを生成する。
- **システム動作**:
    1.  AIモデルが、指定されたチャンネルの過去動画のタイトル、説明文、タグ、コメントなどを解析する。
    2.  再生数やエンゲージメント率が高かった動画の傾向（キーワード、企画内容）を抽出し、レポートとしてまとめる。
    3.  類似の企画を提案したり、効果的なキーワードを提案したりする。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**Scikit-learn**、**TensorFlow**（自然言語処理、クラスタリングモデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**

## 4. データベース設計
- **Users**: ユーザー情報管理
- **Channels**: 登録された競合チャンネルの情報管理
- **Videos**: 競合チャンネルの動画データ（再生数、高評価数、タイトルなど）
- **Keywords**: 動画から抽出されたキーワードの分析結果
