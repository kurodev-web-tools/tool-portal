# 活動ログ・ヘルスケア連携ツール 設計書

## 1. システム構成図
このツールは、以下の3つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが活動ログを記録し、ヘルスケアデータを閲覧するインターフェース。
- **バックエンド（APIサーバー）**: データ管理、外部APIとの連携、通知を処理する。
- **外部API**: 配信プラットフォームやヘルスケアデバイスからデータを取得する。

### PC（ブラウザ）表示
活動ログ（配信時間、コラボ相手など）とヘルスケアデータ（睡眠時間、心拍数など）を並べて表示するダッシュボードを基本とする。両者の相関関係をグラフで可視化する。

### スマホ表示
主要な活動ログとヘルスケアデータを上部に集約し、その下に日々の詳細なログを縦にスクロールして見られるようにする。通知機能はプッシュ通知を利用する。

## 2. 主要機能詳細

### 2-1. 活動ログ自動記録機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTubeなどの配信プラットフォームアカウントを連携させる。
- **システム動作**:
    1.  バックエンドが各プラットフォームのAPIを通じて、配信日時、配信時間、コラボ相手などの活動ログを自動で取得し、データベースに保存する。

### 2-2. ヘルスケアデータ連携・可視化機能
- **ユーザーアクション**:
    - **デバイス連携**: スマートウォッチなどのヘルスケアデバイスを連携させる。
- **システム動作**:
    1.  バックエンドがヘルスケアデバイスのAPIを通じて、睡眠時間、心拍数、活動量などのデータを定期的に自動で取得する。
    2.  取得したデータを活動ログと紐付けて、UI上で可視化する（例: 長時間配信した日の睡眠時間のグラフ）。

### 2-3. 健康アドバイス機能
- **ユーザーアクション**:
    - **アドバイス閲覧**: ダッシュボードで、AIが生成した健康に関するアドバイスを閲覧する。
- **システム動作**:
    1.  AIモデルが、活動ログとヘルスケアデータの相関関係を分析する。
    2.  例えば、「先週は配信時間が長かったため、睡眠時間が不足しています。今日は早めに休息を取りましょう。」といった具体的なアドバイスを生成し、表示する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**Scikit-learn**（データ分析モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**Fitbit API**、**Google Fit API**など。

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **ActivityLogs**: 活動ログ情報管理（配信日時、時間、タイトルなど）。
- **HealthData**: ヘルスケアデータ管理（睡眠時間、心拍数など）。
