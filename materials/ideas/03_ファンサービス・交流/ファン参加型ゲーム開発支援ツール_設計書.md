# ファン参加型ゲーム開発支援ツール 設計書

## ツール名
ファン参加型ゲーム開発支援ツール

## カテゴリ
03_ファンサービス・交流

## 目的
VTuberがプログラミング知識なしで、ライブ配信中に視聴者がコメントや投票などで直接介入できるインタラクティブなミニゲームやコンテンツを容易に作成・導入できるようにする。これにより、配信のインタラクティブ性とエンゲージメントを最大化し、視聴者の満足度と参加意識を向上させる。

## 機能要件
### 1. ユーザー認証・配信連携
*   VTuberアカウントでのログイン機能
*   YouTube Live, Twitchなどの配信プラットフォームとのAPI連携（コメント、チャット取得）
*   OBS Studioなどの配信ソフトウェアとの連携（ブラウザソース、WebSocket）

### 2. ゲーム作成エディタ
*   **テンプレート選択:** クイズ、投票、選択肢分岐、コメント連動アクション、ミニゲーム（例：コメントでキャラクターを動かす）など、多様なゲームテンプレートを提供
*   **GUIベースのコンテンツ入力:**
    *   質問文、選択肢、正解、不正解時のメッセージなどを直感的に入力
    *   コメント連動キーワード、アクション設定（例：特定のコメントでエフェクト表示）
    *   ゲームのルール、勝利条件、敗北条件の設定
*   **メディアアップロード:** 画像、音声、動画などのメディアファイルをアップロードし、ゲーム内に配置
*   **VTuberモデル・画面要素連携:** VTuberのキャラクターモデルや配信画面の既存要素（例：体力バー、アイテム欄）と連携し、ゲームの演出に利用
*   **プレビュー機能:** 作成中のゲームをリアルタイムでプレビュー
*   **プリセット管理:** 作成したゲームをプリセットとして保存・読み込み、再利用可能

### 3. リアルタイムコメント・チャット処理
*   配信プラットフォームからコメントやチャットをリアルタイムで取得
*   コメントのフィルタリング、キーワード抽出、投票集計
*   低遅延での処理

### 4. ゲーム実行・表示
*   作成したゲームを配信画面上にブラウザソースとしてオーバーレイ表示
*   ゲームの進行状況、結果、視聴者の貢献度などをリアルタイムで更新・表示
*   ゲームの開始・終了、一時停止、リセットなどの操作をVTuberの管理画面から制御

### 5. 結果表示・集計
*   投票結果、クイズの正答率、視聴者の貢献度などをリアルタイムで集計し、視覚的に表示
*   ゲーム終了後の詳細な結果レポート生成

## 非機能要件
*   **性能:** コメント入力からゲームへの反映、画面更新までの遅延は1秒以内（目標）。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** ユーザーデータ、配信プラットフォーム連携情報のプライバシー保護。
*   **拡張性:** 新しいゲームテンプレート、配信プラットフォーム、メディアフォーマットへの対応。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** プログラミング知識がないVTuberでも容易にゲームを作成・導入できる直感的なUI/UX。

## システム構成
*   **フロントエンド:** React / Vue.js (ゲーム作成エディタ、ゲーム表示オーバーレイ)
*   **バックエンド:** Node.js (Express/NestJS) / Python (FastAPI)
*   **リアルタイム通信:** WebSocket (コメント取得、ゲーム状態同期)
*   **データベース:** PostgreSQL / MongoDB (ゲームデータ、プリセット、結果)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (メディアファイル)
*   **クラウドプラットフォーム:** AWS / GCP / Azure
*   **連携API:** YouTube Live Streaming API, Twitch API, OBS WebSocket API

## データモデル
*   **User:** `id`, `username`, `email`
*   **GameTemplate:** `id`, `name`, `description`, `type` (quiz, poll, action), `default_settings` (JSONB)
*   **UserGame:** `id`, `user_id`, `template_id`, `game_name`, `game_settings` (JSONB), `media_files` (Array of URLs)
*   **GameSession:** `id`, `user_game_id`, `stream_session_id`, `start_time`, `end_time`, `results` (JSONB)

## 技術スタック
*   **言語:** JavaScript / TypeScript (フロントエンド), Node.js / Python (バックエンド)
*   **フレームワーク:** React / Vue.js, Express.js / FastAPI
*   **リアルタイム通信:** Socket.IO
*   **データベース:** PostgreSQL
*   **ストレージ:** AWS S3

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** クイズ、投票テンプレートの提供、GUIでのコンテンツ入力、リアルタイムコメント取得、OBSへのオーバーレイ表示。
*   **フェーズ2:** 選択肢分岐、基本的なコメント連動アクションテンプレートの追加、メディアアップロード機能、プリセット管理。
*   **フェーズ3:** ミニゲームテンプレートの追加、VTuberモデル・画面要素連携、より高度な結果レポート、他配信プラットフォーム連携。
