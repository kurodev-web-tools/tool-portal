# ポータルページ 設計書

## 1. 概要
*   ポータルページの目的と、動的な要素（ユーザー状態に応じた表示、利用状況など）の必要性。

## 2. 機能要件
*   **F-01: ユーザー状態に応じたUI表示**
    *   未ログイン/未登録、ログイン済み無料プラン、ログイン済み有料プランに応じて、UI要素（ボタン、メッセージなど）を切り替える。
*   **F-02: 各スイートの利用状況表示**
    *   各スイートカードに、そのスイートの残り利用回数などを表示する。
*   **F-03: 登録/ログイン/アップグレードへの導線**
    *   共通UI設計書で定義した右上のボタンの動作。

## 3. システム構成
*   フロントエンド（Next.js/React）とバックエンド（ユーザー認証、プラン情報、利用状況を提供するAPI）の連携。

## 4. API仕様
*   ポータルページが必要とするバックエンドAPIのエンドポイント定義。
    *   例: ユーザーのログイン状態、プラン、各スイートの利用状況を取得するAPI。

## 5. 画面仕様
*   ポータルページのレイアウト（スイートカードの表示など）と、ユーザー状態に応じたUI要素の表示ロジック。

## 6. データモデル
*   ポータルページで利用するユーザー関連のデータモデル（ユーザーID、プラン、利用状況など）。
