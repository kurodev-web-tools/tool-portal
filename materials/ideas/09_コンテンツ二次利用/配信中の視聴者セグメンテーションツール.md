# 配信中の視聴者セグメンテーションツール

## 1. ツールの目的・概要
- **目的**: ライブ配信中に、視聴者を属性ごとにリアルタイムで分類し、配信者が視聴者層を把握できるようにする。
- **ターゲット**: 視聴者層に合わせたトークや企画を展開したいVTuber。
- **価値**: 新規ファンや常連ファン、熱心な支援者など、視聴者の状況をリアルタイムで把握し、よりパーソナライズされたコミュニケーションを可能にする。

## 2. 主要な機能
- **視聴者データ分析**: YouTubeのコメント履歴、チャンネル登録期間、スパチャ履歴などを分析。
- **セグメント自動分類**: 視聴者を「初見」「常連」「メンバーシップ加入者」「高額スパチャ者」などのセグメントに自動で分類。
- **リアルタイムダッシュボード**: 配信中に、各セグメントの人数やコメントの傾向をグラフやチャートで表示。
- **コメントハイライト**: 特定のセグメント（例：初見、メンバーシップ加入者）からのコメントを強調表示し、配信者が気づきやすくする。
- **セグメント別データ分析レポート**: 配信終了後、どのセグメントがどの時間に最も活発だったか、どのようなコメントが多かったかをまとめたレポートを生成。

## 3. 技術的な側面
- **AI/ML**: ユーザーの行動履歴を分析するための機械学習モデル。
- **API**: YouTube Live Chat APIなどから視聴者データをリアルタイムで取得。
- **言語/フレームワーク**: Python（データ分析）、Node.js（リアルタイム通信）。

## 4. 収益モデル
- **月額課金**: 基本的なセグメント分類機能は無料で提供し、詳細なデータ分析やカスタマイズ可能なレポートは有料プランとする。

## 5. 開発ロードマップ
- **MVP（第一段階）**: 初見コメントの検出と、常連ユーザーの識別機能に絞って開発。
- **第二段階**: メンバーシップやスパチャ履歴と連携し、より多くのセグメントに分類できるようにする。
- **第三段階**: リアルタイムダッシュボード機能や、詳細な分析レポート機能を実装する。
