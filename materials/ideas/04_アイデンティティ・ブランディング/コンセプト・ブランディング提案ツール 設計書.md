# コンセプト・ブランディング提案ツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが個性や好みを入力し、提案されたブランディングコンセプトを閲覧するインターフェース。
- **バックエンド（APIサーバー）**: 外部APIからのデータ取得、AIモデルとの連携、データ管理を処理する。
- **AIモデル**: 配信者の個性や強みを分析し、コンセプトやビジュアルの方向性を提案する。
- **外部API**: YouTube Data APIなどから過去の配信データを取得する。

### PC（ブラウザ）表示
個性分析の結果をグラフやキーワードで視覚的に表示し、その隣に提案されたブランディングコンセプトやカラーパレットを一覧で表示するレイアウトを基本とする。

### スマホ表示
主要な分析結果とコンセプトのサマリーを上部に集約し、下に詳細な提案内容を縦にスクロールして見られるようにする。

## 2. 主要機能詳細

### 2-1. 個性・強み分析機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTubeなどのアカウントを連携させる。
- **システム動作**:
    1. バックエンドが外部APIを通じて、過去の配信タイトル、概要、コメント、視聴者層などのデータを取得する。
    2. AIモデルが取得したデータを分析し、配信者の個性や強み（例: 「トーク力」「企画力」「リアクション」など）を評価する。

### 2-2. コンセプト・ビジュアル提案機能
- **ユーザーアクション**:
    - **コンセプト提案**: 分析結果に基づいて、ブランディングコンセプトの提案をリクエストする。
- **システム動作**:
    1. AIモデルが個性分析の結果を基に、「癒し系ゲーマー」「知的な解説系」といったブランドコンセプトを複数生成する。
    2. 提案されたコンセプトに合わせた、ロゴの方向性、配信画面のレイアウト、キャラクターの服装やカラーパレットを提案する。

### 2-3. ターゲットオーディエンス分析機能
- **ユーザーアクション**:
    - **オーディエンス分析**: 既存の視聴者層を分析し、より効果的なブランディング戦略をリクエストする。
- **システム動作**:
    1. AIモデルが視聴者の年齢層、性別、興味関心などを分析し、ターゲットオーディエンスを明確にする。
    2. 分析結果に基づき、どのようなコンテンツやコミュニケーションがターゲットに響くかを提案する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**自然言語処理モデル**、**クラスタリングモデル**
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**X API v2**

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **AnalysisData**: 過去の配信データやSNS投稿の分析結果。
- **BrandingProposals**: AIが生成したブランディングコンセプトの履歴。
