# プロジェクト構造

## プロジェクト概要

VTuber配信ワークフロー連鎖ツール - VTuberの活動を包括的に支援するWebツールスイート

## 技術スタック

- **フレームワーク**: Next.js 15 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **UIライブラリ**: shadcn/ui
- **パッケージマネージャー**: pnpm
- **デプロイ**: GitHub Pages
- **バージョン管理**: Git

## 重要な設計方針

### 命名規則

- **コンポーネント**: PascalCase（例: `UserProfileCard.tsx`）
- **変数・関数**: camelCase（例: `getUserProfile`）
- **型・インターフェース**: PascalCase（例: `type UserProfile`, `interface PostData`）
- **ファイル名**: 
  - コンポーネント: PascalCase
  - ユーティリティ: camelCase
  - フック: use-kebab-case

### インポート順序

1. 外部ライブラリ（例: `react`, `next`）
2. 内部の絶対パス（例: `@/components/Button`）
3. 相対パス（例: `../hooks/useUser`）

### 状態管理

- **ローカル状態**: `useState`
- **コンテキスト**: `useContext`（ツール固有の状態）
- **複雑な状態**: `useReducer`

### コンポーネント設計

- 小さく、単一の責務に集中
- 再利用可能なコンポーネントは `src/components/` に配置
- ツール固有のコンポーネントは各ツールの `components/` に配置

## 現在の課題

### 大規模ファイル（500行以上）

1. **asset-creator/page.tsx** (1766行) - 最大
2. **thumbnail-generator/page.tsx** (1686行)
3. **virtual-bg-generator/page.tsx** (1037行)
4. **thumbnail-generator/components/TemplateSelector.tsx** (729行)
5. **thumbnail-generator/services/TemplateAutoGenerator.ts** (694行)
6. **thumbnail-generator/components/AutoGenerationPanel.tsx** (607行)
7. **thumbnail-generator/contexts/TemplateContext.tsx** (518行)

### ツール間の共通化

- **レイヤーコンポーネント**: `ThumbnailText`, `ThumbnailImage`, `ThumbnailShape` が重複
- **プレビューコンポーネント**: `EnhancedPreview` の実装が異なる
  - サムネイル自動生成: 独自実装
  - イベント用素材制作: 汎用実装
- **テンプレート管理**: `TemplateContext` が重複
- **レイヤー操作**: `useLayerOperations` が重複

### コンポーネント構造の違い

#### サムネイル自動生成
- `EnhancedPreview`: 独自実装、ズーム・グリッド・ガイドを含む
- ツールパネル、サイドバーを分離

#### イベント用素材制作
- `EnhancedPreview`: 汎用実装、`transform: scale()` を使用
- ツールパネル、サイドバーを分離（Phase 3で試みた）

## パッケージマネージャー

**pnpm** を使用しています。

### よく使うコマンド

- `pnpm dev`: 開発サーバー起動
- `pnpm dev:watch`: 開発サーバー + テンプレート監視
- `pnpm build`: プロダクションビルド
- `pnpm start`: プロダクションサーバー起動
- `pnpm lint`: ESLint実行
- `pnpm test`: テスト実行
- `pnpm generate-templates`: テンプレート生成
