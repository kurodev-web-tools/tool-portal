# マルチタレント・コンプライアンス監視ダッシュボード

## 1. ツールの目的・概要
- **目的**: VTuber事務所の運営者が、所属する全タレントの配信やSNS活動を横断的に監視し、コンプライアンス違反や炎上リスクをリアルタイムで検知・管理する。
- **ターゲット**: 複数のVTuberをマネジメントする事務所の運営者、法務・コンプライアンス担当者。
- **価値**: 事務所全体のブランドイメージを、所属タレントの意図しない言動によるリスクから保護する。24時間365日、全タレントの全活動を人力で監視する非現実的なコストと労力を、AIによって大幅に削減する。

## 2. 主要な機能
- **リアルタイム横断監視**: 登録した全タレントのYouTube配信、X(Twitter)の投稿などをリアルタイムでシステムが監視。
- **AIによるリスク検知**:
    - **不適切な発言**: 差別用語、暴力的・政治的な発言、個人情報などをAIが検知し、マネージャーに即時アラート。
    - **著作権侵害**: 許諾を得ていないBGMや映像が配信で使われていないか、音声認識・映像認識でチェック。
    - **未許可のPR**: スポンサー契約外の製品を過度に宣伝するなど、ステルスマーケティングと疑われかねない言動を検知。
- **アラート・レポート機能**: リスクが検知された場合、マネージャーのダッシュボードやスマートフォンに即時通知。日次・週次で各タレントの活動状況とリスク検知のサマリーレポートを自動生成する。
- **インシデント管理**: 検知された事象について、対応状況（確認中、対応済みなど）を記録・管理できる。

## 3. 技術的な側面
- **AI/ML**:
    - **音声認識・自然言語処理(NLP)**: 配信中の会話をリアルタイムでテキスト化し、NGワードや危険な文脈を分析。
    - **音源認識（オーディオフィンガープリント）**: 配信で使われているBGMが、事務所の許諾済み楽曲リストに含まれているかを照合。
    - **画像認識**: 配信画面に不適切な画像や、許諾のないロゴなどが映り込んでいないかをチェック。
- **クローリング・API連携**: YouTube Data API, X APIなどを利用して、タレントの活動データを網羅的に収集。

## 4. 収益モデル
- **月額課金モデル**: 監視対象のタレント数と、利用する機能（音声認識、画像認識など）の範囲に応じた階層的なプランを設定。事務所の規模に合わせたエンタープライズ契約が主となる。

## 5. 開発ロードマップ
- **MVP（第一段階）**: X(Twitter)の投稿とYouTubeのタイトル・概要欄のテキスト監視に特化。NGワードの検知とアラート機能から開発。
- **第二段階**: YouTube配信のリアルタイム音声認識と、不適切な発言の検知機能を追加。
- **第三段階**: BGMの著作権チェック機能、配信画面の画像認識機能など、より高度な監視機能を追加。
