# Portal Design

## Overview

ポータルは「ツール群の入口」として機能する。  
初回MVPでは、サービス全体を `スイート` 単位で見せ、個別ツール探索は `/tools` に集約する。

見せ方の軸は以下。

- 実務ダッシュボード寄り
- 一覧性優先
- 初見で「何の目的のツール群か」が分かる
- スイートごとの役割を自然に理解できる
- 個別ツール一覧とは役割を分ける

## Layout

### Overall Structure

- 上部ヘッダー
- 左サイドバー
- 右メインコンテンツ

左サイドバーは `ショートカット導線`、右メインは `スイート紹介と入口` を担う。

### Header

- 左: サービス名またはロゴ
- 右: ライト / ダーク切替

ヘッダーは常時薄い境界線で区切り、重くしない。

### Left Sidebar

- 初期MVPでは `固定項目 + 実装済みツール` を表示する
- 固定項目の例
  - Home
  - Tools
- 実装済みツールの例
  - Schedule Calendar
- サイドバーは管理ツリーではなく、`よく使う導線` に見える軽さを保つ
- 将来的に `Pinned` `Recent` `Favorites` を追加できる余地を残す

### Main Content

- ヒーロー
- スイートカード一覧

メイン領域はスイート探索の主役であり、個別ツール探索は `/tools` に分離する。

### Hero

- 短い導入文
- 軽いサマリー
  - スイート数
  - 実装済みツール数
  - 準備中の機能数

ヒーローはLPのように大きく見せず、ポータル全体の文脈を整える程度に留める。

### Suite Grid

- 2〜3列基準の中型カードグリッド
- カードはツール単体ではなく `スイート` を表す
- 各カードは役割、代表ツール、導線が分かる情報量にする
- サイドバー込みでも余白を保ち、ポータルTOPとして落ち着いた密度にする

## Suite Cards

各カードは以下の要素で構成する。

- スイート名
- 短説明
- 代表カテゴリまたは用途
- 含まれる代表ツール数や代表ツール名
- 状態ラベル
- 導線ボタン

### State Handling

- 利用可能なスイート: `/tools` へ遷移できる
- 準備中のスイート: 状態ラベルで未実装を明示できる

スイートカードから `/tools` へ遷移する場合は、対象スイートで事前に絞り込み済みの状態で開く。  
例: `/tools?suite=schedule` のような形で、一覧側の初期状態をスイートに合わせる。

### Initial Suite Definitions

初期MVPでは、HOME に表示するスイートは以下の4つを基準とする。

1. 配信ワークフロー
   - key: `stream-workflow`
   - 説明: 企画、準備、配信、配信後の振り返りまでを支えるツール群
2. ファン＆ブランド
   - key: `fan-brand`
   - 説明: ファンとの交流と、VTuberとしての世界観づくりを支えるツール群
3. ビジネス＆コラボ
   - key: `business-collab`
   - 説明: 収益化、運営、コラボ進行を整理するためのツール群
4. 成長＆セルフケア
   - key: `growth-selfcare`
   - 説明: 活動の継続、学習、セルフマネジメントを支えるツール群

HOME 上のカード表示名は短く、説明文で意味を補う。  
内部資料の長い正式名称は保持してよいが、UI 表示は上記の短縮名を優先する。

## Visual Tone

- 背景は落ち着いた面でまとめる
- スイートカードはフラット、境界線で整理
- 実装済み導線に深めティールを使う
- 準備中表示は中立色で抑える
- `/tools` より少し余白を広めに取る

## Responsive Behavior

- PC: 2〜3列を優先
- Tablet: 2列
- Mobile: 1列

## Key Components

- PortalHeader
- PortalSidebar
- PortalHeroSummary
- SuiteCard
- StatusBadge

## Do

- 何の目的のスイートがあるかを一画面で理解できるようにする
- サイドバーをショートカットとして軽く見せる
- ポータルを過剰に演出しない
- 情報の優先順位を固定する

## Do Not

- サイドバーを全件一覧の代替にする
- HOME に個別ツール一覧をそのまま並べる
- カードの装飾差を強くしすぎる
- `/tools` と責務が重なる絞り込みUIを持ち込む
