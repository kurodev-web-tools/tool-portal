# 挨拶・決め台詞生成AI

## 1. ツールの目的・概要
- **目的**: キャラクターの性格や活動内容に合わせて、ファンに覚えてもらいやすい挨拶や決め台詞をAIが生成する。
- **ターゲット**: 新人VTuber、ファンコミュニティを強化したいVTuber。
- **価値**: 配信の冒頭と終わりに一貫性を持たせ、キャラクターの個性を際立たせる。

## 2. 主要な機能
- **キャラクター情報入力**: キャラクターの性格、口調、活動ジャンルなどを入力。
- **挨拶・決め台詞生成**: 入力情報に基づき、「おは〇〇」「おつ〇〇」などの挨拶や、配信の最後に使う決め台詞を複数パターン生成。
- **ファン文化学習**: コメントや過去の配信データから、ファンが好む言葉の傾向を学習し、より響く台詞を提案。
- **言語バリエーション**: 多言語での挨拶や決め台詞を生成する。

## 3. 技術的な側面
- **AI/ML**: 自然言語処理（NLP）、生成AIを使用。
- **データ取得**: YouTube Data API v3。

## 4. 収益モデル
- **無料ツール**: 基本機能は無料で提供し、他のツールへの誘導や、高度な機能は有料プランに含める。

## 5. 開発ロードマップ
- **MVP（第一段階）**: 日本語での挨拶・決め台詞生成機能に絞って開発。
- **第二段階**: ファン文化学習機能を追加し、よりパーソナライズされた台詞を生成。
- **第三段階**: 多言語対応機能を追加し、グローバルなファンベースをターゲットにする。
