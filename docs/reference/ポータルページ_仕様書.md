# ポータルページ 仕様書

## 1. 概要

*   **目的:** VTuber向けツールスイートの各フェーズ（スイート）への入り口となる、ランディングページ。ユーザーはここから目的のツール群へアクセスする。
*   **デザイン哲学:** シンプルでクリーン、かつ機能的なデザインを基調とし、定義済みのカラーテーマ、フォント、アイコンでブランド感を出す。

## 2. 画面仕様

*   **レイアウト:** 各スイートを代表するカードがグリッド形式で並ぶレイアウト。
*   **各スイートカードの内容:**
    *   **スイート名:** （例: 「企画・準備」のように短縮）
    *   **概要:** そのスイートで何ができるかの簡単な説明。（例: 「コンテンツの企画から告知までをサポート」）
    *   **代表的なツールアイコン:** そのスイートに含まれる主要なツールのアイコンをいくつか表示。
    *   **スイートへのリンク:** クリックすると、そのスイートのデフォルトツールに遷移する。
*   **共通UI要素:**
    *   画面上部には、スイート共通UI設計書で定義したグローバルナビゲーションバーを常に表示する。

## 3. 動作

*   スイートカードをクリックすると、そのスイートのデフォルトツールに遷移する。
