# Schedule Calendar Image Prompt

## Purpose

`V_streamer_tools` の `スケジュールカレンダー` 画面モックを画像生成するためのプロンプト。  
目的は週表示中心の見やすさ、右サイドパネルの役割、投稿補助UIの整理感を確認すること。

## Prompt

Create a high-fidelity desktop UI mockup for a Japanese VTuber schedule calendar web app inside a product called "V Streamer Tools".

Style direction:
- practical schedule management tool
- clean, structured, and readable
- compatible with both light mode and dark mode
- flat UI with thin borders
- subtle product polish, but not flashy
- deep teal primary accent with restrained mint support
- readable sans-serif typography
- 8px corner radius

Layout:
- left main calendar area and right fixed side panel
- default emphasis is week view
- calendar toolbar at the top with period label and month/week/day switches
- compact event blocks in the weekly grid
- event blocks show mainly title and time
- selected event details appear in the side panel

Side panel:
- two tabs: Japanese labels for schedule management and post assist
- schedule management tab shows selected day events, add button, edit and delete actions
- post assist tab shows template selector, post preview, copy button, and X posting action
- the post assist area should still look like part of the same practical tool, not a creative poster editor

Content tone:
- Japanese UI text
- made for VTubers, but neutral enough for any gender
- practical, trustworthy, creator workflow focused
- no heavy entertainment styling

Visual details:
- clear calendar grid
- active day, active tab, and selected event use teal emphasis
- dense but readable schedule layout
- side panel remains calm and structured
- should feel immediately usable as a real tool

Deliverable:
- one polished desktop schedule calendar screen mockup
- optionally include both light and dark variants side by side if supported

## Negative Prompt

- flashy social app
- gaming HUD
- neon interface
- pink-heavy palette
- glassmorphism
- oversized decorative illustrations
- cluttered weekly cells
- overly soft rounded toy-like UI
