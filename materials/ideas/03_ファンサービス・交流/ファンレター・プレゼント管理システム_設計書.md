# ファンレター・プレゼント管理システム 設計書

## ツール名
ファンレター・プレゼント管理システム

## カテゴリ
03_ファンサービス・交流

## 目的
VTuberがファンからのファンレターやプレゼントを効率的かつ安全に管理し、ファンへの感謝を漏れなく伝えることを支援する。これにより、ファンとのパーソナルな絆を深め、ロイヤリティの向上とコミュニティの活性化に貢献する。

## 機能要件
### 1. ユーザー認証・プロファイル管理
*   VTuberアカウントでのログイン機能
*   VTuberの基本情報、ファンレター・プレゼントの受け取りに関するポリシー設定

### 2. 受け取り記録
*   **新規記録作成:** ファンレターまたはプレゼントの新規受け取り記録を作成
*   **基本情報入力:** 受け取り日、差出人名（匿名可）、ファンネーム、連絡先（任意）、受け取り方法（郵送、手渡しなど）
*   **写真・動画アップロード:** ファンレターやプレゼントの開封時、内容物の写真や短い動画をアップロードし、記録と紐付け
*   **内容詳細記録:**
    *   **ファンレター:** メッセージ内容のテキスト入力（手書きの場合はOCRによるテキスト化支援）、感想、返信内容のメモ
    *   **プレゼント:** 品目、ブランド、金額（任意）、開封時の感想、使用状況のメモ
*   **タグ付け・分類:** 記録にカスタムタグを付けたり、カテゴリに分類したりする機能（例：誕生日プレゼント、記念日、応援メッセージ）

### 3. お礼管理
*   **お礼状況管理:** 各記録に対して「未送付」「送付済み」「返信不要」などのステータスを設定
*   **お礼メッセージ作成支援:**
    *   お礼メッセージのテンプレート提供
    *   記録内容（差出人名、プレゼント品目など）に基づいたAIによるお礼メッセージの下書き生成
*   **お礼送付機能連携:** 外部のメッセージングツール（メール、SNS DMなど）や、VTuberが利用するお礼動画作成ツールとの連携（オプション）
*   **お礼履歴:** 送付したお礼のメッセージ内容や日時を記録

### 4. 検索・フィルタリング・ソート
*   記録されたファンレターやプレゼントを、差出人、日付、内容、品目、お礼状況、タグなどで検索・フィルタリング・ソート

### 5. ファン情報連携
*   差出人のファン情報（ファンネーム、SNSアカウントなど）と連携し、過去のやり取りや活動履歴を把握（CRM機能の簡易版）

### 6. 統計・分析
*   受け取ったプレゼントの傾向（品目、金額帯）、ファンレターのメッセージ傾向（ポジティブ/ネガティブ、キーワード）などを統計的に分析し、グラフなどで可視化
*   ファンからのフィードバックを活動改善に活かすためのレポート

### 7. プライバシー・セキュリティ管理
*   ファンからの個人情報（住所、氏名など）を安全に管理し、VTuber以外のアクセスを制限
*   データ暗号化、アクセスログ管理

## 非機能要件
*   **性能:** 記録の登録、検索は高速に動作すること。画像・動画アップロードの安定性。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** 機密性の高いファン情報、個人情報の厳重な保護。データ暗号化、アクセス制御。
*   **拡張性:** 新しい連携サービス、分析機能の追加に対応できるアーキテクチャ。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。VTuberが手軽に記録・管理できる設計。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **画像処理:** OpenCV, Pillow (OCR連携)
*   **AI/MLモデル:** OCRエンジン（Google Cloud Vision AI, AWS Textractなど）、NLP（テキスト生成）
*   **データベース:** PostgreSQL / MongoDB (記録データ、ファン情報)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (写真・動画ファイル)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`
*   **FanRecord:** `id`, `vtuber_id`, `received_date`, `sender_name`, `fan_name`, `contact_info` (JSONB), `type` (letter/present), `status` (pending/thanked)
*   **ContentDetail:** `id`, `fan_record_id`, `description`, `item_list` (Array), `message_text`, `vtuber_notes`
*   **MediaFile:** `id`, `fan_record_id`, `file_url`, `file_type` (image/video), `upload_date`
*   **ThankYouMessage:** `id`, `fan_record_id`, `message_text`, `sent_date`, `sent_method`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** OpenCV, Transformers
*   **データベース:** PostgreSQL
*   **ストレージ:** AWS S3

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 基本的な受け取り記録（日付、差出人、内容メモ）、写真アップロード、お礼状況管理、検索・フィルタリング。
*   **フェーズ2:** OCRによる手書き文字のテキスト化支援、AIによるお礼メッセージ下書き生成、ファン情報連携（簡易CRM）。
*   **フェーズ3:** 動画アップロード、統計・分析レポート、外部メッセージングツール連携、より高度なプライバシー・セキュリティ管理。
