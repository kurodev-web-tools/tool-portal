# スケジュール自動調整（外部連携強化版） 設計書

## ツール名
スケジュール自動調整（外部連携強化版）

## カテゴリ
05_バックオフィス・ビジネス

## 目的
VTuberが企業担当者やコラボ相手など外部の関係者との日程調整にかかる時間と労力を大幅に削減する。複数のカレンダーサービスと連携し、AIによる最適な日程候補の提案と自動登録を通じて、コラボレーションやビジネス案件の円滑な進行を支援する。

## 機能要件
### 1. ユーザー認証・カレンダー連携
*   VTuberアカウントでのログイン機能
*   VTuber自身のカレンダーサービス（Google Calendar, Outlook Calendarなど）とのOAuth2.0連携
*   外部関係者のカレンダーサービスとの連携（招待リンク発行、またはOAuth2.0による共有設定）
*   連携カレンダーの管理、同期設定

### 2. 空き時間自動検出
*   連携された複数のカレンダーから、指定された期間内の共通の空き時間をリアルタイムで検出
*   会議の長さ、休憩時間、移動時間などを考慮した空き時間計算
*   空き時間の重複、競合の視覚的表示

### 3. 日程候補提案AI
*   **イベント情報入力:** イベントの長さ、参加人数、優先順位、希望時間帯、希望曜日などの条件を入力
*   **候補日時生成:** AIが入力条件と参加者全員の空き時間に基づき、最適な日程候補を複数提案
*   **最適化アルゴリズム:** 参加者の重要度、イベントの緊急度、過去の調整実績などを考慮し、最も調整しやすい日程を優先的に提案
*   **視覚的表示:** 各候補日時の参加者の空き状況、調整の難易度を視覚的に表示

### 4. 招待・承認フロー
*   提案された日程候補を関係者に招待するためのURLまたはメールを自動生成
*   参加者はURLからアクセスし、希望日時を選択または承認
*   参加者の承認状況をリアルタイムで管理（未回答、承認、拒否）
*   未回答者へのリマインダー自動送信

### 5. 自動カレンダー登録
*   最終的に決定した日程を、参加者全員のカレンダーに自動で登録
*   イベント名、場所、説明、参加者リストなどを自動で入力

### 6. リマインダー・通知
*   決定した日程のリマインダー通知（メール、アプリ内通知）
*   日程の変更・キャンセル時の自動通知

### 7. 会議室・リソース予約（オプション）
*   オフラインイベントの場合、提携する会議室予約システムや機材予約システムとの連携
*   空き状況の確認、予約の自動化

## 非機能要件
*   **性能:** 日程候補の検出・提案は数秒以内。カレンダー同期はリアルタイムまたは数分以内。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** カレンダー情報、参加者情報のプライバシー保護。OAuth2.0による安全な認証。
*   **拡張性:** 新しいカレンダーサービス、リソース予約システム、AIモデルの追加に対応できるアーキテクチャ。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。複雑な日程調整も容易に行える設計。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **カレンダーAPI連携:** Google Calendar API, Microsoft Graph APIなど
*   **AI/MLモデル:** 組み合わせ最適化アルゴリズム、レコメンデーションシステム
*   **データベース:** PostgreSQL / MongoDB (ユーザー設定、イベント情報、調整履歴)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`
*   **CalendarAccount:** `id`, `user_id`, `platform`, `access_token`, `refresh_token`
*   **EventRequest:** `id`, `organizer_id`, `event_name`, `duration`, `participants` (Array of emails), `preferred_dates` (Array), `status` (pending, confirmed, cancelled)
*   **TimeSlot:** `id`, `event_request_id`, `start_time`, `end_time`, `participant_availability` (JSONB)
*   **ConfirmedEvent:** `id`, `event_request_id`, `start_time`, `end_time`, `calendar_event_id` (platform specific)

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **カレンダーAPI:** Google Calendar API Client Library, Microsoft Graph SDK
*   **AI/MLライブラリ:** scikit-learn, PuLP (最適化ライブラリ)
*   **データベース:** PostgreSQL

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** VTuber自身のGoogle Calendar連携、空き時間自動検出、基本的な日程候補提案、招待リンク発行、自動カレンダー登録。
*   **フェーズ2:** Outlook Calendar連携、参加者の承認状況管理、リマインダー・通知機能、より高度な日程候補提案AI。
*   **フェーズ3:** 会議室・リソース予約連携、参加者の優先順位付け、AIモデルの継続的な学習。
