# スパチャ・メンバーシップ収益分析ツール 設計書

## 1. システム構成図
このツールは、以下の3つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: 収益データやトレンドを可視化するダッシュボード。
- **バックエンド（APIサーバー）**: 外部APIからデータを取得・集計し、フロントエンドに提供する。
- **データベース**: 収益データ、スパチャの内容、メンバーシップの履歴などを保存する。

### PC（ブラウザ）表示
スパチャ金額の推移、メンバーシップの加入・解約数、国別・言語別の収益分布など、複数のグラフやチャートを並べて表示するダッシュボードを基本とする。

### スマホ表示
主要な収益額やスパチャの件数を上部に集約し、その下にグラフやスパチャの内容一覧を縦にスクロールして見られるようにする。

## 2. 主要機能詳細

### 2-1. 収益データ自動取得機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTubeアカウントを連携させる。
- **システム動作**:
    1.  バックエンドがYouTube Data APIを通じて、スパチャ金額、メンバーシップの加入者数、収益の詳細データを定期的に自動で取得する。
    2.  取得したデータをデータベースに保存し、集計・分類する。

### 2-2. 収益分析・トレンド可視化機能
- **ユーザーアクション**:
    - **ダッシュボード閲覧**: ログイン後、リアルタイムまたは過去の収益データを確認する。
- **システム動作**:
    1.  データベースに蓄積されたデータを基に、以下の情報を可視化する。
        - **スパチャの金額分布**: どの価格帯のスパチャが最も多いかを表示。
        - **時間帯別・配信別収益**: どの時間帯やどの配信が最も収益を上げたかを表示。
        - **国・言語別収益**: どの国や言語からの収益が多いかを表示。
    2.  スパチャのコメント内容をキーワードで分析し、人気の話題を抽出する。

### 2-3. ファンティア、FANBOX連携機能
- **ユーザーアクション**:
    - **アカウント連携**: ファンティアやFANBOXアカウントも連携させる。
- **システム動作**:
    1.  バックエンドが各プラットフォームのAPIを通じて、月額支援金や売上データを取得し、YouTubeの収益と統合して分析する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**FANBOX API**など。

## 4. データベース設計
- **Users**: ユーザー情報管理
- **SuperChats**: スパチャの詳細データ（金額、コメント内容、日時など）
- **Memberships**: メンバーシップの履歴（加入・解約日時など）
- **IntegratedRevenues**: 各プラットフォームからの収益データを統合して管理
