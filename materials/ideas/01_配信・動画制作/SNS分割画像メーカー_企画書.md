# SNS分割画像メーカー 企画書

## 1. ツールの目的・概要

- **目的**: SNS投稿時の「サムネで見える情報」と「画像展開後に見せる情報」を一体設計し、分割投稿の制作を効率化する。
- **ターゲット**: Xで分割投稿を運用するVTuber、告知画像を段階的に見せたい配信者。
- **価値**: 手作業の切り出しミスや境界ずれを減らし、投稿順まで含めて実用的に出力できる。

## 2. 対応プラットフォームと前提

- MVP対象は **X向け16:9中心** とする。
- 4分割出力を基本とし、投稿順は `1 → 2 → 3 → 4` を前提にする。
- 他SNS向け比率は後続フェーズで拡張する。

## 3. MVPで実装する範囲

### 3.1 モードA: `1枚（分割元）+8枚（上下連結）`

- 入力:
  - メイン画像 1枚（4分割対象）
  - 上側連結画像 4枚
  - 下側連結画像 4枚
- 出力:
  - 4分割画像 4枚（各画像に上下連結を反映）
- 想定用途:
  - サムネでは中心情報を見せ、展開後に上下で追加情報を見せる。

### 3.2 モードB: `1枚（ベース）+4枚（分割枠内差し替え）`

- 入力:
  - ベース画像 1枚（上下コンテンツを含んだ背景）
  - 差し替え画像 4枚（各分割枠用）
- 出力:
  - 4分割画像 4枚（各枠に差し替えを反映）
- 想定用途:
  - 既にデザイン済みの上下情報を残し、中心の4枠だけ差し替える。

### 3.3 微調整エディタ（MVP必須）

- 調整項目:
  - 位置調整（X/Y）
  - スケール調整
  - 境界微調整（分割線位置、分割後の境界補正）
- 補助設定:
  - 境界線の太さ
  - 境界線の色
  - 上下連結高さ比率

### 3.4 ずれ確認プレビュー

- プレビュー1: サムネ見え方（4分割前提の見え方）
- プレビュー2: 投稿後並び想定（1→4順）
- 調整→プレビュー→再出力を同画面で反復できる。

### 3.5 出力

- 連番4枚を個別ダウンロード可能にする。
- ファイル名に投稿順が分かる番号を付与する（例: `_01`〜`_04`）。

## 4. 入出力仕様（MVP）

### 4.1 入力

- 画像形式: PNG / JPEG
- 基本解像度: 16:9想定（不足時は内側基準で調整）
- モードごとの必要枚数:
  - モードA: 1 + 8
  - モードB: 1 + 4

### 4.2 出力

- 4枚固定出力
- 投稿順情報を明示して保存
- 出力画像の並びとプレビュー並びは同一順序とする

## 5. 非対応（MVPではやらないこと）

- AI生成（自動配置、最適レイアウト提案）
- 有料API連携
- SNS API直接投稿
- 認証必須機能
- 自動最適化（エンゲージメント予測）
- X以外の比率最適化（Instagram/TikTok専用出力）

## 6. 画面構成（軽量）

1. **モード選択**
- `1+8連結` / `1+4差し替え` を選択。

2. **素材入力**
- 必須画像スロットを順番にアップロード。

3. **編集・調整**
- キャンバスプレビュー + 微調整パネル。

4. **確認・書き出し**
- サムネ見え方 / 投稿並び想定を確認後、4枚出力。

## 7. 他ツール連携方針

- Schedule Calendar連携はMVPでは **手動取り込み** とする。
  - 例: 配信タイトル、日時、タグ文言を手入力または貼り付け。
- Phase 2で `localStorage` 連携を検討する。

## 8. 成功指標（MVP評価用）

- 2モード（`1+8`, `1+4`）のいずれでも4枚出力できること。
- 境界ずれを調整して再出力できること。
- 投稿順ミスを防げるUI（順番明示）が機能すること。

## 9. フェーズ拡張（後続）

- Phase 2:
  - 追加比率プリセット（1:1, 4:5など）
  - localStorage連携による文言自動反映補助
  - 一括ダウンロード改善
- Phase 3:
  - サムネイルエディタとの相互受け渡し
  - 投稿テンプレート連動
