# 動画タイトル・概要欄自動生成AI MVP開発タスクリスト

## 概要
このタスクリストは、「動画タイトル・概要欄自動生成AI」の雛形（フロントエンドの骨格）およびMVP（Minimum Viable Product）を開発するためのものです。
AI連携などコストのかかる機能は「MVPフェーズ」に切り分け、資金調達後の実装を想定しています。

---

## 雛形フェーズ（コストゼロでの実装範囲）
**目標:** AIやバックエンドのロジックなしで、ツールの主要なUIコンポーネントを静的に構築する。

- **T-01: 基本的なページ構造のセットアップ**
    - [x] `vtuber-tools-portal` プロジェクト内に、ツール用の新しいルートを作成する (`/tools/title-generator`)。
    - [x] `page.tsx` ファイルを作成し、基本的なコンポーネントを配置する。
    - [x] `shadcn/ui` の `Resizable` コンポーネントなどを使用し、左7割（結果表示エリア）と右3割（コントロールパネルエリア）のレイアウトを実装する。

- **T-02: コントロールパネルのUI作成**
    - [x] 右側のパネルに、動画の情報を入力するためのフォームを配置する。
        - [x] **動画のテーマ・内容:** `Textarea` コンポーネントを配置。
        - [x] **主要キーワード:** `Input` コンポーネントを配置。
        - [x] **ターゲット層:** `Input` コンポーネントを配置。
        - [x] **動画の雰囲気:** `Select` または `RadioGroup` コンポーネントを使い、「面白い」「感動」「解説」などの選択肢を配置。
    - [x] フォームの下に「生成する」ボタンを配置（機能は未実装）。

- **T-03: 結果表示エリアのUI作成**
    - [x] 左側のエリアを上下に分割する。
    - [x] **上部: 最終編集エリア**
        - [x] 「最終タイトル」用の `Input` と `Button`（コピー用）を配置。
        - [x] 「最終概要欄」用の `Textarea` と `Button`（コピー用）を配置。
    - [x] **下部: AI提案エリア**
        - [x] 「AIが生成したタイトル案」として、クリック可能なリスト形式のプレースホルダーを5つ程度作成する。
        - [x] 「AIが生成した概要欄」として、テキストブロックのプレースホルダーを作成する。

- **T-04: フロントエンド内でのUIロジック実装**
    - [x] 「生成する」ボタンをクリックした際に、AI提案エリアに静的なプレースホルダーが表示されるようにする（ローディングアニメーションもどきを挟むとより良い）。
    - [x] AI提案エリアのタイトル案リストをクリックすると、そのテキストが「最終タイトル」の `Input` にコピーされる機能を実装する。
    - [x] ページ読み込み時（または生成時）に、AI提案エリアの概要欄プレースホルダーが「最終概要欄」の `Textarea` にコピーされる機能を実装する。

## MVPフェーズ（資金調達後の実装範囲）
**目標:** 雛形にバックエンドとAIの機能を接続し、実際に価値を提供できる最小限の製品を完成させる。

- **T-05: 履歴管理機能（低コストで実装可能）**
    - [ ] **バックエンド:**
        - [ ] 生成セッション（入力内容、AI提案、最終編集内容）を保存・取得するためのAPIエンドポイントを実装する（Supabase/Firebase等のBaaSを利用）。
    - [ ] **フロントエンド:**
        - [ ] コントロールパネルに「履歴」タブを追加する。
        - [ ] 過去の生成セッションをリスト表示するUIを作成する。
        - [ ] 履歴リストの項目をクリックすると、そのセッションの内容が編集画面に復元される機能を実装する。

- **T-06: AI連携による生成機能（※要資金調達）**
    - [ ] **バックエンド:**
        - [ ] 大規模言語モデル（GPTなど）のAPIを呼び出すためのサービスを実装する。
        - [ ] フロントエンドから受け取った動画情報（テーマ、キーワード等）を元に、AIへの適切なプロンプトを生成するロジックを構築する。
        - [ ] AIからの応答をパースし、タイトル案リストと概要欄としてフロントエンドに返すAPIエンドポイントを実装する。
    - [ ] **フロントエンド:**
        - [ ] 「生成する」ボタンのクリック時に、コントロールパネルの入力内容をバックエンドAPIに送信する。
        - [ ] API通信中は、ボタンを無効化し、ローディングスピナーやスケルトン表示を実装する。
        - [ ] APIから受け取ったタイトル案と概要欄を動的に画面に描画する。
