# イベント・コラボレーション管理ツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが企画、日程、タスクを管理するインターフェース。
- **バックエンド（APIサーバー）**: データの管理、通知、外部APIとの連携を処理する。
- **リアルタイム通信サーバー**: チャットやドキュメントの共同編集を可能にする。
- **外部API**: 各SNSから情報を取得し、告知を自動化する。

### PC（ブラウザ）表示
プロジェクト管理ツールのように、各機能（日程調整、タスクリスト、ドキュメント）をタブやサイドバーで切り替えられるレイアウトを基本とする。カレンダーやタスクリストは全体像が把握しやすいように表示する。

### スマホ表示
主要な機能（チャット、タスクの進捗確認）に絞り、縦にスクロールするシンプルなレイアウトを採用する。重要な通知はプッシュ通知で届くようにする。

## 2. 主要機能詳細

### 2-1. プロジェクト管理機能
- **ユーザーアクション**:
    - **プロジェクト作成**: 新しいコラボ企画やイベントのプロジェクトを作成する。
    - **メンバー招待**: 企画に参加するVTuberを招待する。
- **システム動作**:
    1. バックエンドがプロジェクト情報とメンバーリストをデータベースに保存。
    2. 招待されたメンバーに通知を送信する。

### 2-2. 日程調整機能
- **ユーザーアクション**:
    - **候補日入力**: 配信や打ち合わせの候補日を複数入力する。
- **システム動作**:
    1. バックエンドがメンバーの公開スケジュール（連携されたGoogleカレンダーなど）を基に、全員が参加可能な日時を自動で抽出し、提案する。

### 2-3. タスク・ドキュメント管理機能
- **ユーザーアクション**:
    - **タスク作成**: 「台本作成」「告知画像制作」などのタスクを作成し、担当者と期限を割り当てる。
    - **ドキュメント共同編集**: 企画書や台本をツール内で共同編集する。
- **システム動作**:
    1. バックエンドがタスクの進捗状況をデータベースで管理し、期限が近づくと通知を送信する。
    2. リアルタイム通信サーバーがドキュメントの共同編集を可能にする。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **リアルタイム通信**: **WebSocket**
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**Google Calendar API**など。

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Projects**: プロジェクト情報管理（参加メンバー、ステータスなど）。
- **Tasks**: タスク情報管理（タスク名、担当者、期限、ステータスなど）。
- **Schedules**: 日程調整に関するデータ管理。
- **Documents**: 企画書や台本などの共同編集ドキュメントの管理。
