# サムネイル自動生成ツール 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが操作するウェブインターフェース。
- **バックエンド（APIサーバー）**: フロントエンドからのリクエストを処理し、AIモデルや外部APIと連携する。
- **AIモデル**: 動画解析、キーワード抽出、デザイン生成を行うコアエンジン。
- **外部API**: YouTube Data APIから動画データを取得する。

### PC（ブラウザ）表示
広さのある画面を活かし、動画のアップロードエリアと、自動生成された複数のサムネイル候補を並べて表示するレイアウトを基本とする。各サムネイルをクリックすると、詳細なカスタマイズ画面に遷移する。

### スマホ表示
画面サイズに合わせて、動画アップロードエリアを上部に配置し、生成されたサムネイル候補を縦にスクロールして見られるようにする。編集機能は、タップしやすいようにUIを最適化する。

## 2. 主要機能詳細

### 2-1. サムネイル自動生成機能
- **ユーザーアクション**:
    - **動画アップロード**: 編集が完了した動画ファイルをアップロードする。
    - **キーワード入力（任意）**: タイトルや強調したいキーワードを手動で入力する。
    - **生成**: ボタンをクリックして、サムネイルの生成をリクエストする。
- **システム動作**:
    1.  バックエンドがアップロードされた動画ファイルとユーザーの入力を受け取る。
    2.  AIモデルが、動画の内容（音声、映像、テキスト）を解析し、最適なハイライトシーンとキーワードを自動で抽出する。
    3.  抽出した情報と、予め用意されたデザインテンプレートを組み合わせて、複数のサムネイル候補を生成する。
    4.  生成されたサムネイル候補を、UIに表示する。

### 2-2. カスタマイズ・ダウンロード機能
- **ユーザーアクション**:
    - **サムネイル選択**: 生成されたサムネイル候補から一つを選ぶ。
    - **カスタマイズ**: テキストの変更、フォントの選択、ロゴの配置などを調整する。
    - **ダウンロード**: ボタンをクリックして、最適化されたサムネイル画像をダウンロードする。
- **システム動作**:
    1.  フロントエンドでユーザーの編集内容をリアルタイムで反映する。
    2.  ユーザーがダウンロードをリクエストすると、選択された画像を高解像度で出力し、ダウンロードを許可する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**（画像認識、自然言語処理、画像生成モデル）
- **データベース**: **MongoDB**または**PostgreSQL**
- **外部連携**: **YouTube Data API v3**

## 4. データベース設計
- **Users**: ユーザー情報管理
- **Videos**: アップロードされた動画情報管理（動画ID、タイトルなど）
- **GeneratedThumbnails**: 生成されたサムネイルの履歴（関連する動画ID、生成日時など）
- **DesignTemplates**: デザインテンプレート情報管理
