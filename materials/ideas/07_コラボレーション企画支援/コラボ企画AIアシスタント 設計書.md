# コラボ企画AIアシスタント 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーがコラボ相手を検索し、企画案を生成するインターフェース。
- **バックエンド（APIサーバー）**: 外部APIからのデータ取得、AIモデルとの連携を管理する。
- **AIモデル**: チャンネルのデータ分析、相性診断、企画案の生成を行う。
- **外部API**: YouTube Data APIなどから各VTuberのデータを取得する。

### PC（ブラウザ）表示
VTuberの検索フォームを上部に配置し、検索結果として複数の候補とその相性スコアをカード形式で表示するレイアウトを基本とする。詳細画面では、そのVTuberのデータと、AIが生成した企画案を一覧で表示する。

### スマホ表示
検索フォームを上部に配置し、結果を縦にスクロールして見られるようにする。AIが生成した企画案は、各VTuberのプロフィールページで折りたたみ可能な形式で表示する。

## 2. 主要機能詳細

### 2-1. コラボ相手検索・相性診断機能
- **ユーザーアクション**:
    - **VTuber検索**: ジャンル、活動時間、登録者数などの条件でコラボ相手を検索する。
    - **相性診断**: 検索結果から特定のVTuberを選び、相性診断をリクエストする。
- **システム動作**:
    1.  バックエンドがYouTube Data APIを通じて、指定されたVTuberの公開データ（チャンネル登録者数、再生回数、動画ジャンルなど）を取得する。
    2.  AIモデルが、ユーザー自身のチャンネルデータと、候補VTuberのデータを比較し、相性スコアを算出する。
    3.  相性の根拠（例: 「視聴者層が似ている」「人気コンテンツのジャンルが重なっている」など）も合わせてUIに表示する。

### 2-2. 企画案自動生成機能
- **ユーザーアクション**:
    - **企画案生成**: 相性の良いVTuberを選び、企画案の生成をリクエストする。
- **システム動作**:
    1.  バックエンドが、2つのチャンネルのデータをAIモデルに渡す。
    2.  AIモデルが、両チャンネルの人気動画や視聴者層を分析し、両方のファンが楽しめるようなユニークなコラボ企画案を複数生成する。
    3.  生成された企画案を、テーマ、形式（例: ゲーム、雑談、歌）とともにUIに表示する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**（自然言語処理、データ分析モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Channels**: VTuberチャンネルの公開データ（登録者数、動画ジャンルなど）をキャッシュして管理。
- **GeneratedProposals**: 生成された企画案の履歴管理。
