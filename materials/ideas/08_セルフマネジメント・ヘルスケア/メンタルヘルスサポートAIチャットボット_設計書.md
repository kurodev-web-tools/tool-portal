# メンタルヘルスサポートAIチャットボット 設計書

## ツール名
メンタルヘルスサポートAIチャットボット

## カテゴリ
08_セルフマネジメント・ヘルスケア

## 目的
VTuberが抱える特有の精神的ストレスや課題に対し、匿名かつ手軽にアクセスできるAIチャットボットを通じて、メンタルヘルス維持・向上を支援する。心理学的アプローチに基づいた対話と、必要に応じた専門機関への連携により、VTuberの活動継続とウェルビーイングに貢献する。

## 機能要件
### 1. 匿名チャットインターフェース
*   Webベースまたは専用アプリケーションでのチャットインターフェース
*   ユーザーの匿名性を確保するための設計（個人特定情報の収集制限、セッションベースのデータ管理など）

### 2. 対話エンジン
*   **自然言語理解（NLU）:** ユーザーの入力テキストから意図、感情、キーワードを正確に抽出
*   **対話管理:** ユーザーの状況や過去の対話履歴に基づき、適切な応答を生成
*   **感情認識・共感:** ユーザーの感情状態を認識し、共感的なメッセージを生成
*   **心理学的アプローチ:** 認知行動療法（CBT）、解決志向ブリーフセラピー、マインドフルネスなどの要素を対話フローに組み込む

### 3. ストレス解消・リラクゼーション提案
*   ユーザーの感情状態や相談内容に応じたストレス解消法（例：深呼吸、ストレッチ、気分転換のアイデア）を提案
*   リラクゼーション音声ガイド、瞑想ガイドの提供
*   ポジティブな思考を促すメッセージの生成

### 4. 進捗トラッキング・気分記録
*   ユーザーが自身の気分やストレスレベルを日次で記録できる機能（例：5段階評価、簡単な日記）
*   記録されたデータのグラフ表示による変化の可視化
*   定期的な気分記録のリマインダー設定

### 5. 専門機関連携・案内
*   AIの対応範囲を超える深刻な悩みや、専門的なサポートが必要と判断された場合、提携するカウンセリング機関、精神科医、公的相談窓口などの情報を案内
*   案内先の情報（連絡先、営業時間、専門分野など）を詳細に提供

### 6. 情報提供
*   メンタルヘルスに関する基礎知識、ストレスマネジメント、睡眠、栄養などに関するコラムや記事の提供
*   VTuberの活動における特有のストレス要因とその対処法に関する情報

## 非機能要件
*   **性能:** ユーザーの入力に対する応答速度は3秒以内（目標）。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** ユーザーの対話内容、記録データは厳重に暗号化され、プライバシーが最大限に保護されること。匿名性の維持。
*   **拡張性:** 新しい心理学的アプローチ、コンテンツ、専門機関情報の追加に対応できるアーキテクチャ。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいチャットインターフェース。緊急時の対応フローの明確化。

## システム構成
*   **フロントエンド:** React / Vue.js (Webアプリケーション)
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **AI対話エンジン:** 大規模言語モデル（LLM）API利用（例：OpenAI GPTシリーズ, Claude）または、カスタムNLU/NLGモデル
*   **データベース:** PostgreSQL / MongoDB (対話履歴、気分記録、専門機関情報)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **UserSession:** `session_id`, `start_time`, `end_time`, `last_interaction_time` (匿名性を維持するため、ユーザー特定情報は含まない)
*   **Message:** `id`, `session_id`, `sender` (user/bot), `text`, `timestamp`, `sentiment` (AI解析結果)
*   **MoodRecord:** `id`, `session_id`, `date`, `mood_level`, `notes`
*   **Resource:** `id`, `type` (article/audio/video), `title`, `content_url`, `description`
*   **ProfessionalContact:** `id`, `name`, `type` (counselor/psychiatrist), `phone`, `website`, `specialty`, `region`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** Transformers, NLTK, spaCy (カスタムモデルの場合)
*   **データベース:** PostgreSQL
*   **認証:** セッション管理 (匿名性維持のため)

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 匿名チャットインターフェース、基本的な感情認識と共感応答、ストレス解消法提案（テキストベース）。
*   **フェーズ2:** 進捗トラッキング・気分記録、リラクゼーション音声ガイド、専門機関案内機能。
*   **フェーズ3:** より高度な心理学的アプローチの導入、情報提供コンテンツの拡充、VTuber活動ログとの連携（オプション）。
