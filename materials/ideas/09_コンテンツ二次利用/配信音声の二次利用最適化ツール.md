# 配信音声の二次利用最適化ツール

## 1. ツールの目的・概要
- **目的**: 配信アーカイブの音声を、ポッドキャストやラジオコンテンツとして聴きやすい形式に自動で最適化する。
- **ターゲット**: 配信の音声を活用して新たなコンテンツを作成したいVTuber。
- **価値**: 手間のかかる音声編集作業を自動化し、コンテンツの生産性を高める。

## 2. 主要な機能
- **音声分離**: 配信音声から、VTuberの声、ゲーム音、BGM、効果音などをAIが自動で分離。
- **ノイズ・不要音除去**: 分離した音声データから、ゲーム音やBGMを自動で除去。
- **自動編集**: 不要な沈黙部分をカットし、音声レベルを均一化することで、聴きやすいラジオ形式に編集。
- **音声出力**: 最適化された音声をMP3などの形式で出力。
- **音源管理**: 過去の配信音声ファイルを管理し、必要な部分だけを再利用できるようにする。

## 3. 技術的な側面
- **AI/ML**: 音声分離（Source Separation）やノイズリダクション技術を使用。
- **API**: YouTube Data APIから配信アーカイブの音声データを取得。
- **言語/フレームワーク**: Python（AI/ML）、FFmpeg（音声処理）。

## 4. 収益モデル
- **月額課金**: 無料で利用できる処理時間に制限を設け、無制限の利用は有料プランとする。

## 5. 開発ロードマップ
- **MVP（第一段階）**: VTuberの声とそれ以外の音声を分離し、後者を削除する機能に絞って開発。
- **第二段階**: 自動編集機能（沈黙カット、音量均一化）を追加。
- **第三段階**: ユーザーが手動で不要な部分を指定して削除できる機能や、より高度なAIモデルを導入する。
