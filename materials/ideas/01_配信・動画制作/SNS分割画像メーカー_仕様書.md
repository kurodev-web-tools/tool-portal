## 2. 概要

- **目的:** X投稿向けに、分割画像の生成と境界ずれ調整を一体化し、投稿順まで含めて出力できるツールを提供する。
- **ターゲットユーザー:** 告知/企画投稿で分割画像を運用したいVTuber。
- **MVP方針:** X向け16:9中心、完全準拠MVP（`1+8` / `1+4`）を同時提供する。

## 4. 画面仕様（MVP）

### 4.1 主要画面

1. **モード選択画面**
- `1+8連結` / `1+4差し替え` を選択する。

2. **素材入力画面**
- モードに応じた必須スロットへ画像を割り当てる。

3. **編集・調整画面**
- 左: プレビュー（サムネ見え方/投稿並び）
- 右: 微調整パネル（位置/スケール/境界）

4. **出力画面**
- 4枚を個別ダウンロードする。

### 4.2 画面遷移

- モード選択 → 素材入力 → 編集・調整 → 出力
- 編集・調整 ↔ 素材入力（差し替え再入力）

## 5. 詳細機能仕様

### F-01 モード選択

- **入力:** モード種別（`modeA_1plus8` / `modeB_1plus4`）
- **出力:** 必須素材スロット構成を切り替える

### F-02 素材入力

- **対応形式:** PNG/JPEG
- **容量制限:** 1ファイル20MB以下
- **枚数制約:**
  - 1+8: 分割元1、上4、下4（合計9）
  - 1+4: ベース1、差し替え4（合計5）
- **失敗時:** スロット単位でエラー表示（形式不正、容量超過、不足）

### F-03-01 4分割出力生成

- **処理:** 画像を4領域（左上/右上/左下/右下）に分割
- **順序固定:** 投稿順 `1→2→3→4`
- **境界補正:** 微調整値を反映して分割線位置を計算

### F-03-02 モード別合成

- **1+8連結:** 各分割タイルの上下に対応素材を合成
- **1+4差し替え:** ベース画像上の各分割領域へ差し替え素材を合成
- **出力:** 各分割タイルごとに最終画像を生成

### F-04 微調整エディタ

- **調整項目:**
  - X/Yオフセット
  - スケール
  - 分割線位置
  - 境界補正
  - 境界線太さ/色
  - 上下連結高さ比率
- **反映:** 調整時に即時プレビュー更新

### F-05 プレビュー確認

- **サムネ見え方:** 4分割の縮小見え方を表示
- **投稿並び:** 1→4順で表示し、接合ずれを確認
- **目的:** 調整→確認→再調整の反復

### F-06-01 連番命名出力

- **出力形式:** PNG/JPEG
- **ファイル名:** `split-YYYYMMDD-HHMMSS_01` 〜 `_04`
- **保存方式:** 4枚個別ダウンロード

### F-07 下書き保存/復元

- **保存キー:** `v-streamer-tools:sns-split-maker:draft:v1`
- **保存単位:** モード、調整値、出力設定、最終更新時刻
- **復元タイミング:** 起動時
- **破損時:** 初期状態へフォールバック

## 6. データ保存仕様

- 保存方式: `localStorage`
- キー: `v-streamer-tools:sns-split-maker:draft:v1`
- JSON構造（要点）:
  - `version`
  - `mode`
  - `adjustments`
  - `exportFormat`
  - `updatedAt`

## 7. 非機能要件

| 項目 | 内容 |
| :--- | :--- |
| パフォーマンス | 調整操作のプレビュー反映は300ms以内を目標とする。 |
| 対応ブラウザ | Chrome / Edge / Firefox / Safari の最新版。 |
| 出力信頼性 | 4枚の順序・命名規則が常に一致すること。 |
| 制限 | MVP対象比率はX向け16:9中心。 |

## 8. MVP非対応

- AI生成
- 有料API連携
- SNS API直接投稿
- 認証必須機能
- ZIP一括ダウンロード
- X以外の比率最適化テンプレート

## 9. 受け入れ条件（Acceptance）

- 1+8連結と1+4差し替えの両モードで4枚出力できる。
- 位置/スケール/境界調整がプレビューへ反映される。
- 投稿順 `1→2→3→4` で連番命名出力される。
- 下書き保存後に再読み込みで復元できる。
