# ファンコンテンツ共有プラットフォーム 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ファンがコンテンツを投稿し、閲覧するウェブインターフェース。
- **バックエンド（APIサーバー）**: 投稿、閲覧、評価、通知を管理する。
- **AIモデル**: 投稿されたコンテンツ（画像、動画）の解析、VTuberとの関連付けを行う。
- **データベース**: 投稿コンテンツ、ユーザー、VTuber情報を保存する。

### PC（ブラウザ）表示
Pinterestのようにカード形式でコンテンツを一覧表示し、クリックすると詳細ページに遷移するレイアウトを基本とする。VTuberやジャンルごとのフィルタリング、検索機能をサイドバーに配置する。

### スマホ表示
画面サイズに合わせて、コンテンツを縦にスクロールして見られるシンプルなグリッドレイアウトを採用する。投稿ボタンは画面下部に固定し、アクセスしやすくする。

## 2. 主要機能詳細

### 2-1. コンテンツ投稿・管理機能
- **ユーザーアクション**:
    - **コンテンツ投稿**: ファンアート（イラスト）、切り抜き動画、MMD作品などをアップロードし、タイトルや説明文、タグを設定する。
- **システム動作**:
    1. バックエンドが投稿されたコンテンツとメタデータを受け取り、データベースに保存する。
    2. AIモデルがコンテンツを解析し、VTuberや関連するタグを自動で提案する。

### 2-2. 閲覧・交流機能
- **ユーザーアクション**:
    - **コンテンツ閲覧**: 投稿されたコンテンツを検索、フィルタリングして閲覧する。
    - **リアクション・コメント**: 気に入ったコンテンツに「いいね」をつけたり、コメントをしたりする。
    - **VTuberからのリアクション**: VTuberが「いいね」やお気に入りに追加すると、通知が届く。
- **システム動作**:
    1. バックエンドが閲覧、リアクション、コメントのデータをリアルタイムで処理し、人気ランキングや関連コンテンツを生成する。
    2. VTuberからのアクションは、投稿者へ通知されるようにする。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**（画像認識、音声認識モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**X API v2**など。

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Contents**: 投稿されたコンテンツ情報管理。
- **Reactions**: 「いいね」などのリアクション履歴管理。
- **Comments**: コメント情報管理。
- **Tags**: コンテンツに付けられたタグ情報管理.
