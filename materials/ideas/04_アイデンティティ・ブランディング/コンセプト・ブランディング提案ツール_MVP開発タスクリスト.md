# コンセプト・ブランディング提案ツール MVP開発タスクリスト

## 概要
このタスクリストは、「コンセプト・ブランディング提案ツール」の雛形（フロントエンドの骨格）およびMVP（Minimum Viable Product）を開発するためのものです。
AI連携などコストのかかる機能は「MVPフェーズ」に切り分け、資金調達後の実装を想定しています。

---

## 雛形フェーズ（コストゼロでの実装範囲）
**目標:** AIやバックエンドのロジックなしで、ツールの主要なUIコンポーネントを静的に構築する。

- [x] **T-01: 基本的なページ構造のセットアップ**
    - [x] `vtuber-tools-portal` プロジェクト内に、ツール用の新しいルートを作成する (`/tools/branding-generator`)。
    - [x] `page.tsx` ファイルを作成し、基本的なコンポーネントを配置する。
    - [x] `shadcn/ui` の `Resizable` コンポーネントなどを使用し、左7割（結果表示エリア）と右3割（コントロールパネルエリア）のレイアウトを実装する。

- [x] **T-02: 活動状況選択画面のUI作成**
    - [x] ツール初回アクセス時に表示される想定の「あなたの現在の活動状況は？」という問いかけと、以下の2つの選択肢を持つUIを静的に作成する。
        - [x] 選択肢1: 『既に活動している / 準備中』
        - [x] 選択肢2: 『これから活動を始める（準備前）』

- [x] **T-03: コントロールパネルのUI作成（雛形）**
    - [x] **『既に活動している / 準備中』選択時のパネル:**
        - [x] 「YouTubeアカウントを連携」「Xアカウントを連携」ボタンを配置（機能は未実装）。
        - [x] 「自己紹介・活動内容」を入力するための `Textarea` を配置。
        - [x] 「分析を開始する」ボタンを配置（機能は未実装）。
    - [x] **『これから活動を始める（準備前）』選択時のパネル:**
        - [x] 「目指すVTuber像」「活動ジャンル」「立ち絵のイメージ」の入力フォームを配置。
        - [x] 「分析を開始する」ボタンを配置（機能は未実装）。

- [x] **T-04: 結果表示エリアのUI作成（雛形）**
    - [x] **分析結果表示エリア:**
        - [x] 分析結果のサマリー、キーワード、グラフなどが表示される領域をプレースホルダーとして作成する。
    - [x] **コンセプト提案表示エリア:**
        - [x] 生成されたコンセプトが複数表示されることを想定し、カード形式のレイアウトを2〜3個静的に作成する。各カードにはコンセプト名、概要、キーワードのプレースホルダーを含める。
    - [x] **カラーパレット提案表示エリア:**
        - [x] 生成されたカラーパレットが複数表示されることを想定し、カード形式のレイアウトを2〜3個静的に作成する。各カードには色見本（5色程度）とHEXコードのプレースホルダーを含める。
        - [x] カラーパレット編集用のボタンを配置（機能は未実装）。

## MVPフェーズ（資金調達後の実装範囲）
**目標:** 雛形にバックエンドとAIの機能を接続し、実際に価値を提供できる最小限の製品を完成させる。

- [ ] **T-05: 提案の保存・履歴機能（低コストで実装可能）**
    - [ ] **バックエンド:**
        - [ ] 提案内容（コンセプト名、カラーパレットなど）を保存・取得するためのAPIエンドポイントを実装する（Supabase/Firebase等のBaaSを利用）。
    - [ ] **フロントエンド:**
        - [ ] コントロールパネルに「提案を保存」ボタンを実装する。
        - [ ] 保存時に提案名を入力するためのモーダルダイアログを作成する。
        - [ ] サイドパネルに「保存済み提案」タブを追加し、保存した提案をリスト表示する。
        - [ ] 履歴リストの項目をクリックすると、保存した内容が結果表示エリアに復元される機能を実装する。

- [ ] **T-06: AI連携と分析・提案機能（※要資金調達）**
    - [ ] **バックエンド:**
        - [ ] YouTube Data API, X APIとのOAuth連携を実装する。
        - [ ] 外部APIから取得したデータを処理し、AIモデルへの入力として整形するパイプラインを構築する。
        - [ ] AIモデル（自然言語処理、クラスタリング）をホスティングまたはAPI経由で連携し、分析APIを実装する。
        - [ ] コンセプト生成AIモデルを連携し、提案APIを実装する。
        - [ ] カラーパレット生成AIモデルを連携し、提案APIを実装する。
    - [ ] **フロントエンド:**
        - [ ] 「アカウント連携」「分析を開始する」「コンセプトを提案する」などのボタンに、対応するバックエンドAPIを接続する。
        - [ ] API通信中にローディングスピナーやスケルトン表示を実装する。
        - [ ] APIから取得した分析結果、コンセプト、カラーパレットを動的に画面に描画する。
