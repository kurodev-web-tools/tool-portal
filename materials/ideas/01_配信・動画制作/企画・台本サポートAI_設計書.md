# 企画・台本サポートAI 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが操作するウェブインターフェース。
- **バックエンド（APIサーバー）**: フロントエンドからのリクエストを処理し、AIモデルや外部APIと連携する。
- **AIモデル**: 企画案や台本骨子の生成を行うコアエンジン。
- **外部API**: 外部サービスからデータを取得する。

### PC（ブラウザ）表示
広さのある画面を活かし、入力フォームと生成された結果を左右に並べる二列レイアウトを基本とする。

### スマホ表示
画面サイズに合わせて、入力フォーム、結果表示、設定項目を縦に並べるシングルカラムレイアウトを採用する。重要なボタンや入力欄はタップしやすい大きさに設計する。

## 2. 主要機能詳細

### 2-1. 企画案自動生成機能
- **ユーザーアクション**:
    - **キーワード入力**: 「ゲーム実況」「雑談」「歌」などのキーワードを入力する。
    - **ペルソナ設定**: 既存のキャラクター設定を選択するか、新しい設定を簡単に入力する。
    - **生成**: ボタンをクリックして、企画案の生成をリクエストする。
- **システム動作**:
    1.  バックエンドが入力データを受信する。
    2.  バックエンドはYouTube Data APIやX APIを通じて、入力キーワードに関連する最新トレンドデータを取得する。
    3.  AIモデルに、ユーザーのペルソナ情報、入力キーワード、最新トレンドデータを渡し、複数の企画案を生成させる。
    4.  生成された企画案を、UIに表示する。

### 2-2. 台本骨子作成機能
- **ユーザーアクション**:
    - **企画案選択**: 生成された企画案から一つを選ぶ。
    - **台本生成**: ボタンをクリックして、台本骨子の生成をリクエストする。
- **システム動作**:
    1.  バックエンドが選択された企画案の詳細を受け取る。
    2.  AIモデルが、企画案を基に「導入」「本題」「結論」といったパートに分けた台本の骨子を生成する。
    3.  生成された台本骨子を、ユーザーが編集可能な形式でUIに表示する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**、**PyTorch**
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**X API v2**

## 4. データベース設計
- **Users**: ユーザー情報管理
- **Personas**: キャラクターペルソナ情報管理（ユーザーと関連付け）
- **GeneratedIdeas**: 生成された企画案の履歴（ユーザー、キーワード、日時など）
- **GeneratedScripts**: 生成された台本の履歴（関連する企画ID、内容など）
