# 統合アナリティクスダッシュボード 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーが操作するダッシュボード。
- **バックエンド（APIサーバー）**: 外部APIからデータを取得・集計し、フロントエンドに提供する。
- **AIモデル**: データの分析や予測を行うコアエンジン。
- **外部API**: 各プラットフォームからデータを取得する。

### PC（ブラウザ）表示
広さのある画面を活かし、複数のグラフ、チャート、KPI（重要業績評価指標）を並べて表示するマルチカラムレイアウトを基本とする。各ウィジェットはドラッグ＆ドロップで配置を変更できるように設計する。

### スマホ表示
画面サイズに合わせて、主要なKPIを上部に配置し、その下にグラフを縦にスクロールして見られるようにするシングルカラムレイアウトを採用する。

## 2. 主要機能詳細

### 2-1. 収益・データ統合機能
- **ユーザーアクション**:
    - **アカウント連携**: YouTube、FANBOX、BOOTHなどのアカウントを連携させる。
- **システム動作**:
    1.  バックエンドが各プラットフォームのAPIを通じて、収益、再生数、チャンネル登録者数、売上などのデータを定期的に取得する。
    2.  取得したデータをデータベースに保存し、正規化・集計する。
    3.  統合されたデータをダッシュボードに表示する。

### 2-2. リアルタイムデータ可視化機能
- **ユーザーアクション**:
    - **ダッシュボード閲覧**: ログイン後、リアルタイムで更新されるデータを確認する。
- **システム動作**:
    1.  バックエンドは、リアルタイムAPIやWebSocketsを利用して、最新の視聴者数やスパチャ、コメントなどのデータを取得し、フロントエンドにプッシュする。
    2.  これにより、ダッシュボード上のグラフや数値がリアルタイムで更新される。

### 2-3. 成長予測・インサイト提供機能
- **ユーザーアクション**:
    - **レポート生成**: ボタンをクリックして、特定の期間の成長予測レポートを生成する。
- **システム動作**:
    1.  バックエンドが蓄積された過去のデータとAIモデルを利用し、将来の成長を予測する。
    2.  AIモデルは、視聴者の動向、人気コンテンツ、市場トレンドなどを分析し、成長を加速させるためのインサイトや具体的なアクションプランを提案する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**Scikit-learn**、**TensorFlow**（時系列分析、予測モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**FANBOX API**、**BOOTH API**など

## 4. データベース設計
- **Users**: ユーザー情報管理
- **IntegratedData**: 各プラットフォームから取得した統合データ管理
- **GrowthPrediction**: 成長予測モデルの結果を保存
- **InsightReports**: 生成されたインサイトレポートを保存
