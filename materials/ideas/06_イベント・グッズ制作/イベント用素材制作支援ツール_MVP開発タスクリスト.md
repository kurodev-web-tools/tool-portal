# イベント用素材制作支援ツール MVP開発タスクリスト

## 概要
このタスクリストは、「イベント用素材制作支援ツール」の雛形（フロントエンドの骨格）およびMVP（Minimum Viable Product）を開発するためのものです。
**DOMベースのレイヤー操作と`html-to-image`による画像生成機能の実装を目指します。**

---

## 雛形フェーズ（フロントエンドでの実装範囲）
**目標:** バックエンドの画像生成処理なしで、クライアントサイドで完結する基本的な画像編集・プレビュー機能を構築する。

- **T-01: 基本的なページ構造のセットアップ**
    - [x] `vtuber-tools-portal` プロジェクト内に、ツール用の新しいルートを作成する (`/tools/asset-creator`)。
    - [x] `page.tsx` ファイルを作成し、基本的なコンポーネントを配置する。
    - [x] `shadcn/ui` の `Resizable` コンポーネントを使用し、左7割（プレビュー・編集エリア）と右3割（コントロールパネルエリア）のレイアウトを実装する。

- **T-02: テンプレート選択画面のUI作成とアスペクト比切り替え機能**
    - [x] ツール初期画面として、テンプレートを一覧表示するギャラリーを作成する。
    - [x] 「ロゴ」「キービジュアル」「待機画面」などで分類するタブを配置する。
    - [x] 静的なプレースホルダー画像を用いて、複数のテンプレートカードを配置する。
    - [x] **サイドパネルにアスペクト比切り替えUI（プリセット比率と手動設定）を実装する。**

- **T-03: コントロールパネルのUI作成**
    - [x] 右側のパネルに、編集操作を行うためのUIを配置する。
        - [x] **テキスト編集:** テキスト内容、フォント、サイズ、色などのUIを配置。
        - [x] **画像編集:** 画像追加ボタンを配置。
        - [x] **図形追加:** 四角、円、線、矢印などの図形追加ボタンを配置。
        - [x] **スタイル設定:** レイヤー選択に応じたスタイル（塗りつぶし、枠線、太さなど）のUIを配置。

- **T-04: プレビュー・編集エリアの実装（クライアントサイド完結）**
    - [x] **DOMベースのレイヤー操作**: プレビューエリアにHTML要素を配置し、`react-rnd` を用いてテキスト、画像、図形などのレイヤーをドラッグ、リサイズ、回転可能にする。
    - [x] **テンプレート読み込み**: テンプレートカードをクリックした際に、対応するテンプレートの初期レイヤー（背景画像、テキスト要素など）をプレビューエリアに描画する機能を実装する。
    - [x] **レイヤーパネル**: レイヤーの表示/非表示、ロック/アンロック、順序変更、複製、削除などの機能を実装する。

- **T-05: ダウンロード機能（クライアントサイド完結）**
    - [x] `html-to-image` を用いて、プレビューエリアのコンテンツをPNG画像としてダウンロードする機能を実装する。
    - [x] **画質選択機能**: 「通常画質」「高画質」「最高画質」の3段階でダウンロードできるUIを実装する。
    - [x] **解像度自動計算**: 選択された画質レベルと現在のアスペクト比に基づいて、ダウンロード画像の解像度を自動計算する。

---

## MVPフェーズ（バックエンド連携と機能強化）
**目標:** テンプレートや作成した素材をサーバー側で管理し、より高度な機能を提供する。

- **T-06: テンプレート管理機能**
    - [ ] **バックエンド:**
        - [ ] テンプレート情報（画像URL、テキスト要素の初期値・位置など）を管理するためのCRUD APIを実装する（BaaSを利用）。
    - [ ] **フロントエンド:**
        - [ ] テンプレート選択画面で、静的なプレースホルダーの代わりにAPIから取得したテンプレートを動的に表示する。

- **T-07: 作成した素材の保存・履歴機能**
    - [ ] **バックエンド:**
        - [ ] ユーザーが作成した素材の状態（各オブジェクトの位置、内容、スタイルなど）をJSON形式で保存・取得するAPIを実装する（BaaSを利用）。
    - [ ] **フロントエンド:**
        - [ ] コントロールパネルに「保存」ボタンを追加する。
        - [ ] サイドパネルに「作成履歴」タブを追加し、保存した素材をリスト表示する。
        - [ ] 履歴をクリックすると、Canvasの状態が復元される機能を実装する。

- **T-08: 高解像度ダウンロード（サーバーサイド生成）**
    - [ ] **バックエンド:**
        - [ ] フロントエンドから送信されたCanvasの状態（JSON）を元に、サーバーサイドの画像処理ライブラリ（`sharp`, `Pillow`など）を使って高解像度の画像を生成し、返すAPIを実装する。
    - [ ] **フロントエンド:**
        - [ ] ダウンロードボタンに、サーバーサイド生成APIを呼び出すオプションを追加する（例：「高画質でダウンロード」）。
