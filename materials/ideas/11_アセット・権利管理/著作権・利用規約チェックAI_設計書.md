# 著作権・利用規約チェックAI 設計書

## ツール名
著作権・利用規約チェックAI

## カテゴリ
11_アセット・権利管理

## 目的
VTuberがコンテンツ制作で使用するBGM、画像、動画、フォントなどの素材が、著作権法および関連する利用規約に準拠しているかを自動で検証し、法的なリスクを未然に防ぐ。これにより、VTuberが安心してクリエイティブ活動に専念できる環境を提供する。

## 機能要件
### 1. ユーザー認証・素材管理
*   VTuberアカウントでのログイン機能
*   利用素材のアップロード（ファイル、URL）
*   素材のカテゴリ分類（BGM, 画像, 動画, フォントなど）

### 2. 著作権チェック機能
*   **音声認識・フィンガープリント:** BGMや動画の音声を解析し、既存の著作権データベース（JASRAC, NexToneなど）と照合。既知の楽曲との一致度を判定。
*   **画像認識・類似性検出:** 画像や動画のフレームを解析し、既存の著作物（イラスト、写真など）との類似性を検出。
*   **メタデータ解析:** ファイルのメタデータ（作成者、ライセンス情報など）を解析。
*   **データベース照合:** 著作権管理団体、ストック素材サイト、フリー素材サイトなどのデータベースと連携し、素材の著作権情報を照合。

### 3. 利用規約チェック機能
*   **URL解析・テキスト抽出:** 素材のダウンロード元URLから利用規約ページを特定し、テキストを抽出。
*   **自然言語処理（NLP）による解析:** 抽出した利用規約テキストをAIが解析し、以下の項目を自動で識別・評価。
    *   商用利用の可否
    *   改変の可否
    *   クレジット表記の要否と形式
    *   再配布の可否
    *   特定のプラットフォーム（YouTube, Twitchなど）での利用可否
*   **プラットフォーム規約照合:** YouTube, Twitch, TikTokなどの主要配信プラットフォームの利用規約データベースと照合し、素材の利用が各プラットフォームの規約に準拠しているかを確認。

### 4. 違反検出・警告・提案
*   著作権侵害の可能性や利用規約違反が検出された場合、具体的な問題点（例：商用利用不可の素材を使用）と警告メッセージを表示。
*   違反レベル（高、中、低）の表示。
*   **代替案提案:** 違反が検出された場合、代替となるフリー素材、または利用条件を満たす類似素材を提案。
*   **クレジット表記自動生成:** 利用可能な素材について、必要なクレジット表記のテンプレートを自動生成。

### 5. レポート・履歴管理
*   チェック結果の詳細レポート（検出された問題点、推奨されるアクションなど）
*   素材ごとのチェック履歴、ライセンス情報、警告内容の管理
*   利用素材リストのエクスポート機能

## 非機能要件
*   **性能:** 素材アップロード後、チェック結果を数分以内に表示（目標）。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** アップロードされた素材データ、ユーザーの利用履歴のプライバシー保護。著作権データベースへの安全なアクセス。
*   **拡張性:** 新しい素材形式、著作権データベース、配信プラットフォーム規約への対応。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。

## システム構成
*   **フロントエンド:** React / Next.js
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **素材解析エンジン:** Python (Librosa, OpenCV, FFmpeg)
*   **AI/MLモデル:** Hugging Face Transformers (NLP), TensorFlow / PyTorch (画像・音声認識)
*   **著作権・規約データベース:** PostgreSQL / Elasticsearch (カスタムデータベース、外部API連携)
*   **クラウドストレージ:** AWS S3 / Google Cloud Storage (アップロード素材の保存)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **User:** `id`, `username`, `email`, `hashed_password`
*   **Material:** `id`, `user_id`, `file_name`, `file_type`, `upload_date`, `source_url`, `storage_path`
*   **CheckResult:** `id`, `material_id`, `check_date`, `status` (compliant, warning, violation), `details` (JSONB), `suggested_actions` (Array)
*   **LicenseInfo:** `id`, `material_id`, `license_type`, `commercial_use`, `modification_allowed`, `credit_required`, `credit_text`

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** Librosa, OpenCV, Transformers, NLTK, spaCy
*   **データベース:** PostgreSQL, Elasticsearch
*   **ストレージ:** AWS S3

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** BGMファイルの著作権チェック（JASRAC/NexTone連携）、基本的な利用規約解析（商用利用可否、クレジット要否）。
*   **フェーズ2:** 画像・動画ファイルの著作権チェック、より詳細な利用規約解析（改変可否、再配布可否）、代替案提案機能。
*   **フェーズ3:** フォントチェック、主要配信プラットフォーム規約との照合、自動クレジット表記生成、履歴管理の強化。
