# コンテンツ二次利用最適化プラットフォーム 設計書

## 1. システム構成図
このツールは、以下の4つの主要なコンポーネントで構成される。

- **フロントエンド（UI）**: ユーザーがライセンス設定を行い、二次創作コンテンツを閲覧・管理するインターフェース。
- **バックエンド（APIサーバー）**: ライセンス情報、コンテンツの検出、収益分配を管理する。
- **AIモデル**: 著作権侵害や二次創作コンテンツを自動で検出する。
- **データベース**: ライセンス情報、検出されたコンテンツのデータなどを保存する。

### PC（ブラウザ）表示
ダッシュボード形式で、ライセンス設定、検出されたコンテンツの一覧、収益分配の状況を視覚的に表示する。

### スマホ表示
主要な機能（ライセンスのON/OFF、検出されたコンテンツの承認）に絞り、シンプルな操作性を採用する。

## 2. 主要機能詳細

### 2-1. ライセンス設定・公開機能
- **ユーザーアクション**:
    - **ライセンス設定**: VTuberが自身のコンテンツ（動画、キャラクター）ごとに二次利用の許諾範囲を設定する。
- **システム動作**:
    1.  バックエンドがライセンス情報をデータベースに保存。
    2.  ライセンス情報は公開され、ファンは簡単に確認できる。

### 2-2. 二次創作コンテンツ自動検出機能
- **ユーザーアクション**:
    - **検出結果閲覧**: AIが検出した二次創作コンテンツを一覧で確認する。
- **システム動作**:
    1.  AIモデルがYouTubeやSNSを巡回し、VTuberのキャラクターやコンテンツが含まれる動画、画像を自動で検出する。
    2.  検出されたコンテンツはデータベースに保存され、VTuberのダッシュボードに表示される。

### 2-3. 収益分配システム
- **ユーザーアクション**:
    - **収益分配設定**: 二次創作が収益化された場合の分配率を設定する。
- **システム動作**:
    1.  二次創作コンテンツの収益データ（例: YouTubeの広告収益）をAPIを通じて取得する。
    2.  設定された分配率に従って収益を自動で計算し、VTuberとクリエイター（ファン）に分配する。

## 3. 技術スタック
- **フロントエンド**: **Next.js (React)**
- **UIフレームワーク**: **Tailwind CSS**, **shadcn/ui**
- **バックエンド**: **Python (FastAPI)**
- **AI/ML**: **Python**、**TensorFlow**（画像認識、音声認識モデル）
- **データベース**: **PostgreSQL**または**MongoDB**
- **外部連携**: **YouTube Data API v3**、**X API v2**など。

## 4. データベース設計
- **Users**: ユーザー情報管理。
- **Licenses**: コンテンツごとのライセンス情報管理。
- **DetectedContents**: AIが検出した二次創作コンテンツの履歴管理。
- **RevenueSharing**: 収益分配に関するデータ管理。
