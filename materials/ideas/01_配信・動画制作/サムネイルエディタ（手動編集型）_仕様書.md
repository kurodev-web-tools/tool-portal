## 2. 概要

- **目的:** VTuber向けに、素材持ち込み前提で16:9サムネイルを素早く内製できる編集ツールを提供する。
- **ターゲットユーザー:** 個人勢VTuber、配信告知画像を自作したい配信者。
- **MVP方針:** AI/外部APIに依存せず、文字品質とレイヤー編集の実用性を優先する。

## 4. 画面仕様（MVP）

### 4.1 主要画面

1. **テンプレート選択画面**
- プリセット一覧を表示し、新規作成開始の起点とする。

2. **編集ワークスペース**
- 左: キャンバスエリア
- 右: レイヤー一覧 + プロパティパネル
- 上: キャンバス操作（新規/保存/書き出し）

3. **書き出しダイアログ**
- 形式（PNG/JPEG）選択
- 出力実行

### 4.2 画面遷移

- テンプレート選択 → 編集ワークスペース
- 編集ワークスペース → 書き出しダイアログ → 編集ワークスペース

## 5. 詳細機能仕様

### F-01-01 キャンバスサイズ選択

- **入力:** サイズ種別（`1280x720` / `1920x1080`）
- **制約:** MVPでは16:9固定
- **出力:** 新規キャンバス設定へ反映

### F-02-01 画像レイヤー追加

- **入力:** PNG/JPEGファイル
- **制約:** 1ファイル20MB以下、読み込み失敗時はエラー通知
- **処理:** キャンバス中央に初期配置
- **出力:** レイヤー一覧へ追加

### F-02-02 テキストレイヤー追加

- **入力:** 文字列
- **制約:** 1レイヤーあたり最大150文字
- **処理:** デフォルトフォント（Google Fonts）で追加
- **出力:** レイヤー一覧へ追加

### F-02-03 図形レイヤー追加

- **入力:** 図形種別（矩形/円）
- **制約:** 最小サイズ16px
- **出力:** レイヤー一覧へ追加

### F-03-01 テキストスタイル

- **入力:** フォント、サイズ、色、行間
- **制約:** フォントはプリセット登録済みGoogle Fontsのみ
- **出力:** 即時プレビューに反映

### F-03-02 基本エフェクト

- **入力:** 縁取り太さ/色、影オフセット/ぼかし/色、透明度、ぼかし強度
- **制約:** 値範囲はUIスライダーで制限
- **出力:** 即時プレビューに反映

### F-04-01 プリセット選択

- **入力:** プリセット種別（配信告知/歌枠/雑談/切り抜き）
- **処理:** 初期レイアウト、色、テキストスタイルを適用
- **出力:** 編集可能状態でワークスペースへ遷移

### F-05-01 下書き保存 / F-05-02 下書き復元

- **保存先キー:** `v-streamer-tools:thumbnail-editor:draft:v1`
- **保存単位:** キャンバス設定、レイヤー配列、プリセットID、最終更新時刻
- **復元タイミング:** ツール起動時
- **エラー時:** 破損データは破棄して初期状態で起動

### F-05-03 画像書き出し

- **入力:** 出力形式（PNG/JPEG）
- **処理:** キャンバスをラスタライズし1枚出力
- **出力:** `thumbnail-YYYYMMDD-HHMMSS.(png|jpg)`
- **失敗時:** 書き出し失敗メッセージ表示

## 6. データ保存仕様

- 保存方式: `localStorage`
- キー: `v-streamer-tools:thumbnail-editor:draft:v1`
- JSON構造（要点）:
  - `version`
  - `canvas`（幅・高さ）
  - `layers`（種類・座標・スタイル）
  - `presetId`
  - `updatedAt`

## 7. 非機能要件

| 項目 | 内容 |
| :--- | :--- |
| パフォーマンス | 主要操作（レイヤー追加、スタイル更新）は200ms以内の視覚反映を目標とする。 |
| 対応ブラウザ | Chrome / Edge / Firefox / Safari の最新版。 |
| 可用性 | 1セッション内の編集状態を下書き復元できること。 |
| 制限 | 画像素材はユーザー持ち込み前提。 |

## 8. MVP非対応

- AI生成
- 有料API連携
- SNS API直接投稿
- 認証必須機能
- 自動最適化（CTR予測など）
- ローカルフォントimport

## 9. 受け入れ条件（Acceptance）

- プリセット4種から開始し、画像/テキスト/図形を配置できる。
- 縁取り・影・透明度・ぼかしがUI操作で反映される。
- 下書き保存後、再読み込みで同じ状態に復元できる。
- PNG/JPEGを書き出せる。
