# VTuber向け法務相談チャットボット 設計書

## ツール名
VTuber向け法務相談チャットボット

## カテゴリ
05_バックオフィス・ビジネス

## 目的
VTuberが活動中に直面しうる法的な問題（著作権、肖像権、契約、誹謗中傷対策、個人情報保護など）について、AIが基本的な情報提供や相談窓口の案内を行う。法的な専門知識がなくても気軽に相談でき、適切な対応を早期に検討できるよう支援し、VTuberの法的リスクを低減する。

## 機能要件
### 1. ユーザー認証・匿名性確保
*   VTuberアカウントでのログイン機能（オプション）
*   ユーザーが匿名で相談できるセッションベースのチャット機能
*   個人特定情報を収集しない設計

### 2. チャットインターフェース
*   Webベースまたは専用アプリケーションでのチャット形式のインターフェース
*   質問入力、回答表示、関連情報リンク表示

### 3. 質問内容理解・分類
*   **自然言語理解（NLU）:** 入力された質問内容をAIが解析し、ユーザーの意図、キーワード、感情を抽出
*   **法的なカテゴリ分類:** 質問内容を法的なカテゴリ（例：著作権、肖像権、契約、誹謗中傷、個人情報保護、税務）に自動分類

### 4. 情報提供・回答生成
*   **法律知識データベース連携:** VTuberの活動に特化した法律知識データベース（著作権法、民法、刑法、プラットフォーム規約など）に基づき、質問に対する基本的な情報や回答を生成
*   **大規模言語モデル（LLM）活用:** LLMを用いて、法律用語をVTuberにも分かりやすい言葉で解説し、具体的な事例を交えて説明
*   **リスク指摘・注意喚起:** 質問内容から潜在的な法的リスクを検出し、注意喚起や予防策を提案
*   **関連情報提示:** 質問に関連するFAQ、コラム、テンプレートなどを提示

### 5. 相談窓口案内
*   AIの対応範囲を超える専門的な相談が必要な場合、提携する弁護士事務所、公的機関（例：法テラス、著作権情報センター、警察庁サイバー犯罪対策）の相談窓口を案内
*   案内先の情報（連絡先、営業時間、専門分野、費用目安など）を詳細に提供
*   オンライン相談予約システムとの連携（オプション）

### 6. 過去の相談履歴
*   ユーザーの過去の相談履歴を保存し、参照可能（匿名セッションの場合はセッションIDで管理）

### 7. FAQ・ナレッジベース
*   よくある質問とその回答をまとめたFAQやナレッジベースを提供
*   キーワード検索機能

## 非機能要件
*   **性能:** ユーザーの質問に対する応答速度は3秒以内（目標）。
*   **可用性:** サービス稼働率99.9%以上。
*   **セキュリティ:** ユーザーの相談内容、履歴データの機密性の厳重な保護。データ暗号化、アクセス制御。匿名性の維持。
*   **拡張性:** 新しい法律、判例、プラットフォーム規約、相談窓口情報の追加に対応できるアーキテクチャ。AIモデルの更新。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいチャットインターフェース。法律知識が少ないVTuberでも気軽に利用できる設計。

## システム構成
*   **フロントエンド:** React / Vue.js (Webアプリケーション)
*   **バックエンド:** Python (FastAPI) / Node.js (NestJS)
*   **AI対話エンジン:** 大規模言語モデル（LLM）API利用（例：OpenAI GPTシリーズ, Claude）または、カスタムNLU/NLGモデル
*   **法律知識データベース:** PostgreSQL / Elasticsearch (カスタムデータベース、外部API連携)
*   **クラウドプラットフォーム:** AWS / GCP / Azure

## データモデル
*   **UserSession:** `session_id`, `start_time`, `end_time`, `last_interaction_time` (匿名性を維持するため、ユーザー特定情報は含まない)
*   **Message:** `id`, `session_id`, `sender` (user/bot), `text`, `timestamp`, `legal_category` (AI解析結果)
*   **LegalKnowledge:** `id`, `category`, `question_keywords` (Array), `answer_text`, `related_laws` (Array), `example_cases` (Array)
*   **ConsultationService:** `id`, `name`, `type` (lawyer/public_org), `contact_info` (JSONB), `specialty` (Array)

## 技術スタック
*   **言語:** Python / TypeScript
*   **フレームワーク:** FastAPI / Next.js
*   **AI/MLライブラリ:** Transformers, NLTK, spaCy
*   **データベース:** PostgreSQL

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 匿名チャットインターフェース、基本的な質問内容理解、著作権・肖像権に関する情報提供、相談窓口案内。
*   **フェーズ2:** 契約、誹謗中傷対策に関する情報提供、リスク指摘・注意喚起、FAQ・ナレッジベースの拡充。
*   **フェーズ3:** 個人情報保護、税務に関する情報提供、より高度なAIによる回答生成、提携弁護士との連携強化。
