## 2. 概要

VTuberが日々の配信スケジュールを直感的に管理し、プロフェッショナルなデザインの週間スケジュール画像を簡単に生成・共有できるWebアプリケーション。

### 2.1. ターゲットユーザー

*   **メインターゲット**: 配信スケジュール管理や、告知用の画像作成に手間を感じている全てのVTuber。特に、デザインツールに不慣れな新人VTuber。
*   **サブターゲット**: 複数のイベントやコラボを管理する必要がある中堅・企業所属VTuber。

## 3. 機能要件

| ID | 機能名 | 概要 |
| :--- | :--- | :--- |
| **F-01** | **スケジュール管理** | 配信スケジュールの登録・編集・削除・表示を行う。 |
| F-01-01 | スケジュールの新規登録 | 新しい配信スケジュールを登録する。 |
| F-01-02 | スケジュールの編集 | 既存のスケジュールを編集する。 |
| F-01-03 | スケジュールの削除 | 既存のスケジュールを削除する。 |
| F-01-04 | カレンダーでの予定表示 | カレンダー形式で月間・週間の予定を表示する。 |

| **F-03** | **SNS投稿文生成** | スケジュール情報に基づいたSNS投稿文を生成する。 |
| F-03-01 | 投稿文テンプレート選択・編集 | 複数の投稿文テンプレートを選択・編集する。 |
| F-03-02 | 投稿文コピー | 生成された投稿文をクリップボードにコピーする。 |

## 4. 画面仕様

画面は主要な2つのエリアで構成される。

### 4.1. カレンダーエリア（画面左側 約7割）

*   F-01-04で定義したカレンダーを表示するメインエリア。
*   エリア上部には、「月」「週」「日」を切り替える表示モードボタンを配置する。

### 4.2. サイドパネルエリア（画面右側 約3割）

*   各種操作を行うためのカード型パネルエリア。
*   パネル上部には、以下の機能を切り替えるためのタブを設置する。
    *   **タブ1: 予定管理**
        *   選択した日付の予定一覧を表示する。
        *   一覧の各項目には「編集」「削除」ボタンを配置する（F-01-02, F-01-03）。
        *   「新規スケジュール登録」ボタンを配置する（F-01-01）。
    *   **タブ2: SNS投稿**
        *   F-03で定義したSNS投稿文生成機能のUIを表示する。

*補足: このレイアウトは主にPC表示を想定する。モバイル表示の場合は、サイドパネルエリアがモーダル（またはボトムシート）として表示されるなど、別途最適なUIを検討する。*

## 5. 詳細機能仕様

（ここに機能ごとの詳細仕様を記述）

### F-01-01: スケジュールの新規登録

*   **概要:** 新しい配信スケジュールをシステムに登録する。
*   **トリガー:** ユーザーがスケジュール管理画面で「新規登録」ボタンをクリックする。
*   **入力:** 

| 項目名 | 必須/任意 | 型 | バリデーション/制約 |
| :--- | :--- | :--- | :--- |
| タイトル | 任意 | 文字列 | 最大50文字 |
| 日付 | **必須** | Date | - |
| 時間 | 任意 | Time | 30分刻みの選択式 |
| カテゴリ | 任意 | 文字列 | ユーザーによる追加・編集・削除が可能 |
| プラットフォーム | 任意 | 文字列 | ユーザーによる追加・編集・削除が可能 |
| 備考 | 任意 | 文字列 | 最大200文字 |

*   **処理:** 
    1.  入力された値のバリデーションチェックを行う（日付が空でないか）。
    2.  エラーがなければ、一意のIDを付与してスケジュールオブジェクトを生成する。
    3.  生成したオブジェクトを`localStorage`に保存する。

*   **出力/結果:** 
    *   **成功時:** 「保存しました」というトースト通知を表示し、フォームを閉じてカレンダー表示を更新する。
    *   **失敗時:** 「日付を入力してください」というエラーメッセージをフォーム内に表示する。

*   **デフォルト値:**
    *   フォーム表示時、日付項目には「今日」の日付が、それ以外の項目は「空欄」が設定される。

### F-01-02: スケジュールの編集

*   **概要:** 既存のスケジュール情報を変更する。
*   **トリガー:** 
    *   ユーザーがカレンダーに表示されている予定をクリックする。
    *   ユーザーが「予定管理」タブの一覧で、各予定の横にある**「編集」ボタン**をクリックする。
*   **入力:** 
    *   「F-01-01: スケジュールの新規登録」と同一。ただし、フォームは選択された予定の既存データで初期化される。
*   **処理:** 
    1.  フォームが開く際、選択された予定のIDを元に`localStorage`からデータを取得し、各入力フィールドに設定する。
    2.  ユーザーが「保存」ボタンをクリックすると、F-01-01と同様のバリデーションチェック（日付が空でないか）を行う。
    3.  エラーがなければ、指定されたIDのスケジュールオブジェクトを新しい内容で更新し、`localStorage`に保存する。
*   **出力/結果:** 
    *   **成功時:** 「更新しました」というトースト通知を表示し、フォームを閉じてカレンダーおよび一覧表示を更新する。
    *   **失敗時:** F-01-01と同様のエラーメッセージを表示する。

### F-01-03: スケジュールの削除

*   **概要:** 既存のスケジュールを削除する。
*   **トリガー:** 
    *   ユーザーが「予定管理」タブの一覧で、各予定の横にある**「削除」ボタン**をクリックする。
*   **処理:** 
    1.  「この予定を削除しますか？元に戻すことはできません。」という確認ダイアログを表示する。
    2.  ユーザーが「はい」を選択した場合、対象のスケジュールデータを`localStorage`から削除する。
    3.  ユーザーが「いいえ」を選択した場合、処理を中断する。
*   **出力/結果:** 
    *   **成功時:** 「削除しました」というトースト通知を表示し、カレンダーおよび一覧表示を更新する。
    *   **キャンセル時:** 何も表示せず、ダイアログを閉じる。

### F-01-04: カレンダーでの予定表示

*   **概要:** 登録されたスケジュールをカレンダー形式で表示する。
*   **仕様詳細:**
    *   **表示モード:**
        *   「月」「週」「日」の3つの表示モードを提供し、ボタンで切り替え可能とする。
        *   デフォルトの表示モードは「月表示」とする。
    *   **表示内容:**
        *   各モードでの表示内容は以下の通りとする。
            *   **月表示:** 各日付マス内に、予定の「時間」と「カテゴリ」を表示する。
            *   **週表示:** 各予定ブロックに、「タイトル」「時間」「カテゴリ」「プラットフォーム」を表示する。
            *   **日表示:** 各予定ブロックに、「タイトル」「時間」「カテゴリ」「プラットフォーム」「備考」を全て表示する。
    *   **インタラクション:**
        *   **マウスオーバー:** ユーザーが任意の日付マスにマウスカーソルを合わせると、その日に登録されている全ての予定が一覧でポップアップ表示される。マウスカーソルがマスから外れると、ポップアップは消える。
        *   **日付選択:** ユーザーが任意の日付マスをクリックすると、その日付が「選択状態」となり、背景色が変わる。これにより、現在どの日の予定を操作しているかが明確になる。
        *   **予定クリック:** カレンダー上の各予定をクリックすると、編集フォームが開く（F-01-02の仕様に準ずる）。

### F-03-01: 投稿文テンプレートの管理

*   **概要:** SNS投稿に使用するテキストテンプレートを管理する。
*   **仕様詳細:**
    *   ユーザーはテンプレートに名前を付け、複数保存・編集・削除できる。
    *   テンプレート編集画面のテキストエリア付近に、以下の「変数を挿入」ボタンを配置する。
        *   `[タイトル]` `{title}`
        *   `[日付]` `{date}`
        *   `[時間]` `{time}`
        *   `[カテゴリ]` `{category}`
        *   `[プラットフォーム]` `{platform}`
    *   ボタンをクリックすると、カーソル位置に対応する変数が挿入される。
    *   「SNS投稿」タブ内に「ハッシュタグ管理」エリアを設け、ユーザーが頻繁に使うハッシュタグをリスト形式で追加・削除できるようにする。

### F-03-02: SNS投稿文の生成とコピー

*   **概要:** 予定とテンプレートから投稿文を生成し、クリップボードにコピーする。
*   **トリガー:** ユーザーがカレンダーで予定を選択後、「SNS投稿」タブを開く。
*   **処理:**
    1.  ユーザーがドロップダウン等で、保存済みのテンプレートを選択する。
    2.  テンプレート内の変数が、選択した予定のデータで自動的に置換される。
    3.  「ハッシュタグ管理」リストのハッシュタグがチェックボックス付きで表示され、ユーザーは投稿に含めるものを選択できる。
    4.  最終的な投稿文がプレビューエリアに表示される。
*   **出力/結果:**
    *   プレビューエリアの横に「クリップボードにコピー」ボタンを配置する。
    *   ボタンをクリックすると、「コピーしました」というトースト通知が表示され、生成されたテキストがクリップボードにコピーされる。
