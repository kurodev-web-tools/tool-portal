# キャラクターボイスチェンジャーAI 設計書

## ツール名
キャラクターボイスチェンジャーAI

## カテゴリ
01_配信・動画制作

## 目的
VTuberのキャラクター設定や感情表現に合わせた、自然で高品質なリアルタイム音声変換を提供する。これにより、VTuberの表現力を向上させ、視聴者への没入感を高めるとともに、声に関するVTuberの課題を解決する。

## 機能要件
### 1. ユーザー認証・プロファイル管理
*   VTuberアカウントでのログイン機能
*   キャラクタープロファイル登録・編集（性別、年齢、声の高さ、声質タイプ、性格など）
*   複数のキャラクタープロファイルの管理

### 2. 音声入力・出力設定
*   マイク入力デバイスの選択
*   仮想オーディオデバイスへの出力（OBS, Discordなどへの連携）
*   入出力音声のモニタリング機能

### 3. リアルタイム音声変換
*   設定されたキャラクタープロファイルに基づいたリアルタイム音声変換
*   **変換パラメータ調整:** ピッチ、フォルマント、声の太さ、響きなどの微調整
*   **低遅延処理:** 配信に影響を与えないための低遅延（目標20ms以内）

### 4. 感情表現調整
*   **手動感情調整:** 喜び、悲しみ、怒り、驚きなどの感情パラメータを手動で調整し、音声に反映
*   **自動感情認識・調整:** 入力音声からAIが感情を認識し、自動で声質やトーンを調整（オプション）

### 5. 声質プリセット管理
*   汎用的な声質プリセット（例：男性、女性、子供、ロボットなど）の提供
*   VTuberが作成したカスタム声質プロファイルの保存・読み込み
*   コミュニティでの声質プロファイル共有機能（オプション）

### 6. 学習機能（パーソナライズ）
*   VTuberの過去の配信音声データや、理想とするキャラクターボイスのサンプル音声（数分程度）をアップロードし、AIモデルをファインチューニング
*   学習進捗の表示と、学習済みモデルの選択

### 7. 音声前処理・後処理
*   ノイズリダクション、エコー除去、ゲイン調整などの入力音声前処理
*   リミッター、コンプレッサーなどの出力音声後処理

## 非機能要件
*   **性能:** リアルタイム変換における低遅延（目標20ms以内）。CPU/GPUリソースの効率的な利用。
*   **可用性:** 安定した動作、クラッシュ耐性。
*   **セキュリティ:** 音声データのプライバシー保護。学習データの安全な管理。
*   **拡張性:** 新しい音声変換モデルや感情認識モデルの追加に対応できるアーキテクチャ。
*   **保守性:** モジュール化されたコードベース、適切なドキュメンテーション。
*   **ユーザビリティ:** 直感的で分かりやすいUI/UX。配信中でも容易に設定変更できるインターフェース。
*   **互換性:** 主要な配信ソフトウェア（OBS Studio, Streamlabs OBSなど）や通話ソフトウェア（Discord, Zoomなど）との互換性。

## システム構成
*   **クライアントアプリケーション:** デスクトップアプリケーション (Electron, C++ with Qt/WPFなど)
*   **音声処理エンジン:** C++ / Python (リアルタイム音声処理ライブラリ)
*   **AI/MLモデル:** PyTorch / TensorFlow (Voice Conversionモデル, Emotion Recognitionモデル)
*   **クラウドサービス:** AWS / GCP / Azure (学習済みモデルのホスティング、ファインチューニング環境)
*   **データベース:** SQLite (ローカル設定), PostgreSQL (ユーザープロファイル、学習データ管理)

## データモデル
*   **User:** `id`, `username`, `email`, `hashed_password`
*   **CharacterProfile:** `id`, `user_id`, `profile_name`, `gender`, `age_range`, `pitch_offset`, `formant_shift`, `timbre_params`, `emotion_bias`
*   **VoiceSample:** `id`, `user_id`, `profile_id`, `sample_path`, `sample_type` (training, reference)

## 技術スタック
*   **言語:** Python, C++ (高性能な音声処理部分)
*   **フレームワーク:** PyTorch / TensorFlow (AIモデル), Electron (デスクトップアプリ)
*   **音声処理ライブラリ:** librosa, PyAudio, PortAudio
*   **AIモデル:** VITS, F0-VAE, Tacotron, WaveNet (Voice Conversion), Wav2Vec2 (Emotion Recognition)
*   **データベース:** SQLite (ローカル), PostgreSQL (クラウド)

## 開発ロードマップ（簡易版）
*   **フェーズ1 (MVP):** 基本的なリアルタイム音声変換（ピッチ、フォルマント調整）、汎用プリセット、入出力設定。
*   **フェーズ2:** キャラクタープロファイル詳細設定、手動感情調整、ノイズリダクション、学習機能（基本的なファインチューニング）。
*   **フェーズ3:** 自動感情認識・調整、より高度な学習機能、コミュニティ共有機能、他プラットフォーム連携強化。
