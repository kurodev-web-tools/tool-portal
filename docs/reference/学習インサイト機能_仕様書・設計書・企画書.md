## 🎯 企画書

### プロジェクト概要
**プロジェクト名**: VTuberツールポータル 学習インサイト機能  
**目的**: VTuberツール利用者の学習パターン分析と生産性向上支援  
**対象ユーザー**: VTuberツールポータルの利用者（VTuber、クリエイター）

### 背景・課題
- VTuberツール利用者の学習進捗が可視化されていない
- 個人の使用パターンに基づく改善提案が不足
- 目標設定と進捗管理の仕組みが不十分
- 過去の活動履歴を活用した学習最適化ができていない

### 解決策
- **パターン分析**: 使用データから学習パターンを自動分析
- **目標管理**: 個人の目標設定と進捗追跡機能
- **インサイト提供**: AI ベースの改善提案と推奨事項
- **履歴可視化**: 過去の活動データの視覚的表示

### 期待効果
- **学習効率向上**: 個人に最適化された学習パターンの発見
- **目標達成支援**: 明確な目標設定と進捗管理
- **継続的改善**: データに基づく継続的な改善提案
- **モチベーション維持**: 進捗の可視化による達成感の向上

## 📝 仕様書

### 機能要件

#### 1. 基本インサイト機能
**概要**: ユーザーの使用パターンから基本的な洞察を提供

- 生産性スコア（0-100）

**データソース**:

**表示内容**:

### データフロー設計

#### 1. データ収集フロー
```typescript
// 使用追跡
const trackUsage = (toolId: string, duration: number) => {
  const pattern: UsagePattern = {
    toolId,
    timestamp: Date.now(),
    duration,
    context: getTimeContext(new Date().getHours()),
    dayOfWeek: new Date().getDay(),
    frequency: 1,
  };
  
  saveUsagePattern(pattern);
  analyzePatterns();
};
```

#### 2. インサイト生成フロー
```typescript
// パターン分析
const analyzePatterns = (patterns: UsagePattern[]) => {
  const insights = {
    favoriteTools: calculateFavoriteTools(patterns),
    peakUsageTimes: calculatePeakTimes(patterns),
    productivityScore: calculateProductivityScore(patterns),
    recommendations: generateRecommendations(patterns),
  };
  
  setInsights(insights);
};
```

#### 3. 目標管理フロー
```typescript
// 目標設定
const setUserGoals = (goals: UserGoals) => {
  localStorage.setItem('user-goals', JSON.stringify(goals));
  updateProgressTracking(goals);
};

// 進捗追跡
const updateProgressTracking = (goals: UserGoals) => {
  const currentProgress = calculateCurrentProgress();
  const achievementRate = (currentProgress / goals.target) * 100;
  
  setProgressData({
    current: currentProgress,
    target: goals.target,
    achievementRate,
  });
};
```

### データベース設計

#### 1. 使用パターンテーブル
```sql
CREATE TABLE usage_patterns (
  id VARCHAR(255) PRIMARY KEY,
  user_id VARCHAR(255),
  tool_id VARCHAR(255),
  timestamp BIGINT,
  duration INT,
  context ENUM('morning', 'afternoon', 'evening', 'night'),
  day_of_week INT,
  frequency INT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 2. ユーザー目標テーブル
```sql
CREATE TABLE user_goals (
  id VARCHAR(255) PRIMARY KEY,
  user_id VARCHAR(255),
  goal_type ENUM('weekly_hours', 'productivity_score', 'tool_mastery'),
  target_value DECIMAL(10,2),
  current_value DECIMAL(10,2),
  start_date DATE,
  end_date DATE,
  status ENUM('active', 'completed', 'paused'),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 3. インサイト履歴テーブル
```sql
CREATE TABLE insight_history (
  id VARCHAR(255) PRIMARY KEY,
  user_id VARCHAR(255),
  insight_type VARCHAR(100),
  insight_data JSON,
  generated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user_insight (user_id, generated_at)
);
```

ユーザーフィードバックを重視し、データに基づいた継続的な改善を行い、最終的には個人に最適化された学習支援システムの構築を目指します。
